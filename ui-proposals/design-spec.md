# 源匣 SrcBox · 界面重制设计规范（v2 · dark-first）

来源：读取 `D:\github\SrcBox` 现有实现后提取 —— `Resources/Colors.Dark.xaml`、`Resources/Colors.Light.xaml`、
`Styles/PlayerStyles.xaml`、`Styles/MenuStyles.xaml`、`MainWindow.xaml`（1541 行；三栏 Grid：节目指南 322 / 视频 \* / 抽屉 344，底部 64）、
`Windows/Settings/SettingsWindow.xaml`（应用/播放/视频/声音/网络/频道/录制/关于 8 个选项卡）、
`Resources/Strings.zh-CN.xaml`（界面文案原文）。
本规范**只涉及外观**：不改功能、不改文案键值、不改快捷键，不引入新的字体依赖与第三方控件。

## 一句话设计系统

深色影音工作台：视频是唯一主角，界面用近黑中性色退后；单一冷青强调色只出现在进度、焦点与当前项上；
分隔靠色调差与 1px 极弱描边，而不是层层嵌套的卡片边框；信息密度保持，但把 10px 的小字全部提到 12px 以上。

## 一、六个核心令牌（OKLch）

| 令牌 | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `--bg` | `oklch(0.175 0.006 255)` | `oklch(0.968 0.002 255)` | 应用底、列表底、输入框底 |
| `--surface` | `oklch(0.225 0.006 255)` | `oklch(1 0 0)` | 抽屉、工具栏、标题栏、对话框 |
| `--fg` | `oklch(0.945 0.004 255)` | `oklch(0.215 0.010 255)` | 主文本、主图标、主按钮填充 |
| `--muted` | `oklch(0.735 0.010 255)` | `oklch(0.505 0.010 255)` | 次级文本、时间码、分组副标题 |
| `--border` | `oklch(0.325 0.008 255)` | `oklch(0.895 0.004 255)` | 分隔线、控件描边 |
| `--accent` | `oklch(0.760 0.110 195)` | `oklch(0.605 0.115 195)` | 进度已播段、焦点环、当前项、直播前的钩子 |

**唯一的语义例外**：直播红 `--live` = `oklch(0.630 0.205 25)`（浅色 `oklch(0.550 0.190 25)`），
只允许出现在「直播 / 正在录制」这一个语义上。仓库现状是红（直播）+ 绿（今天/进度）+ 蓝（预约、回放）+ 青（时移）
四种语义色同时争抢注意力，这是本次重制要解决的头号问题。

派生色一律现场推导，不新增颜色令牌：

```
--hover      = color-mix(in oklch, var(--fg) 7%, transparent)     /* 对应旧 #19FFFFFF */
--pressed    = color-mix(in oklch, var(--fg) 12%, transparent)    /* 对应旧 #33FFFFFF */
--selected   = color-mix(in oklch, var(--accent) 16%, transparent)
--accent-soft= color-mix(in oklch, var(--accent) 14%, transparent)
--fg-faint   = color-mix(in oklch, var(--fg) 5%, transparent)
```

## 三、从仓库观察到、必须贯彻的 4 条规则

1. **一个强调色**。强调色只用于：进度已播段、焦点环、当前选中项（频道行、设置分类）、收藏星标。
   回放 / 预约 / 刷新 / 清空等动作按钮全部降级为中性描边按钮；「今天」不再用实心绿底，
   改为中性底 + 前景色文字（`--pressed`），选中态靠字重和底色而非色相区分。
2. **容器不做重复嵌套**。现状是「列表项卡片边框 + 卡片内按钮边框 + 面板边框 + 1px 分隔线」四层同色描边。
   改为：面板之间用 1px `--border`；列表行之间用 5% 前景色的内阴影分隔；列表行自身不再包卡片。
3. **滚动条细而安静**：8px 宽，滑块 `color-mix(fg 16%)`，悬停才提到 28%，不抢视觉。
4. **状态栏是数据条**：分辨率 / 解码器 / 码率 / 帧率用等宽字体按列排布（`.np-stats`、`.statusbar`），
   与播放无关的装饰信息一律去掉。

## 五、禁止事项

- 不使用紫色渐变、emoji 图标、左侧色条 + 圆角卡片的提示样式。
- 不新增功能、不改文案键值、不改快捷键；原型中所有中文均取自 `Strings.zh-CN.xaml`。
- 频道台标在原型中使用中性字标（粤新/珠江/民生…）替代，不使用真实电视台台标素材；
  演示用的节目画面为纯 CSS 占位底色，不包含任何频道画面截图。
- 深色下不出现纯黑 `#000` 与纯白 `#FFF` 的大面积色块（视频区例外，保持真实播放器的黑底）。

## 六、原型与规范的对应关系

`srcbox-ui/srcbox-player-ui.html` 是上述规范的可交互实现：三栏结构、节目单、频道列表（五个选项卡 + 搜索过滤）、
传输条（播放/暂停、停止、±30 秒、上下频道、录制、速度、静音与音量）、设置对话框（8 个分类）、
深浅外观切换、面板折叠与 E / L / Space / ↑ / ↓ / R 快捷键、以及用 `localStorage` 记录外观、频道、进度与面板状态。
实现时以本规范的令牌与部件尺寸为准，原型中的演示频道名与节目名都是自拟的占位数据。

# 附：v3 Cinema First 方向（modern-minimal）

对应实现：`srcbox-ui/srcbox-player-ui-cinema.html`。第三套方案，功能集合与 v1 / v2 完全一致。

## 1. 方向来源

取运行时方向库的 `modern-minimal`（Linear / Vercel 的克制、精准、软件原生观感）：

- **浅色主题的六个令牌逐字绑定该方向规范**：`--bg: oklch(99% 0.002 240)`、`--surface: oklch(100% 0 0)`、
  `--fg: oklch(18% 0.012 250)`、`--muted: oklch(54% 0.012 250)`、`--border: oklch(92% 0.005 250)`、
  `--accent: oklch(58% 0.18 255)`；字体栈沿用规范的系统字体取向（Windows 上落到 Segoe UI Variable / Cascadia Mono）。
- **深色不是另起一套配色**，而是同色相（250）的电影院暗色推导：只推 L、收 C，色相关系与浅色一致。
- 执行规范里的姿态：显示字号收紧字距（-0.02em / -0.03em）、只用发丝级描边（阴影仅给浮层）、数字用等宽 + tabular-nums。

|---|---|---|
| `--bg` | `oklch(13% 0.010 250)` | `oklch(99% 0.002 240)` |
| `--surface` | `oklch(18% 0.012 250)` | `oklch(100% 0 0)` |
| `--fg` | `oklch(97% 0.003 250)` | `oklch(18% 0.012 250)` |

## 3. 与 v1 / v2 的结构差异

| | v1 影音工作台 | v2 NavigationView | v3 Cinema First |
|---|---|---|---|
| 常驻框架 | 三栏固定分栏 | 48px 导航栏 | **无**，全部悬浮 |
| 频道浏览 | 右侧抽屉列表 | 导航页网格 | 覆盖式「浏览」面板：聚光卡 + 卡片墙 |
| 节目单 | 左侧竖向列表 | 独立页竖向列表 | **多频道横向时间轴**（18 条频道道 + 时间标尺 + 现在线） |
| 播放控制 | 底部固定传输条 | 浮层底部控制条 | 悬浮控制坞，播放中**收成一条进度轨**，鼠标移动展开 |
| 设置 | 模态对话框 | 导航页分栏 | 覆盖面板：顶部分段 + 瀑布流卡片（字段由数据驱动渲染） |
| 视觉材料 | 极弱描边、色调差 | Mica 分层 + Acrylic | 毛玻璃浮层 + 发丝描边 + 单一强调色 |

## 4. v3 的功能对位

浏览面板顶部 5 个筛选项（全部 / 分组 / 收藏 / 播放记录 / 录制）承接了 v2 的收藏、记录、录制三个独立页；
控制坞右侧一排图标承接时移 / 画面比例 / 多屏 / 画中画 / 投射 / 播放速度 / 静音音量 / 全屏；
录制面板内含录播列表、上传队列、开始实时录制、加载本地分组；设置面板 7 个分段共 103 个控件，覆盖原设置窗口全部条目。

## 5. v3 禁止事项

- 不引入第二强调色；浅色下也不把画面区刷亮。
- 浮层的显隐一律用 `display` / `transform`，**不用 opacity 从 0 到 1 做可见性**（不驱动过渡的环境会停在 0 上）。
- 不把控制坞做成常驻大面板；播放中它必须能让位给画面。
