# 預約功能

SrcBox 提供強大的預約功能，支援預約通知、預約播放和預約錄製三種模式，是觀看 IPTV 直播的得力助手。

## 功能概覽

| 功能 | 說明 |
|------|------|
| **預約通知** | 節目開始前提醒，不自動播放 |
| **預約播放** | 到點自動切換到目標頻道播放 |
| **預約錄製** | 到點自動開始錄製（前臺/後臺模式） |

---

## 預約通知

節目開始前彈出通知提醒，用戶可選擇觀看或忽略。

### 功能特點
- 提前提醒（可自訂提前時間）
- 右下角 Toast 通知，不搶焦點
- 支援僅提醒模式

### 使用方式
1. 在 EPG 中選擇目標節目
2. 點擊右鍵選擇「預約」
3. 選擇「僅提醒」模式
4. 等待通知到來

---

## 預約播放

到點自動切換到目標頻道並開始播放。

### 功能特點
- 到點自動播放目標頻道
- 支援從時移開始播放
- 自動切換到目標頻道

### 使用方式
1. 在 EPG 中選擇目標節目
2. 點擊右鍵選擇「預約」
3. 選擇「到點自動播放」模式
4. 到點後自動切換並播放

---

## 預約錄製 (v1.1.9 新增)

到點自動開始錄製，支援前臺和後臺兩種模式。

### 前臺錄製

錄製時畫面會跳轉到正在錄製的頻道。

| 特點 | 說明 |
|------|------|
| 畫面跳轉 | 切換到錄製頻道 |
| 即時預覽 | 可看到錄製畫面 |
| 自訂時長 | 支援設定錄製時長，到時自動停止 |
| 計時器顯示 | 顯示已錄製時長 |

### 後臺錄製

錄製時保持當前播放頻道，不跳轉。

| 特點 | 說明 |
|------|------|
| 不中斷觀看 | 保持當前播放 |
| 後臺運行 | 錄製在後臺進行 |
| 自動停止 | 支援基於時長的自動停止 |
| 完成通知 | 錄製完成顯示 Toast 通知 |

### 錄製完成通知

- 錄製完成時顯示 Toast 通知
- 5 秒後自動隱藏
- 區分前臺/後臺錄製完成提示

### 使用方式

1. 在 EPG 中選擇目標節目
2. 點擊右鍵選擇「預約」
3. 選擇「前臺錄製」或「後臺錄製」模式
4. 可選設定錄製時長
5. 到點自動開始錄製

---

## 預約列表

管理所有已建立的預約。

### 功能特點
- 單一實例管理窗口
- 勾選方塊批次刪除
- 全選/反選功能
- 狀態篩選下拉框（v1.1.9 新增）
- 刷新按鈕（v1.1.9 新增）
- 窗口層級在播放器之上

### 入口方式
- 系統匣右鍵菜單 → 預約
- 下拉菜單 → 預約管理
- 右鍵菜單 → 預約列表

---

## 快捷鍵

| 快捷鍵 | 功能 |
|--------|------|
| `R` | 開始/停止錄製 |

---

## 相關設定

預約功能相關設定可在設定窗口中配置：
- 預約提前提醒時間
- 預設預約模式
- 錄製保存路徑
- 錄製完成通知方式
