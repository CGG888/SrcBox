# Web 遠程控制

SrcBox 提供 Web 遠程控制功能，允許您通過瀏覽器遠程操控播放器，實現播放控制、音量調節、頻道切換等操作。

## 功能概述

Web 遠程控制基於 WebSocket 和 HTTP 協議實現，支援以下功能：

- **播放控制**：播放、暫停、停止
- **進度控制**：快進、快退、跳轉
- **音量調節**：音量增減、静音
- **頻道切換**：上下換台、頻道列表
- **狀態查看**：當前播放狀態、節目信息
- **多語言支持**：中文、英文、俄文等

## 啟用遠程控制

1. 打開 SrcBox 設置窗口
2. 切換到 **Web 遠程控制** 選項卡
3. 勾選 **啟用 Web 遠程控制**
4. （可選）設置訪問端口（默認 8899）
5. （可選）啟用密碼保護，設置訪問密碼
6. 點擊 **保存** 按鈕

## 訪問遠程控制

啟用後，在瀏覽器中訪問：

```
http://localhost:8899
```

如果是本機訪問，直接使用 `localhost`。如果是區域網遠程訪問，請將 `localhost` 替換為 SrcBox 所在電腦的 IP 地址。

## 界面說明

### 狀態顯示區

- 當前播放狀態（直播/回放/時移）
- 當前頻道名稱和 Logo
- 當前節目名稱和播放時間

### 播放控制區

| 按鈕 | 功能 |
|------|------|
| 播放/暫停 | 切換播放狀態 |
| 停止 | 停止播放 |
| 快退 | 快退 10 秒 |
| 快進 | 快進 10 秒 |

### 頻道控制區

| 按鈕 | 功能 |
|------|------|
| 上一頻道 | 切換到上一個頻道 |
| 下一頻道 | 切換到下一個頻道 |
| 頻道列表 | 顯示/隱藏頻道列表 |

### 音量控制區

| 控件 | 功能 |
|------|------|
| 音量滑塊 | 調節音量大小 |
| 静音按鈕 | 切換静音狀態 |

### 頻道列表

- 顯示所有可用頻道
- 支援搜索過濾
- 點擊頻道名稱即可切換播放

### EPG 節目單

- 顯示當前頻道的節目列表
- 支援翻頁查看更多節目
- 顯示節目時間和簡介

## 安全設置

### 密碼保護

啟用密碼保護後，訪問遠程控制頁面需要輸入密碼：

1. 在設置中勾選 **需要密碼訪問**
2. 設置訪問密碼
3. 保存設置

訪問時需要輸入密碼才能使用遠程控制功能。

### 注意事項

- 默認情況下，遠程控制僅允許本地訪問（localhost）
- 如需區域網訪問，請確保防火牆允許對應端口
- 建議啟用密碼保護以確保安全
- 更改端口後需要刷新瀏覽器頁面

## 故障排除

### 無法訪問遠程控制頁面

1. 確認已在設置中啟用 Web 遠程控制
2. 檢查端口是否被占用（默認 8899）
3. 檢查防火牆設置
4. 確認 SrcBox 播放器正在運行

### 頁面顯示空白

1. 嘗試刷新頁面
2. 清除瀏覽器緩存
3. 使用其他瀏覽器訪問
4. 檢查是否啟用了密碼保護

### 操作無響應

1. 確認 SrcBox 播放器正在播放
2. 檢查網絡連接是否正常
3. 嘗試重新啟動 SrcBox 播放器

## 技術實現

Web 遠程控制採用以下技術：

- **WebSocket**：實時雙向通信，用於播放控制指令
- **HTTP**：狀態查詢和靜態資源服務
- **JSON**：數據交換格式
- **原生 HTML/CSS/JS**：無外部依賴

服務端默認監聽端口 8899，Web 界面通過瀏覽器訪問，無需額外安裝軟體。
