# Web 遠程控制

SrcBox 提供 Web 遠程控制功能，允許您通過瀏覽器遠程操控播放器，實現播放控制、音量調節、頻道切換、回看、預約錄製等完整操作。

## 功能概述

Web 遠程控制基於 WebSocket 和 HTTP 協議實現，支援以下功能：

- **播放控制**：播放、暫停、停止
- **進度控制**：快進、快退、跳轉
- **音量調節**：音量增減、靜音
- **頻道切換**：上下換台、頻道列表、頻道搜尋
- **回看功能**：時移回看、節目回看
- **預約功能**：預約提醒、預約錄製（前台/後台）
- **源管理**：添加、選擇、刪除播放源
- **狀態查看**：當前播放狀態、節目信息、EPG節目單
- **多語言支持**：中文、英文、俄文、繁體中文
- **界面切換**：標準遙控界面與完整界面一鍵切換，選擇自動記憶
- **數字鍵換台**：標準遙控界面可直接輸入頻道編號換台，頻道列表同步顯示編號
- **掃碼訪問**：設置中展示訪問二維碼與鏈接，手機掃碼或複製鏈接即可打開
- **HTTPS 訪問**：同一個端口同時支援 http 與 https，內建自簽憑證下載，手機可裝成受信任憑證
- **安裝到主畫面**：以 PWA 安裝到手機主畫面，用獨立視窗全螢幕開啟

## 啟用遠程控制

1. 打開 SrcBox 設置窗口
2. 切換到 **Web 遠程控制** 選項卡（設置中已獨立為一個選項卡）
3. 勾選 **啟用 Web 遠程控制**，勾選後立即生效，無需重啟
4. （可選）設置訪問端口（默認 8899）
5. （可選）啟用密碼保護，設置訪問密碼
6. 點擊 **保存** 按鈕

## 訪問遠程控制

啟用後，在瀏覽器中訪問：

```
http://localhost:8899
```

如果是本機訪問，直接使用 `localhost`。如果是區域網遠程訪問，請將 `localhost` 替換為 SrcBox 所在電腦的 IP 地址，例如：

```
http://192.168.1.100:8899
```

同一個端口也支援 HTTPS（伺服端依首個位元組自動區分），裝好憑證後可直接訪問 `https://192.168.1.100:8899`，詳見下方 [HTTPS 與憑證](#https-與憑證)。

### 掃碼訪問

啟用後，設置窗口的 **Web 遠程控制** 選項卡會顯示當前訪問地址與二維碼：

- 用手機相機或瀏覽器掃描二維碼即可打開遙控器
- 點擊 **複製鏈接** 複製訪問地址
- 憑證就緒時，二維碼與鏈接指向的是 **HTTPS 位址**（`https://電腦IP:端口`，手機首次開啟需先安裝憑證）；憑證不可用時才回退為 HTTP 位址
- 選項卡同時顯示**憑證安裝位址**、憑證狀態（含到期日）與**重新產生憑證**按鈕
- 二維碼與鏈接會隨端口變化自動更新；若未找到區域網地址，請檢查網絡連接

### HTTPS 與憑證

Web 遠程控制使用**單一端口**同時提供 HTTP 與 HTTPS：同一個端口既能接受 `http://` 也能接受 `https://` 請求（伺服端讀取首個位元組判斷是否為 TLS 握手），因此不需要另外配置 HTTPS 端口。

使用 HTTPS 的原因：

- 瀏覽器的「安裝應用程式」（PWA）與 Service Worker 只在安全環境（`https://` 或 `localhost`）下可用，手機以 `http://192.168.x.x` 開啟時無法把遙控器安裝成應用程式
- 區域網內明文 HTTP 的流量可被同網段裝置監聽，HTTPS 會加密流量

首次啟用遠程控制時，SrcBox 會在 `%LOCALAPPDATA%\SrcBox\webremote-certs` 下**自動產生**自簽根憑證與伺服器憑證（根憑證有效期 10 年；伺服器憑證 397 天，並在到期前 30 天自動續簽），無需手動建立。

用手機以 `http://192.168.1.100:8899` 開啟頁面後，頁面上的 **安裝** 按鈕會提示目前是 http 明文環境，並提供憑證下載入口：

| 地址 | 下載檔案 | 用途 |
|:---|:---|:---|
| `/cert` | `srcbox-ca.crt`（DER） | Android、Windows 安裝為受信任的 CA 憑證 |
| `/cert.pem` | `srcbox-ca.pem` | Android 讀不到 `.crt` 時的文字格式備用 |
| `/cert.mobileconfig` | `srcbox-ca.mobileconfig` | iPhone 描述檔，一鍵安裝 |

**Android 安裝憑證**：設定 → 安全性 → 加密與憑證 → 安裝憑證 → CA 憑證 → 選擇下載的 `srcbox-ca.crt`（讀不到就改用 `.pem`）。

**iOS 安裝憑證**：安裝下載的描述檔後，還須前往 設定 → 一般 → 關於本機 → 憑證信任設定，為 SrcBox 憑證開啟**完全信任**。

裝好憑證後回到提示框點擊 **用 HTTPS 開啟**（即跳轉到 `https://192.168.1.100:8899/`），也可以直接在瀏覽器網址列改用 `https://` 訪問。

不想裝憑證也沒關係：Android 用瀏覽器選單 →「加入主畫面」，開啟後點頁面右上角的全螢幕按鈕（⛶）；iOS 用 Safari 分享 →「加入主畫面」，系統會以全螢幕方式開啟（iOS 不要求憑證）。差別只是這種方式不算真正的 PWA 安裝。

**卸載憑證**：iPhone 在「設定 → 一般 → VPN 與裝置管理」移除 SrcBox 描述檔，再到「憑證信任設定」關閉完全信任；Android 在「設定 → 安全性 → 加密與憑證 → 受信任的憑證 → 使用者」中選擇 SrcBox 憑證移除；Windows 在 `certmgr.msc` 的「受信任的根憑證頒發機構 → 憑證」中刪除 SrcBox。卸載後需改用 `http://` 訪問，或重新安裝憑證。設定頁的**重新產生憑證**會簽發一套新的根憑證與伺服器憑證，舊憑證隨即失效，手機上需要重新安裝。

### HTTPS 可用性與憑證續簽

- **啟動自檢**：SrcBox 啟動時會用環回位址對自身做一次 TLS 握手自檢，只有確認真的能提供 HTTPS，才會在頁面與二維碼裡給出 `https://` 位址。如果當前環境用不了 HTTPS（例如程式受安全策略限制、憑證目錄不可寫），頁面與二維碼會自動回落到 `http://`，憑證下載入口（`/cert`、`/cert.pem`、`/cert.mobileconfig`）仍然可用——不會再給手機一個**打不開的** `https://` 入口。
- **換網後自動續簽**：伺服器憑證會把當前網卡位址寫進憑證的 SAN。IP 變化（DHCP 續租、切換 Wi-Fi 或網路線）後，SrcBox 會按新的位址清單**自動重新簽發**伺服器憑證，不需要重啟程式，手機也不會再報 `ERR_CERT_COMMON_NAME_INVALID`；根憑證不變，已安裝的 CA 不需要重新安裝。
- **想用語音遙控請走 HTTPS**：手機麥克風只在安全環境（`https://` 或 `localhost`）下可用。以 `http://192.168.x.x` 開啟時頁面會提示當前不是安全環境，語音面板無法錄音；按上面的步驟裝好憑證、改用 `https://` 開啟即可。

### 安裝到主畫面（PWA）

遙控器頁面是一個 PWA（`manifest.json` + Service Worker），可以安裝到手機主畫面，像應用程式一樣全螢幕開啟：

- **Android（Chrome / Edge）**：在安全環境（https 或 localhost）下頁面會顯示 **安裝** 按鈕，點按後選擇「安裝應用程式」；若瀏覽器沒有提供安裝提示，可開啟瀏覽器選單 →「安裝應用程式」或「加入主畫面」
- **iOS（Safari）**：點「分享」→「加入主畫面」，這是 iOS 唯一的安裝方式
- 已用獨立視窗（standalone）開啟時安裝入口不再顯示；選擇過「不再提示」後也不會再出現
- 安裝後以獨立視窗執行，沒有網址列；頁面右上角的全螢幕按鈕（⛶）在純 http 下同樣可用

## 界面說明

- **標準遙控**：手機豎屏友好的遙控器佈局（方向鍵、數字鍵、音量鍵、換源/靜音）

- 顯示所有可用頻道和收藏頻道

- 收藏頻道以星標顯示在列表頂部
- 每個頻道顯示頻道編號，編號按播放清單的分組順序連續排列、不隨分組重置，與標準遙控界面的數字鍵一一對應（收藏頻道沿用其分組中的編號）

### EPG 節目單

- 顯示當前頻道的節目列表（默認顯示當天節目）
- 點擊節目可進入回看
- 支援三個操作按鈕：
  - **觀看**（紅色）：直接切到該頻道觀看正在直播的節目
  - **回看**（紫色）：適用於**已播過的節目，且該頻道支援回看（catch-up）或時移**（頻道自帶 `catchup-source`，或設定中啟用了時移模板）才會顯示，不再只看全域時移開關
  - **預約**（藍色）：預約節目提醒

### 語音遙控（離線）

頁面上的**麥克風按鈕**會開啟「語音控制」面板：

![語音控制面板](../../screenshots/web-remote-voice-light.png)

- 點大麥克風按鈕開始說話，再點一次結束；**錄音在手機上完成**（16 kHz 單聲道），分片上傳給播放器
- 播放器用**本機離線模型**（SenseVoice-Small，int8 量化，約 228 MB，**不連網**）辨識，音訊與辨識結果都不會離開本機
- 辨識結果與候選頻道會回顯在面板裡（例如聽到「3 台」，面板列出 `CCTV3`）；辨識完成後面板保持開啟，可以連續下達多條指令
- 面板下方的輸入框可以直接**輸入指令**再點「傳送」，效果與語音相同

可以直接說：

| 說法 | 結果 |
|------|------|
| `湖南衛視` / `CCTV3` / `3 台` | 按台名或頻道號換台（同音字如「2 太 / 2 胎」也能辨識） |
| `下一個台` / `上一個台` | 上下換台 |
| `換源` | 切換當前頻道的下一個播放來源 |
| `音量 40` / `音量加` / `靜音` | 調整音量或靜音 |
| `快進 30 秒` / `後退 15 秒` | 相對跳轉（回看 / 時移中生效） |
| `回看今天的新聞聯播` | 在當前頻道的節目單裡找到該節目並回看 |
| `現在在播什麼` | 播報當前頻道的節目資訊 |

首次使用只要把 **設定 → Web 遙控器 → 離線語音辨識** 打開：開關會先問一句「需要先下載語音模型（約 228 MB），現在下載嗎？」，確認後開啟下載視窗，即時顯示**階段（連線 / 下載 / 校驗）、百分比、目前檔案、速度與剩餘時間**，隨時可以停止——已下載的部分會保留，下次接著傳；每個檔案下載完都會與發佈值逐一核對 **SHA-256**，接著自動載入模型並跑一段無聲樣本自檢，狀態列顯示「語音模型已就緒，自檢通過」才真正可用。旁邊的**刪除模型**按鈕會釋放磁碟與記憶體並自動關閉開關。語音喚醒詞、自訂短語規則、音量級距也在同一頁設定。

> 手機麥克風只在安全環境（`https://` 或 `localhost`）下可用：以 `http://192.168.x.x` 開啟時頁面會提示當前不是安全環境，語音面板無法錄音——按上文《HTTPS 與憑證》裝好憑證、改用 `https://` 開啟即可。

## 安全設置

### 密碼保護

啟用密碼保護後，訪問遠程控制頁面需要輸入密碼：

1. 在設置中勾選 **需要密碼訪問**
2. 設置訪問密碼
3. 保存設置

訪問時需要輸入密碼才能使用遠程控制功能。

### 注意事項

- 啟用後服務監聽本機**所有網卡**（`0.0.0.0`），同一區域網內任何裝置只要知道位址與埠即可存取；預設**不開啟密碼**，建議勾選「需要密碼存取」
- 如需區域網訪問，請確保防火牆允許對應端口
- 建議啟用密碼保護以確保安全
- 區域網內明文 `http://` 的流量可被同網段裝置監聽，建議安裝憑證後改用 `https://` 訪問（見 [HTTPS 與憑證](#https-與憑證)）
- 手機安裝到主畫面需要安全環境（https 或 localhost），純 http 只能「加入主畫面」
- 更改端口後需要刷新瀏覽器頁面
- 設定中的 **顯示頻道列表** 與 **顯示節目單** 開關現在真正生效：關閉後遠程頁面不再顯示對應區塊
- 設定中的 **節目單條數上限**（Max EPG items）可填 5–500，預設 50，用來控制遠程頁面節目單一次顯示的節目數量

## WebSocket API 參考

除了瀏覽器界面操作外，還可以通過 WebSocket API 進行編程控制。

### 連接方式

```javascript
const ws = new WebSocket('ws://localhost:8899');
```

### 認證（需要密碼時）

```json
// 發送
{ "action": "auth", "password": "your_password" }

// 接收
{ "success": true, "requireAuth": true }
```

### 通用響應格式

所有操作成功後返回 JSON 響應，失敗返回 `{ "error": "錯誤信息" }` 或 `{ "success": false }`。

### API 列表

#### 播放控制

| Action | 參數 | 說明 |
|--------|------|------|
| `play` | - | 播放/繼續播放 |
| `pause` | - | 暫停播放 |
| `stop` | - | 停止播放 |
| `volume` | `volume` (0-100) | 設置音量 |
| `fullscreen` | - | 切換全屏 |
| `seek` | `seconds` (+/-數值) | 跳轉秒數 |

#### 頻道控制

| Action | 參數 | 說明 |
|--------|------|------|
| `channel` | `channelId` | 切換頻道 |

上一頻道 / 下一頻道按鈕由頁面依目前頻道清單算出目標頻道 id，再呼叫 `channel` 實現；WebSocket 介面本身沒有 `prevChannel` / `nextChannel` 動作（呼叫會回傳 `Unknown action`）。

#### 速度控制

| Action | 參數 | 說明 |
|--------|------|------|
| `setSpeed` | `speed` (0.5/1.0/2.0) | 設置播放倍速 |
| `setTimeshift` | `enabled` (true/false) | 開啟/關閉時移 |

#### 回看功能

| Action | 參數 | 說明 |
|--------|------|------|
| `replayProgram` | `channelId`, `programTitle`, `start` (ISO), `end` (ISO) | 回看指定節目（頁面上的 **回看** 按鈕只在已播過的節目且該頻道支援回看或時移時顯示） |

#### 狀態查詢

| Action | 返回 | 說明 |
|--------|------|------|

| `getChannels` | `{ groups: [...], favorites: [...] }` | 獲取頻道列表 |
| `getEpg` | `{ channelId, programs: [...] }` | 獲取節目單 |
| `getSources` | `{ sources: [...] }` | 獲取播放源列表 |
| `getReminders` | `{ reminders: [...] }` | 獲取預約列表 |
| `getRecordings` | `{ recordings: [...] }` | 獲取錄製列表 |

#### 錄製管理

#### 源管理

| Action | 參數 | 說明 |

## 故障排除

### 無法訪問遠程控制頁面

1. 確認已在設置中啟用 Web 遠程控制
2. 檢查端口是否被占用（默認 8899）
3. 檢查防火牆設置
4. 確認 SrcBox 播放器正在運行

### 頁面顯示空白

1. 嘗試刷新頁面
2. 清除瀏覽器緩存
3. 使用其他瀏覽器訪問
4. 檢查是否啟用了密碼保護

### 操作無響應

1. 確認 SrcBox 播放器正在播放
2. 檢查網絡連接是否正常
3. 嘗試重新啟動 SrcBox 播放器

## 技術實現

Web 遠程控制採用以下技術：

- **WebSocket**：實時雙向通信，用於播放控制指令
- **HTTP**：狀態查詢和靜態資源服務
- **JSON**：數據交換格式
- **原生 HTML/CSS/JS**：無外部依賴

服務端默認監聽端口 8899，Web 界面通過瀏覽器訪問，無需額外安裝軟體。
