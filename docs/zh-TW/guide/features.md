# 功能特性

## 播放控制

- **播放控制**: 播放/暫停、停止、快進/快退、拖動進度
- **音量調節**: 滑塊調節 + 靜音 (0-100)
- **音頻設置**: 音量增益 (-200dB~+60dB)、最大音量 (100%~1000%)、音頻延遲 (-100s~+100s)
- **狀態標識**: 全螢幕條顯示直播/回放/時移狀態
- **倍速播放**: 時移/回放模式下支援 0.5×~5.0× 倍速，音高校正不變調

## 節目單與回看

### M3U 解析
支援本地/遠端 M3U 播放清單，相容 UTF-8/GB18030 編碼，支援 `#EXTINF` 擴展屬性。

### EPG 電子節目單
支援 XMLTV (gz) 格式，自動按日切換，智慧匹配 `tvg-id`。
[查看設定說明](./epg)

### 回放 (Catchup)
基於模板自動生成回放 URL（如 `{utc:yyyyMMddHHmmss}`），不錯過精彩節目。
[查看使用說明](./catchup-timeshift)

## 多屏播放

支援 4/6/9 屏幕同時觀看，適合監控或多任務場景。

| 快捷鍵 | 功能 |
|--------|------|
| `Ctrl+4/6/9` | 打開對應多屏模式 |
| `1-9` | 選擇對應小屏幕 |
| `↑/↓` | 切換頻道 |
| `←/→` | 切換源 |

## 預約錄製

支援前台/後台兩種預約錄製模式，錄製完成自動 Toast 通知。

- **前台錄製**: 畫面跳轉目標頻道，支援自訂時長自動停止
- **後台錄製**: 保持當前播放頻道，支援定時停止
- **WebDAV 同步**: 錄播後自動上傳到 WebDAV 伺服器

## Web 遠程控制

透過瀏覽器遠程控制播放器，隨時隨地掌控電視。

- 播放控制、音量調節、頻道切換
- 即時狀態查看、節目資訊顯示
- 可選密碼保護

[查看詳細說明](./web-remote)

## 頻道管理

- **分組**: 頻道分組管理，支援排序
- **搜尋**: 快速搜尋頻道
- **收藏**: 收藏常用頻道
- **歷史**: 播放歷史記錄，本機持久化
- **R/T 標識**: 快速識別支援回放(R)或時移(T)的頻道

## 解碼器選擇

支援多種硬體/軟體解碼器，播放時動態切換：

| 解碼器 | 說明 |
|--------|------|
| 自動 | 自動選擇最佳解碼器 |
| D3D11VA | Windows 影片加速 (預設) |
| DXVA2 | DirectX Video Acceleration |
| NVDEC | NVIDIA GPU 解碼 |
| 軟體 | CPU 軟體解碼 |

## 畫面優化

### 去交錯 (Deinterlace)
針對 1080i/720i 隔行掃描視頻流優化：
- 三種模式: 自動 / 強制開啟 / 關閉
- 兩種演算法: yadif (預設) / bwdif (更優質量)
- 場序設定: 自動 / 頂場優先 (TFF) / 底場優先 (BFF)

## 全螢幕交互

- **雙擊全螢幕** 或按 `Enter` 進入全螢幕
- **懸浮控制條**: 滑鼠移到底部自動顯示
- **側邊抽屜**: 滑鼠貼邊顯示頻道列表(右)或 EPG(左)
- **ESC** 退出全螢幕

## 介面特色

- **深色/淺色主題**: 完美適配 Windows 10/11
- **精簡模式**: 緊湊視窗形態，適合小螢幕觀看
- **多語言**: 支援簡體中文、繁體中文、英文、俄文
