# 項目介紹

**源匣 (SrcBox)** 是一款專為 Windows 平台打造的高效能、現代化 IPTV 播放器。基於強大的 **libmpv** 播放內核，結合 **WPF** 現代化界面設計，為用戶提供流暢、穩定的直播觀看體驗。

## 核心特性

### FCC 極速切台
針對 IPTV 場景深度優化的快速切台技術，實現毫秒級頻道切換，告別傳統播放器的漫長等待。

### M3U + EPG
- 支援本地/遠程 M3U 播放列表
- 完整 XMLTV (gz) 電子節目單
- 自動按日切換，智慧節目匹配

### 時移與回看
- 即時拖動回看直播歷史
- 基於模板自動生成回放連結
- 快進快退限制在節目邊界內

### 多屏播放
支援 4/6/9 屏幕同時觀看，數字鍵快速切換，適合監控或多工場景。

### 預約錄製
- 前台/後台雙模式錄製
- 定時自動停止
- WebDAV 雲端同步

### Web 遠程控制
透過瀏覽器隨時隨地遠程操控播放器，支援播放控制、音量調節、頻道切換。

## 技術架構

| 層級 | 組件 | 說明 |
|------|------|------|
| 播放內核 | libmpv-2.dll | 高效能跨平台播放器內核 |
| 渲染層 | WindowsFormsHost | 承載 mpv 窗口句柄嵌入 WPF |
| UI 框架 | WPF + ModernWpf | 現代化 Windows 界面 |
| 服務層 | M3U/EPG/Recording | 核心業務服務 |

| 技術選型 | 說明 |
|----------|------|
| 語言 | C# (.NET 8) |
| UI 框架 | WPF + ModernWpf |
| 播放內核 | libmpv |
| 硬體解碼 | D3D11VA / DXVA2 / NVDEC |
| 遠程控制 | WebSocket + HTTP |
| 錄播同步 | WebDAV |
| 文檔站點 | VitePress |

## 功能一覽

### 播放功能
- 播放/暫停/停止/快進/快退
- 音量調節 + 靜音
- 音頻延遲調節 (-100s~+100s)
- 倍速播放 (0.5×~5.0×)

### 頻道管理
- 分組管理，支援排序
- 快速搜尋
- 收藏常用頻道
- 播放歷史記錄

### 畫面優化
- 硬體解碼自動切換
- 去交錯處理 (1080i/720i)
- 自動換源

### 界面特色
- 深色/淺色主題自適應
- 全屏懸浮控制條
- 側邊抽屜 (頻道列表/EPG)
- 精簡模式窗口

### 多語言
- 簡體中文
- 繁體中文
- English
- Русский
