# 項目介紹

**源匣 (SrcBox)** 是一款專為 Windows 平台打造的高性能、現代化 IPTV 播放器。

## 概述

SrcBox 基於強大的 **libmpv** 播放內核構建，結合 **WPF** 的現代化界面設計，為用戶提供流暢、穩定的直播觀看體驗。它不僅支援 M3U 播放列表、EPG 電子節目單、回看、時移、錄播等核心功能，還針對 IPTV 場景進行了深度優化。

## 技術架構

| 組件 | 技術 |
|------|------|
| 播放內核 | libmpv |
| UI 框架 | WPF + ModernWpf |
| 語言 | C# (.NET 8) |
| 錄播同步 | WebDAV |
| 遠程控制 | WebSocket + HTTP |

## 主要功能

### 核心播放
- M3U 播放列表解析（本地/遠程）
- EPG 電子節目單（XMLTV 格式）
- 直播時移與節目回放
- 硬體加速解碼支援

### 特色功能
- **FCC 快速切台**：毫秒級極速換台體驗
- **Web 遠程控制**：通過瀏覽器遠程操控
- **音頻優化**：音量增益、最大音量、音頻延遲
- **去交錯處理**：針對隔行掃描視頻優化
- **WebDAV 錄播**：本地錄播配合雲端同步

### 用戶體驗
- 深色/淺色主題自適應
- 多語言界面（簡/繁/英/俄）
- 頻道收藏與歷史記錄
- 節目預約提醒

## 適用場景

- 觀看 IPTV 直播電視
- 錄播精彩節目內容
- 回看錯過的電視節目
- 遠程控制播放器

## 系統要求

- Windows 10/11
- .NET 8 Runtime
- 網絡連接（用於直播和 EPG）
