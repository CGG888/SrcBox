# 頻道快照預覽

滑鼠懸停在頻道列表的頻道上時，會顯示一個即時預覽快照浮窗，方便在切換頻道前快速預覽內容。

![頻道快照預覽](/screenshots/videosnapshot.png)

## 前置要求

頻道快照功能依賴 **rtp2httpd** 的 `X-Request-Snapshot` HTTP Header 特性。

請確保你的 rtp2httpd 已開啟快照支援：

```bash
rtp2httpd --enable-snapshot
```

## 功能特點

- **懸停即現**: 滑鼠移入頻道列表項，快照浮窗立即顯示在頻道左側
- **不干擾播放**: 快照僅在懸停時顯示，雙擊播放頻道時會自動關閉浮窗
- **可自訂尺寸**: 預設為 214×120 (16:9)，可在設定中調整
- **LRU 快取**: 30 秒快取，同一頻道 30 秒內不重複請求，節省頻寬
- **併發控制**: 最多 2 個併發快照請求，避免 rtp2httpd 過載

## 設定說明

在 **設定 → 頻道** 頁面：

1. 勾選 **頻道快照預覽** 開啟功能（預設關閉）
2. 可選調整 **寬度** 和 **高度**（最小 80×60）
3. 推薦保持 16:9 比例

## 運作原理

功能實現通過向 rtp2httpd 發送帶有 `X-Request-Snapshot: 1` HTTP Header 的 HEAD 請求來觸發快照生成，然後以 JPEG 格式回傳當前視訊幀。SrcBox 使用以下策略確保體驗流暢：

- 快照請求為非同步，不阻塞 UI 執行緒
- 結果快取在記憶體中，30 秒內重複請求直接回傳快取
- 多個頻道同時懸停時，最多等待 2 個請求完成

## 適用場景

- **頻道瀏覽**: 在不播放的情況下快速瀏覽多個頻道的內容
- **頻道切換**: 切換前預覽目標頻道是否為目標內容
- **多屏監控**: 多屏模式下，懸停即可預覽各頻道當前畫面
