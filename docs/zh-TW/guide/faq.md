# 常見問題 (FAQ)

## 播放問題

**Q: 有畫面無聲音怎麼辦？**
A: 部分 IPTV 來源音訊探測較慢，已設定 `probesize=32` 加速起播，可能導致短暫無聲。可嘗試：
- 切換音軌（如果有多音軌）
- 重啟播放
- 檢查系統音量設定

**Q: 頻道切換很慢怎麼辦？**
A: 確保開啟了 FCC 快速切台功能（設定 > 播放 > FCC 快速切台）。如仍慢，可嘗試：
- 啟用硬體解碼（D3D11VA）
- 檢查網絡延遲
- 關閉 UDP 組播優化（如果不需要）

**Q: 播放卡頓/緩衝怎麼辦？**
A: 嘗試以下方法：
- 切換解碼器（自動/D3D11VA/DXVA2/NVDEC/軟體）
- 檢查網絡穩定性
- 降低視頻質量期望（部分來源有限制）
- 嘗試自動換源功能

**Q: 全屏後如何顯示控制條？**
A: 滑鼠移動到螢幕底部即可顯示懸浮控制條，自動隱藏時間可在設定中調整。

## M3U 與播放清單

**Q: 如何載入 M3U 播放清單？**
A: 點擊頂部功能表「開啟 > 開啟 M3U 檔案」或「開啟 > 開啟 M3U URL」，支援本地檔案和網絡地址。

**Q: 支援哪些 M3U 格式？**
A: 支援標準 M3U/M3U8 格式，相容 UTF-8 和 GB18030 編碼，支援 `#EXTINF` 擴展屬性（如 logo、分組資訊）。

**Q: TXT 格式的頻道清單可以用嗎？**
A: 可以，TXT 格式每行一個 URL，程式會自動識別。

**Q: M3U 緩存是永久的嗎？**
A: 不是，M3U 緩存預設 12 小時（可通過設定中的 `M3uCacheTtlHours` 調整）。可通過「管理 M3U 清單」強制刷新。

## EPG 電子節目單

**Q: EPG 顯示「無數據」怎麼辦？**
A: 請檢查：
- XMLTV URL 是否可正常訪問
- 是否為 GZIP 壓縮格式（.gz）
- `tvg-id` 是否與 M3U 中的頻道匹配
- 網絡是否能訪問 EPG 數據來源

**Q: 如何配置 EPG？**
A: 在設定視窗的「EPG」標籤頁中填入 XMLTV URL，支援本地檔案和網絡地址。

**Q: 節目單時間不準怎麼辦？**
A: 檢查系統時區設定是否正確，EPG 數據依賴本地時間計算節目排程。

## 錄製功能

**Q: 如何開始錄製？**
A: 按 `R` 鍵或點擊錄製按鈕開始錄製，再次按下停止。

**Q: 錄製的檔案保存在哪裡？**
A: 預設保存在「文檔\SrcBox\Recordings」目錄，可在設定中修改。

**Q: 支援 WebDAV 上傳嗎？**
A: 支援。在設定中配置 WebDAV 伺服器位址、使用者名稱和密碼後，錄製完成會自動上傳。

**Q: 前台錄製和後台錄製有什麼區別？**
A:
- **前台錄製**：錄製時畫面跳轉到正在錄製的頻道，顯示錄製計時器
- **後台錄製**：保持當前播放頻道，不跳轉錄製，錄製完成顯示 Toast 通知

## 回看與時移

**Q: 時移功能怎麼用？**
A: 按 `T` 鍵進入時移模式，拖動進度條回看直播歷史。再次按 `T` 返回直播。

**Q: 回放 (Catchup) 怎麼用？**
A: 需要頻道支援 `catchup-source` 屬性。EPG 中點擊已播放節目即可回看。

**Q: 時移能回看多久？**
A: 取決於頻道伺服器的 `catchup-source` 配置和時移緩衝區設定。

## 多屏播放

**Q: 如何開啟多屏模式？**
A: 按 `Ctrl+4`/`Ctrl+6`/`Ctrl+9` 分別打開 4/6/9 屏幕模式。

**Q: 多屏模式下如何切換頻道？**
A: 使用 `1-9` 數字鍵選擇屏幕，`↑/↓` 切換頻道，`←/→` 切換來源。

## Web 遠程控制

**Q: 如何開啟 Web 遠程控制？**
A: 在設定中啟用 Web 遠程控制，按提示設定連接埠和密碼（可選）。

**Q: 如何訪問 Web 遠程控制？**
A: 在同一區域網路內的流覽器中輸入 `http://播放器電腦IP:連接埠`。

## 快捷鍵

**Q: 常用快捷鍵有哪些？**
A:
| 快捷鍵 | 功能 |
|--------|------|
| `Space` | 播放/暫停 |
| `S` | 停止 |
| `↑/↓` | 上一/下一頻道 |
| `M` | 靜音 |
| `Enter` | 全屏切換 |
| `L` | 頻道清單 |
| `E` | EPG 節目單 |
| `R` | 開始/停止錄製 |
| `T` | 時移模式 |
| `Ctrl+,` | 設定 |
| `Ctrl+/` | 快捷鍵幫助 |

## 故障排查

**Q: 程式啟動即崩潰？**
A: 請確保 `libmpv-2.dll` 已放置在程式運行目錄。

**Q: 設定不保存？**
A: 確保程式目錄有寫入許可權，或嘗試以管理員身份運行。

**Q: 如何回饋問題或建議？**
A: 請到 [GitHub Issues](https://github.com/CGG888/SrcBox/issues) 提交，我們會盡快處理。

## 系統要求

**Q: 支援哪些作業系統？**
A: Windows 10/11 (x64)。

**Q: 需要安裝什麼運行庫？**
A: 需要 .NET 8 Runtime。首次運行如提示缺少運行庫，請從微軟官網下載安裝。
