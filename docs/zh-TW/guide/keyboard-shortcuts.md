# 鍵盤快捷鍵

SrcBox 支援豐富的鍵盤快捷鍵，方便在觀看直播時實現盲操作。

## 播放控制

| 快捷鍵 | 功能 | 說明 |
|--------|------|------|
| `Space` | 播放/暫停 | 切換播放狀態 |
| `S` | 停止播放 | 停止當前播放 |

## 頻道切換

| 快捷鍵 | 功能 | 說明 |
|--------|------|------|
| `↑` | 上一頻道 | 切換到上一個頻道 |
| `↓` | 下一頻道 | 切換到下一個頻道 |
| `←` | 上一源 | 直播模式下切換到上一個播放源 |
| `→` | 下一源 | 直播模式下切換到下一個播放源 |

## 時移與回看

| 快捷鍵 | 功能 | 說明 |
|--------|------|------|
| `←` | 快退 | 時移/回看模式下快退 10 秒 |
| `→` | 快進 | 時移/回看模式下快進 10 秒 |

> **注意**：左右鍵的行為根據當前播放模式自動切換：
> - 直播模式：切換播放源
> - 時移/回看模式：快進快退

## 音量控制

| 快捷鍵 | 功能 | 說明 |
|--------|------|------|
| `M` | 靜音 | 切換靜音狀態 |
| `=` / `+` | 音量增加 | 調高音量 |
| `-` / `Num-` | 音量減少 | 調低音量 |

## 界面控制

| 快捷鍵 | 功能 | 說明 |
|--------|------|------|
| `Enter` | 全屏切換 | 進入/退出全屏模式 |
| `L` | 頻道列表 | 顯示/隱藏頻道列表側邊欄 |
| `Ctrl+Shift+L` | 精簡模式 | 切換精簡播放器窗口 |
| `E` | EPG 節目單 | 顯示/隱藏 EPG 電子節目單 |

## 錄製控制

| 快捷鍵 | 功能 | 說明 |
|--------|------|------|
| `R` | 開始/停止錄製 | 控制錄製開始或停止 |

## 多屏播放 (v1.1.9 新增)

| 快捷鍵 | 功能 | 說明 |
|--------|------|------|
| `Ctrl+4` | 4屏模式 | 打開 4 屏幕多屏播放 |
| `Ctrl+6` | 6屏模式 | 打開 6 屏幕多屏播放 |
| `Ctrl+9` | 9屏模式 | 打開 9 屏幕多屏播放 |
| `1-9` | 選擇屏幕 | 多屏播放中選擇對應小屏幕 |
| `↑/↓` | 切換頻道 | 多屏播放中切換上一/下一頻道 |
| `←/→` | 切換源 | 多屏播放中切換上一個/下一個源 |

## 全屏模式專用

| 快捷鍵 | 功能 | 說明 |
|--------|------|------|
| `Escape` | 退出全屏 | 從全屏模式返回窗口模式 |

## 其他

| 快捷鍵 | 功能 | 說明 |
|--------|------|------|
| `F1` | 調試窗口 | 打開調試信息窗口 |
| `Ctrl+,` | 設置 | 打開設置窗口 |
| `Ctrl+I` | 關於 | 打開關於對話框 |
| `Ctrl+/` | 快捷鍵說明 | 打開快捷鍵幫助窗口 |

## 常見問題

**Q: 為什麼按左右鍵有時候是切換頻道，有時候是快進快退？**

A: 左右鍵的行為是智慧切換的：
- 在觀看直播時，左右鍵用於切換播放源（適合多源頻道）
- 在時移或回看模式下，左右鍵變為快進快退
- 在多屏播放模式下，左右鍵用於切換源

**Q: 快捷鍵在窗口模式和全屏模式下都生效嗎？**

A: 是的，所有快捷鍵在窗口模式和全屏模式下都通用（`Escape` 僅在全屏模式下有效）。

**Q: 多屏播放的快捷鍵怎麼使用？**

A: 打開多屏播放後，直接按 1-9 數字鍵選擇對應屏幕，選中後即可使用 ↑↓ 切換頻道、←→ 切換源。

**Q: 如何快速打開設置窗口？**

A: 按 `Ctrl+,` 即可快速打開設置窗口。
