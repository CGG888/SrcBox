# 路標圖 (Roadmap)

我們致力於持續提升 IPTV 觀看體驗。

## 未來計劃

- [ ] **智慧推薦**：基於觀看習慣的 AI 節目推薦
- [ ] **多視角同屏**：支援多源拼屏觀看（畫中畫/四分屏）
- [ ] **雲端錄製 (PVR)**：支援連接遠端儲存進行節目錄製
- [ ] **高級視聽體驗**：HDR10+ 動態元資料支援、8K 120fps 解碼優化
- [ ] **互動功能**：語音彈幕（語音轉字幕）、低延遲雲遊戲入口
- [ ] **版權保護**：區塊鏈版權校驗（防篡改溯源）
- [ ] **通知動畫**：預約通知淡入/滑入、置中彈窗動效
- [ ] **晶片可定制**：直播/回放晶片圖示/色彩/圓角的外觀模板化

## 已實現功能

- [x] **時移 (Time-Shift)**：基於 `catchup-source` 的回放式時移，支援即時拖動回看。
- [x] **EPG 電子節目單**：支援 XMLTV (gz) 解析與展示。
- [x] **頻道回看**：基於模板自動生成回放 URL。
- [x] **M3U 解析**：支援本地/遠端清單及 `#EXTINF` 擴展屬性。
- [x] **頻道管理**：分組、搜尋、收藏功能。
- [x] **直播優化**：FCC 快速切台、UDP 組播優化、自动换源。
- [x] **硬體解碼**：預設開啟 `d3d11va`。
- [x] **預約能力**：預約通知、預約列表、到點自動播放策略。
- [x] **精簡模式**：精簡視窗、頂欄互動、視窗態/全螢幕態狀態同步。
- [x] **UI/UX**：全螢幕懸浮控制、側邊抽屜、多語言支援（中/英）。
- [x] **v1.1.2+ 互動更新**：
  - EPG 狀態晶片：直播=紅填充、回放=綠填充；點擊直播晶片即播放
  - 當前播放識別：整行高亮；回放播放中左側綠色豎線
  - 預約通知：列表單一實例、首次置中、勾選框批刪、系統匣/右鍵/下拉入口一致
  - M3U 管理：批次刪除、單筆編輯、系統匣入口、全螢幕可見
  - 系統匣常駐：打開/預約/管理 M3U/設定/退出
  - 關閉確認：×/ESC 僅關閉對話框；「否」最小化系統匣（全螢幕先退出全螢幕）
  - 深淺色標題列：預約列表、M3U 管理、預約提醒、退出框在建立後即時匹配主題
  - 倍速控制：支援時移/回放的倍速播放（含 3×/5×），自動音高校正；直播不支援

## 預覽/實驗特性

- [~] 預約/通知動畫：樣式與動效方案已設計，後續版本開放
- [~] 回放晶片可點擊直達：交互評估中，計劃與「點擊節目標題回放」並存
