# 路標圖 (Roadmap)

我們致力於持續提升 IPTV 觀看體驗。

## 未來計劃

- [ ] **智慧推薦**：基於觀看習慣的 AI 節目推薦
- [ ] **雲端錄製 (PVR)**：支援連接遠端儲存進行節目錄製
- [ ] **高級視聽體驗**：HDR10+ 動態元資料支援、8K 120fps 解碼優化
- [ ] **互動功能**：語音彈幕（語音轉字幕）、低延遲雲遊戲入口
- [ ] **版權保護**：區塊鏈版權校驗（防篡改溯源）
- [ ] **通知動畫**：預約通知淡入/滑入、置中彈窗動效
- [ ] **晶片可定制**：直播/回放晶片圖示/色彩/圓角的外觀模板化

## 已實現功能

### 核心播放
- [x] **時移 (Time-Shift)**：基於 `catchup-source` 的回放式時移，支援即時拖動回看，快進快退限制在節目邊界內。
- [x] **EPG 電子節目單**：支援 XMLTV (gz) 解析與展示，支援央視/教育台頻道類型後綴。
- [x] **頻道回看**：基於模板自動生成回放 URL。
- [x] **M3U 解析**：支援本地/遠端清單及 `#EXTINF` 擴展屬性，支援 TXT 格式。
- [x] **M3U 二進制緩存**：ETag/Last-Modified 驗證的二進制緩存，毫秒級載入。
- [x] **頻道管理**：分組、搜尋、收藏功能，支援分組排序。

### 播放優化
- [x] **直播優化**：FCC 快速切台、UDP 組播優化、自動換源。
- [x] **硬體解碼**：預設開啟 `d3d11va`，支援多種解碼器選擇（D3D11VA/DXVA2/NVDEC/軟體）。
- [x] **多屏播放 (v1.1.9)**：支援 4/6/9 屏幕同時播放，1-9 數字鍵選擇，源切換。
- [x] **Web 遠端控制**：透過瀏覽器遠端控制播放器。

### 錄製功能
- [x] **本地錄製**：本地錄製、WebDAV 上傳、上傳佇列。
- [x] **預約錄製 (v1.1.9)**：前台/後台兩種預約錄製模式，錄製完成 Toast 通知。

### 介面與互動
- [x] **精簡模式**：精簡視窗、頂欄互動、視窗態/全螢幕態狀態同步。
- [x] **預約能力**：預約通知、預約列表、到點自動播放策略。
- [x] **UI/UX**：全螢幕懸浮控制、側邊抽屜、多語言支援（中/英/繁中/俄語）。
- [x] **快捷鍵**：完整的鍵盤快捷鍵支援，支援快捷鍵幫助窗口。
- [x] **設定窗口**：可調節大小，深/淺色模式配色優化。
- [x] **關閉模式記憶 (v1.1.9)**：記住用戶選擇（退出或最小化到系統匣）。

### v1.1.9 新功能
- 多屏播放：4/6/9 屏幕同時播放，1-9 選擇屏幕，↑↓ 切換頻道，←→ 切換源
- 系統匣多屏菜單：系統匣右鍵菜單添加多屏播放子菜單
- 預約錄製：前台/後台錄製模式，錄製完成 Toast 通知
- 解碼器選擇：自動/D3D11VA/DXVA2/NVDEC/軟體，播放時動態切換
- 快捷鍵幫助窗口：ShortcutsWindow 快捷鍵說明窗口
- 菜單系統重構：按功能域分類，TXT 格式支援
- 設定窗口重構：12 標籤整合為 7 標籤
- 時移增強：節目邊界內快進快退、連續播放、節目結束自動跳轉
- M3U 下拉刷新：添加新鏈接後自動刷新
- mpv 緩存優化：錄製狀態動態控制緩存

### v1.1.2+ 互動更新
- EPG 狀態晶片：直播=紅填充，回放=綠填充；點擊直播晶片即播放
- 當前播放識別：整行高亮；回放播放中左側綠色豎線
- 預約通知：列表單一實例、首次置中、勾選框批刪、系統匣/右鍵/下拉入口一致
- M3U 管理：批次刪除、單筆編輯、系統匣入口、全螢幕可見
- 系統匣常駐：打開/預約/管理 M3U/設定/退出
- 關閉確認：×/ESC 僅關閉對話框；「否」最小化系統匣（全螢幕先退出全螢幕）
- 深淺色標題列：預約列表、M3U 管理、預約提醒、退出框在建立後即時匹配主題
- 倍速控制：支援時移/回放的倍速播放（含 3×/5×），自動音高校正；直播不支援

## 預覽/實驗特性

- [~] 預約/通知動畫：樣式與動效方案已設計，後續版本開放
- [~] 回放晶片可點擊直達：交互評估中，計劃與「點擊節目標題回放」並存
