# EPG 節目單（使用與設定）

本頁說明如何在播放器中使用 EPG（節目單），以及 EPG 與「回看/時移」的關係。

## EPG 是什麼

EPG（Electronic Program Guide）是電視節目的時間表。播放器透過 EPG 取得：

- 每個頻道當前/已播/未播節目的時間段
- 「回看」所需的節目開始/結束時間（用於生成回放 URL）

## EPG 資料來源

播放器支援 XMLTV（含 `.gz`）格式的 EPG 位址。常見來源方式：

- **在 M3U 標頭提供** `x-tvg-url`：

```m3u
#EXTM3U x-tvg-url="http://example.com/e.xml"
```

- **在播放器設定中配置 EPG URL**（當 M3U 未提供或需要覆蓋時使用）

## 頻道如何與 EPG 對上（匹配優先級）

播放器採用**鏈式多級匹配**策略，按以下順序嘗試匹配：

### 匹配優先級（從高到低）

1. **tvg-id 精確匹配** — 直接用 M3U 的 `tvg-id` 與 EPG XML 的 `channel@id` 對應
2. **tvg-id 清理後匹配** — 去除 `-`、`_`、空格等特殊字符後再次匹配（如 `CCTV-1` 與 `CCTV1`）
3. **tvg-name 清理後匹配** — 用 M3U 的 `tvg-name` 與 EPG 的 `display-name` 進行清理後匹配
4. **channelName 清理後匹配** — 用 M3U 的頻道名稱（`display-name`）與 EPG 的 `display-name` 清理後匹配
5. **智慧模糊匹配（兜底）** — 處理 CCTV/衛視等常見命名差異

### M3U 中的相關屬性

```m3u
#EXTINF:-1 tvg-id="cctv1" tvg-name="CCTV" group-title="央視" ch-name="CCTV-1 綜合",http://example.com/stream
```

| 屬性 | 說明 |
|------|------|
| `tvg-id` | 頻道唯一識別碼，用於精確匹配 |
| `tvg-name` | 頻道名稱識別碼（獨立於顯示名稱） |
| `ch-name` 或逗號後 | 頻道顯示名稱 |

### 建議

- 盡量在 M3U 中填寫正確的 `tvg-id`（最準確的匹配方式）
- 同時填寫 `tvg-name` 可以提高匹配成功率
- 頻道顯示名稱保持與 EPG 中的標準名一致或接近

## 播放器內操作（查看節目單）

1. 選擇一個頻道並播放。
2. 打開 EPG 面板（左側節目單）。
3. 可切換日期查看不同天的節目。
4. 節目單會根據當前時間顯示「正在播放/即將播放/已播出」等狀態；右側使用**晶片式標識**：
   - 直播：紅色填充晶片；可點擊，等同於點擊頻道播放直播。
   - 回放：綠色填充晶片；點擊節目標題依模板生成回放 URL 並播放。
   - 預約：顯示「預約」按鈕（尺寸與圓角與晶片一致），僅未來節目出現；支援「僅提醒/自動播放」。
   - 正在播放：整行高亮；回放播放中左側有綠色豎線提示。

## EPG 時間軸（進度條）

視窗底欄與全螢幕浮層的進度條預設就是 **EPG 時間軸**：它不是一根光禿禿的滑桿，而是把當前頻道的節目單畫成一條帶節目名的時間軸。

![視窗底欄的 EPG 時間軸](../../screenshots/timeline-windowed-light.png)

![全螢幕浮層的 EPG 時間軸](../../screenshots/timeline-fullscreen-light.png)

### 介面元素

| 元素 | 說明 |
|------|------|
| 節目段 | 每個節目一個方塊，寬度按節目時長分配，名稱過長會截斷（滑鼠停留可看完整名稱）；正在播出的節目用綠色進度填滿表示已播部分 |
| 刻度尺 | 第一行是時間刻度，可直接點擊定位；滑鼠停留會顯示該位置的時間與命中的節目 |
| 狀態角標 | `直播` 跟隨直播邊緣、`回看` 是當前可點播的已播節目、`時移` 表示落在本次緩衝視窗內、`預約` 表示未來節目 |
| 播放頭 | 當前播放位置；時移時另有直播邊緣標記 |
| 翻頁 | 兩端的 ◀ / ▶ 按節目段前後翻頁，只移動瀏覽時段，不會跳轉播放 |

### 操作

| 操作 | 結果 |
|------|------|
| 點已播節目段 | 跳到該節目開頭播放（回看按回看位址重新請求，時移在本次工作階段內跳轉） |
| 點未來節目段 | 等同於節目單裡的「預約」按鈕，建立預約（僅提醒 / 自動播放） |
| 點刻度尺任意位置 | 跳到該時間點；當前不能回看/時移時忽略 |
| 拖動播放頭 | 連續跳轉；時移時會被限制在當前緩衝視窗內，不會請求還沒錄製到的時段 |
| 滑鼠停留 | 顯示虛線游標與氣泡（時間 + 節目名 + 提示） |

### 切換成標準進度條

設定 → **播放** → **進度條樣式**：

- **EPG 時間軸**（預設）：上面這條帶節目資訊的進度條
- **標準進度條**：只顯示一根進度條與已播/總時長，不顯示節目名與刻度，適合視窗較窄或不需要節目資訊時

![標準進度條](../../screenshots/seekbar-standard-light.png)

> 頻道沒有節目單時，視窗底欄會自動改用標準進度條。

## EPG 與回看/時移的關係

### 回看

- 回看是「基於節目單」的：點擊已播節目後，播放器使用該節目的開始/結束時間去替換 `catchup-source`（或全域模板）中的時間佔位符。
- 因此：EPG 越準確，回看越準確。

### 時移

- 時移的時間範圍與游標時間會受 EPG 的最早節目時間影響（用於限制可回退的最早邊界）。
- 當某時間點能命中節目單時，播放器會優先使用該節目的結束時間作為回放 URL 的結束時間；否則會使用預設時長兜底。

## 常見問題

- **有頻道但沒有節目單**：優先檢查 `tvg-id` 是否匹配，或 EPG 位址是否可訪問。
- **回看節目點開後時間不對**：多數是 EPG 時區/來源端要求的 UTC 與本地時間不一致，建議對照來源端要求調整 `catchup-source` 的時間格式（詳見 [回看與時移](./catchup-timeshift)）。
