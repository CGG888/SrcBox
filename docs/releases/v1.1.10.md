## Technical Details

### Fix 1: Multi-Screen Playback Freeze

**Root Cause:** `cache-pause-initial` was never set in code. mpv defaults to `"yes"`, which pauses playback when initial buffer runs low.

**Fix:** Added in `MpvPlayer.cs` Initialize():
```csharp
SetString("cache-pause", "no");
SetString("cache-pause-initial", "no");  // Key fix!
```

### Fix 2: Source Switching Not Working

**Root Cause:** Lambda captured `currentChannel` at menu open time, not click time.

**Fix:** Changed to use `PlaySourceByIndex()` which re-fetches channel at click time:
```csharp
var item = new ToolStripMenuItem(srcLabel, null, (s, e) => PlaySourceByIndex(screenIndex, sourceIdx));
```

### Fix 3: Reconnection Lost Source Selection

**Root Cause:** `PlayChannel()` always reset `_sourceIndexes[screenIndex] = 0`.

**Fix:** Added `ReconnectChannel()` that preserves the original source index:
```csharp
private void ReconnectChannel(int screenIndex, Channel channel, int sourceIndex)
{
    _sourceIndexes[screenIndex] = sourceIndex;  // Preserve selection
    ...
}
```
