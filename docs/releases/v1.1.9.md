# v1.1.9 Release Notes

> **Release Date:** 2026-08-08  
> **Previous Version:** [v1.1.8](./v1.1.8.md)

---

## New Features

| Feature | Description |
|---------|-------------|
| **Multi-Screen Playback** | 多屏播放支持 4/6/9 屏幕同时播放 |
| **Tray Multi-Screen Menu** | 托盘右键菜单添加多屏播放子菜单 |
| **Multi-Screen Source Switching** | 多屏播放支持切换源子菜单和快捷键 (↑↓频道，←→源) |
| **Scheduled Recording** | 支持前台/后台两种预约录制模式 |
| **Recording Toast** | 录制完成时显示 Toast 通知 |
| **Front Recording Timer** | 支持自定义时长自动停止前台录制 |
| **Recording List Filter** | 录制列表窗口添加状态筛选下拉框 |
| **Reminder Refresh Button** | 预约列表窗口添加刷新按钮 |
| **M3U Dropdown Auto-Refresh** | 添加新链接后频道列表下拉框自动刷新 |
| **Dynamic Cache Control** | 根据录制状态动态控制 mpv 缓存大小 |
| **Decoder Selection** | 添加解码器选择菜单（自动/D3D11VA/DXVA2/NVDEC/软件），支持播放时动态切换 |
| **Shortcuts Help Window** | 新增快捷键说明窗口 (ShortcutsWindow) |
| **Menu System Refactoring** | 重构菜单系统：按功能域分类，新增 TXT 格式支持 |
| **Settings Window Refactoring** | 设置窗口重构：12 标签整合为 7 标签，优化深色/浅色模式配色 |
| **Top Menu i18n** | 顶部菜单国际化：修复缺失的菜单国际化 key |
| **Timeshift Improvements** | 时移功能增强：快进快退限制在节目边界内、连续播放、节目结束自动跳转下一节目 |
| **EPG Matching** | 扩展 EPG 匹配规则支持央视/教育台频道类型后缀 |
| **Close Mode Memory** | 统一关闭行为：支持记住用户选择（退出或最小化到托盘），添加"清除关闭记忆"选项 |

---

## Performance Improvements

| Optimization | Impact |
|--------------|--------|
| **mpv Cache Optimization** | 根据录制状态动态调整缓存大小，减少内存占用 |

## Bug Fixes

| Issue | Fix |
|-------|-----|
| [#29](https://github.com/CGG888/SrcBox/issues/29) - 频道分组排序功能 | 添加频道分组排序功能 |
| [#34](https://github.com/CGG888/SrcBox/issues/34) - 央视台EPG节目名不显示 | 扩展 EPG 匹配规则支持央视类型后缀 |
| [#35](https://github.com/CGG888/SrcBox/issues/35) - 关闭模式记忆 | 统一关闭行为，支持记住关闭模式 |
| 多屏幕全屏时快捷键失效 | 打开多屏后自动选中第一个屏幕 |
| 深色模式托盘菜单文字颜色 | 修复深色模式下托盘菜单文字颜色显示问题 |
| 托盘菜单语言同步 | 更改语言后无需重启即可生效 |
| 频道去重源丢失 | 频道按名称去重时合并多个源 |
| 源列表 URL 解析失败 | 修复 IptvCheckerClient 无法解析字符串格式 URL |
| 预约列表不自动刷新 | 从 EPG 添加预约后列表自动刷新 |
| M3U 下拉不显示新链接 | 添加链接后下拉框自动刷新 |
| 前台录制可停止性 | 确保可从预约列表停止前台录制 |
| 录制时长计算 | 使用 EPG 节目结束时间作为默认录制时长 |
| 预约录制状态更新延迟 | 在启动流之前更新预约录制状态为 Recording |
| 预约录制属性通知 | 修复 ScheduledRecordingInfo 实现 INotifyPropertyChanged |
| 预约录制列表筛选 | 修复只显示录制项目而非全部项目 |
| 后台录制自动跳转 | 防止后台录制触发时跳转到对应频道 |
| 前台录制计时器 | 改善前台录制自动停止计时器逻辑 |
| 预约录制完成模式 | 设置正确的录制完成模式按钮文本 |
| 时移模式左右快捷键失效 | 修复时移模式下左右快捷键 seek 不生效的问题 |
| 时移范围被 EPG 数据覆盖 | 修复时移范围被 EPG 数据覆盖的问题 |
| 时移快进快退边界限制 | 时移快进快退移除节目边界限制，连续播放不受节目边界影响 |
| 时移节目结束停止 | 时移连续播放时 URL 结束时间改为遥远未来，避免在节目结束时停止 |
| 时移结束时间不合理 | 时移结束时间改为当前时间，更加合理 |
| 时移时间格式 | 改用 start_time+end_time 格式替代 duration 格式 |
| EPG 调试日志重复 | 优化 EPG 调试日志：日期日志只在变化时输出，避免重复 |

## User Interface

### Window Layout Optimization
- 多屏播放支持 1-9 数字键快速选择屏幕
- ↑↓切换频道，←→切换源
- 托盘右键菜单添加多屏播放子菜单 (4/6/9 屏幕)
- 托盘菜单支持深色/浅色模式自动同步

### Menu System Refactoring
- 按功能域分类重构顶部菜单结构
- 新增 TXT 格式支持
- 修复菜单国际化 key 缺失和重复问题

### Settings Window Refactoring
- 12 标签整合为 7 标签，简化界面
- 优化深色/浅色模式配色
- 统一字体大小
- 调整输入框和下拉框样式

### Player UI Improvements
- 统一按钮尺寸为 24x24，图标为 12x12 Viewbox+Path
- 切换源和画面比例改为文字按钮（避免 Path 图标解析错误）
- 同步窗口/全屏模式按钮状态和图标颜色
- 添加 OverlayToggle 高亮样式
- 修复窗口模式播放按钮图标不更新问题
- 静音图标前景色支持主题动态切换
- 视频标签字体大小调整为 10
- 添加视频编码缩写显示 (MPEG-1/2, VP8/9, AV1, WMV)
- 退出精简模式时恢复窗口宽度
