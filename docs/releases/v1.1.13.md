# v1.1.13 Release Notes

> **Release Date:** 2026-10-03
> **Previous Version:** [v1.1.12](https://github.com/CGG888/SrcBox/releases#release-v1.1.12)

---

## Highlights

本次版本集中修复**回看 / 时移**整条链路（起播、左右键定位、进度条时间、占位符方言），并补齐社区反馈中的字幕轨选择、逐源 EPG 绑定、台标命中率、多屏 DPI 与 rtp2httpd 时区适配。

---

## New Features

| Feature | Description |
|---------|-------------|
| **内嵌字幕轨选择** | 视频菜单新增「字幕」子菜单，列出流内的所有内嵌字幕轨（标题 · 语言 · 编码），可随时切换或关闭 (#35) |
| **逐播放列表绑定 EPG** | 每个 M3U 源可单独指定 EPG 地址，加载该源时优先使用它，未配置则回落到全局列表 (#38) |
| **多 EPG 源合并** | 支持配置多个 EPG 地址并合并成一份节目单，先配置的源优先 (#38) |
| **rtp2httpd 时区标记** | 设置中可让请求携带 `TZ/UTC+N`，rtp2httpd 按其时区解释 epg/playseek 时间；也可直接指定 User-Agent (#13) |
| **附加播放查询参数** | 可把 `r2h-seek-mode=range(UTC+8/3600)` 等参数附加到直播/回看地址，适配不同代理方言 (#13) |
| **窗口尺寸与位置记忆** | 记住主窗口的大小与位置，下次启动恢复 |
| **面板状态记忆** | 记住频道列表与 EPG 面板的开合状态 |
| **精简模式** | 窗口宽度按播放区计算（不因面板变化而累加），面板入口在精简模式下隐藏，保留顶部悬浮标题栏 |
| **快速换台 (Fast Zap)** | 基于 mpv playlist 预取的快速换台，带防抖与队列合并 |
| **源健康扫描** | 仅扫描当前播放频道的源，可开关并设置并发数，避免长时间扫描卡顿 |

## Bug Fixes

| Issue | Fix |
|-------|-----|
| #13 时移起播失败 / 时间不对 | 时间改写器不再无条件把地址改写成"本地 14 位 starttime/endtime"，保留频道自带模板（UTC `T` 分隔、playseek 等）；进入时移会真正切到回看流 |
| #35 回看时左右键不移动时间 | 回看 seek 重新请求"新起点"的回看地址；进度条改按节目区间显示（左端为节目内位置、右端为该节目总时长，不再越按越短） |
| #35 内嵌字幕无法选择 | 新增字幕轨菜单（见上） |
| #36 全屏边缘热区被副屏误触发 | 忽略不在全屏窗口所在显示器与矩形内的光标位置 |
| #37 中文路径 / rtp2httpd 源无法播放 | 发送给 libmpv 的地址统一 UTF-8 编码 |
| #38 EPG 只能配置一个 | 多 EPG 合并 + 逐播放列表绑定 |
| #39 txt 源分组丢失 | 解析 `#genre#` 分组与 `#EXTGRP`，txt 列表也能按分组展示 |
| #39 台标模板不生效 | 台标模板在所有分支生效（含已有 logo 字段的列表），并对名称做 URL 转义 |
| #39 台标大量 404 | 模板改用"清洗名"（`CCTV-1 HD` → `CCTV1`、`湖南卫视高清` → `湖南卫视`、去空格、`PLUS` → `+`），失败再按原名尝试；失败结果负缓存，滚动列表不再反复请求 |
| 面板开合导致窗口越来越宽 | 播放区宽度固定为基准，面板宽度叠加在其上，不再累积 |
| 菜单切换频道列表不调整窗口宽度 | 面板标志无论从按钮、菜单还是快捷键变化，都统一重算窗口尺寸 |
| 中文输入法下快捷键失效 | 规范化 IME 处理过的按键，E/L/空格等快捷键恢复 |
| 预约提醒看不到执行情况 | 预提醒 / 已触发 / 已错过事件提升为 Info 日志，正常日志即可看到 |
| 回看占位符不全 | 支持 `${(b)yyyyMMdd|UTC}`、`${utc:...}`、`:utc`、`{utc}`、`${start}` 等方言 (#13) |

## Improvements

- **DPI**：新增 `app.manifest` 声明 PerMonitorV2，多显示器不同缩放下窗口几何与全屏热区更准确 (#36)
- **日志**：回看/时移 seek 会记录模式、位置、锚点与重发地址，便于定位源端问题
- **测试**：新增回看/时移集成测试、占位符、窗口布局、面板状态、字幕轨、查询参数等 20+ 用例；修复 2 个长期失败的陈旧测试

---

## Known Issues

- rtp2httpd 的时区标记在程序启动时写入 mpv，修改后需**重启程序**生效；"附加播放查询参数"立即生效
- 各源的 `playseek` 方言差异较大，若某源回看仍异常，可用"附加播放查询参数"适配
