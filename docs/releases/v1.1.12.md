# v1.1.12 Release Notes

> **Release Date:** 2026-08-17
> **Previous Version:** [v1.1.11](https://github.com/CGG888/SrcBox/releases#release-v1.1.11)

---

## New Features

| Feature | Description |
|---------|-------------|
| **Web Remote M3U Source Switching** | Web 遥控器频道列表支持切换 M3U 源列表，与播放器下拉列表同步 |
| **Web Remote Source Health Indicators** | 频道卡片显示源健康状态（绿色/黄色/红色椭圆指示器） |
| **Web Remote Channel Cards** | 频道列表显示 Logo + 频道名 + 当前节目名称 |
| **Debug Menu Fix** | 修复右键-应用-调试菜单点击无效的问题 |

---

## Web Remote Improvements

### Channel List Enhancements
- 频道卡片显示 Logo（矩形 56px 高，自动宽度）+ 频道名称 + 当前节目
- Logo 加载本地缓存文件，通过 `/logo/` HTTP 端点访问
- 无 Logo 时显示 TV 图标，与 Logo 区域对齐
- 频道列表改为单列显示，完整展示节目信息
- 支持 M3U 源列表切换，下拉框显示在频道列表顶部

### Source Management
- 源列表弹窗居中显示
- 支持深色/浅色模式自动切换
- 显示当前选中的 M3U 源
- 切换源后频道列表同步刷新

### EPG Improvements
- Web 端 EPG 节目匹配修复，正确传递 tvgName 参数
- 支持显示下一节目（当无当前节目时）
- EPG 同步添加详细日志记录

---

## Bug Fixes

| Issue | Fix |
|-------|-----|
| Web EPG 节目不显示 | 修复 GetCurrentProgram 未传递 tvgName 导致 EPG 匹配失败 |
| 频道 Logo 不显示 | 添加 `/logo/` HTTP 端点服务本地缓存 Logo 文件 |
| Logo 加载失败无后备 | 添加 TV 图标后备显示，与 Logo 区域对齐 |
| 调试菜单点击无效 | 启用右键应用菜单的调试窗口菜单项 |
| Web 状态每 5 秒刷新 | 修复状态区域不必要的自动刷新 |

## User Interface

```
┌─────────────────────────────────────┐
│ [Logo]  频道名称                     │
│         当前节目名称                  │
└─────────────────────────────────────┘
```

- TV 后备图标：80px × 56px，与 Logo 对齐
