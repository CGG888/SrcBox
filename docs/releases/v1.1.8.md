# v1.1.8 Release Notes

Release Date: 2026-07-31

## New Features

- **M3U Binary Cache Support** - Add binary cache for M3U playlists to improve loading performance
- **Channel List M3U Dropdown Selection** - Added dropdown selector for M3U sources in channel list
- **Group Page Search Bar Reuse** - Search bar is now reused across group pages
- **Recording Filter by JSON** - Added JSON-based filtering for recordings
- **Startup Optimization** - Improved application startup time

## Performance Improvements

- **Brotli Compression Support** - Enabled Brotli compression for better network efficiency
- **Span Parsing + Channel Object Pool** - Optimized parsing with Span<T> and object pooling
- **Progressive Loading** - Channels display first, then filter conditions are calculated
- **String.Intern Optimization** - Reduced memory footprint by interning strings
- **Batch Channel List Updates** - Fixed UI lag with batched UI updates
- **Logo Cache Improvements** - Optimized logo caching mechanism

## Bug Fixes

- Fixed window positioning error in multi-monitor fullscreen playback
- Fixed URL encoding loss issue with Uri.ToString()
- Fixed EPG not loading when M3U is loaded from cache at startup
- Fixed EPG matching parameter errors
- Fixed WebSocket handshake response missing Sec-WebSocket-Version: 13 header
- Fixed GDI icon resource leak (using DestroyIcon to release resources)
- Fixed debug window loading entire log files at once (now uses streaming load)

## User Interface

- **Window Layout Optimization**:
  - EPG and channel list align with bottom control bar
  - Video area maintains fixed dimensions
  - Window auto-expands when sidebar is opened
  - Adjusted window size to 1024x768

## Build & Release

- **GitHub Actions Release Workflow** - Automated build and release process
- **Inno Setup 6.7.3** - Using latest Inno Setup with full language support
- **English-Only Installer** - Simplified installer language to English only
- **Fixed libmpv-2.dll URL** - Corrected download URL for libmpv DLL
