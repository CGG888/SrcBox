# v1.1.8 Release Notes

> **Release Date:** 2026-07-31  
> **Previous Version:** [v1.1.7](./v1.1.7.md)

---

## New Features

| Feature | Description |
|---------|-------------|
| **M3U Binary Cache** | 新增 M3UCacheService，支持 ETag/Last-Modified 验证的二进制缓存，缓存命中加载速度从 3-10s 降至毫秒级 |
| **Channel List M3U Dropdown** | 频道列表添加 M3U 下拉选择，方便切换不同源 |
| **Group Page Search Reuse** | 分组页面复用搜索栏，提升用户体验 |
| **Recording JSON Filter** | 录播过滤支持 JSON 格式配置 |
| **Startup Optimization** | 优化启动流程，减少启动时间 |

---

## Performance Improvements

| Optimization | Impact |
|--------------|--------|
| **Brotli Compression** | 启用 Brotli 压缩支持，提升网络传输效率 |
| **Span Parsing + Object Pool** | 使用 Span<T> 解析和 Channel 对象池优化内存分配 |
| **Progressive Loading** | 渐进式加载：先显示频道列表，再计算过滤条件 |
| **String.Intern** | 使用 string.Intern 减少字符串重复占用内存 |
| **Batch UI Updates** | 批量更新频道列表，解决 UI 卡顿问题 |
| **Logo Cache** | 优化 Logo 缓存机制 |
