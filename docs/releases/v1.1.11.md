# v1.1.11 Release Notes

> **Release Date:** 2026-08-10
> **Previous Version:** [v1.1.10](https://github.com/CGG888/SrcBox/releases#release-v1.1.10)

## New Features

| Feature | Description |
|---------|-------------|
| **Channel Preview** | 鼠标悬停频道显示实时预览快照，基于 rtp2httpd X-Request-Snapshot，需要在设置中开启 |
| **RTP Direct Address** | 支持 rtp://@host:port 原始 UDP 组播地址播放，优化 rtp-max-dropout/rtp-max-misorder 参数 |

## Performance Improvements

### Player Buffering & Async
| Optimization | Impact |
|--------------|--------|
| **ConfigureAwait(false)** | 所有服务层 await 添加 ConfigureAwait(false)，减少 UI 线程上下文切换 |
| **Thread.Sleep → Task.Delay** | MpvPlayerEngineAdapter 频道切换 80ms 阻塞改为异步等待 |
| **ReminderService 定时器** | 定时器回调中的同步阻塞调用改为异步处理，避免线程池饥饿 |
| **App 启动/关闭** | 启动关闭流程改为真正的异步，避免 UI 线程阻塞 |
| **M3U Cache Write** | 缓存写入从串行改为并行（Task.WhenAll） |
| **EpgService SmartMatch** | Dictionary+lock 改为 ConcurrentDictionary，支持真正的并发读取 |
| **Fire-and-forget 异常** | LogoCacheService、PluginManager、MainShellViewModel 的 fire-and-forget 添加 try-catch 和日志 |

### Network & Connection
| Optimization | Impact |
|--------------|--------|
| **Connection Preheater** | DNS 预取和连接预热从串行改为并行，频道列表加载提速 |
| **ConnectionPreheater Timeout** | 预热超时从 3s 增加到 5s，减少慢网误判 |
| **HttpClientExtensions** | 直连失败时不再抛代理异常，真实错误更清晰 |
| **UrlTimeRewriter Regex** | 正则表达式优化，减少正则回溯 |

### Media & Cache
| Optimization | Impact |
|--------------|--------|
| **MediaProbeService** | 固定 600ms 等待改为轮询检测，减少不必要的等待 |
| **RegistryProxyProvider** | 注册表代理缓存，避免重复查询 |
| **MpvPlayer Error** | 去交织/音频设置失败时添加日志，不再静默吞掉 |
| **MediaProbeService** | 探针失败时添加日志，不再静默返回 null |

## Bug Fixes

| Issue | Fix | Ref |
|-------|-----|-----|
| ChannelService 静默失败 | 网络故障时用户看到空列表无提示 → 添加错误日志和重试 | NEW-17 |
| TxtParser 无重试 | TXT 格式播放列表下载无容错 → 添加带重试的获取方法 | NEW-18 |
| 流播放零重试 | mpv 加载流无重试逻辑 → 添加播放失败重试机制 | NEW-19 |
| SourceTimeoutSec 过短 | 3s 默认对部分流过短 → 提高默认值为 5s | NEW-24 |
| AsyncImageConverter 阻塞 | .Result 阻塞等待 HTTP → 改为 async/await | NEW-10 |
| EPG 日志重复 | 调试日志按日期重复输出 → 只在日期变化时输出 | #34 |
| 频道去重源丢失 | 按名称去重时多个源被丢弃 → 合并多个源到去重列表 | #34 |
| WebRemote 死锁风险 | lock 内调用 ws.SendAsync → 改为异步发送 | NEW-13 |
| UploadQueueService I/O | lock 内同步 Save() → 改用 SemaphoreSlim | NEW-11 |
