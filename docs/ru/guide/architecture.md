# Архитектура

Проект разработан на **C# / WPF**, основная архитектура следующая:

- **UI слой**: Основан на WPF (ModernWpf), обеспечивает плавный современный интерфейс.
- **Архитектурный слой**: `Architecture/` разделен на Application / Platform / Presentation, модули воспроизведения, настроек и синхронизации.
- **Слой взаимодействия**: Инкапсулирует libmpv через `MpvPlayer.cs` и `MpvPlayerEngineAdapter`.
- **Слой рендеринга**: Использует `WindowsFormsHost` для размещения Win32, встраивая вывод mpv в интерфейс WPF.
- **Сервисный слой**:
  - `M3UParser`: Высокопроизводительный парсер на регулярных выражениях для M3U.
  - `EpgService`: Асинхронная загрузка и кэширование EPG на основе `XmlSerializer`.
  - `RecordingIndexService / UploadQueueService / WebDavClient`: Индексация, очередь загрузки и удалённое хранилище.
  - `ReminderService`: Напоминания и планирование.

## Структура проекта

Подробная структура проекта доступна в [Полной архитектурной документации](/ARCHITECTURE.md).

```text
📂 SrcBox
├── 📂 Architecture    # Архитектура (Application/Platform/Presentation)
├── 📂 Services        # Сервисы (M3U/EPG/Запись/WebDAV/Уведомления)
├── 📂 Controls        # Элементы (EPG/Запись/Таймшифт/Очередь загрузки)
├── 📂 Resources       # Локализация и темы
├── 📂 Tests           # MSTest
├── 📄 MainWindow.*.cs # Главное окно
└── 📄 MpvPlayer.cs    # Обертка libmpv
```

## Ключевые модули

- **Модуль напоминаний**: `ReminderService` + `ScheduledReminder`, поддержка стратегий "только напомнить/автозапуск".
- **Модуль записи**: `MainWindowRecordingManager` управляет началом/остановкой записи, метаданными.
- **Модуль загрузки**: `UploadQueueService` + `WebDavClient` для очереди и повтора ошибок.
- **Минимальный режим**: Координация состояний окна и Overlay.

## Движок libmpv

Проект зависит от `libmpv-2.dll`.

- **Аппаратное декодирование**: По умолчанию включено `d3d11va`.
- **Проблема со звуком**: Для медленных источников установлено `probesize=32` для ускорения.
