# Предпросмотр канала

При наведении курсора мыши на канал в списке каналов появляется всплывающее окно с мгновенным снимком, позволяющим быстро просмотреть содержимое перед переключением канала.

![Предпросмотр канала](/screenshots/videosnapshot.png)

## Предварительные требования

Функция предпросмотра канала зависит от HTTP-заголовка `X-Request-Snapshot` в **rtp2httpd**.

Убедитесь, что в rtp2httpd включена поддержка снимков:

```bash
rtp2httpd --enable-snapshot
```

## Функции

- **Мгновенное отображение**: При наведении мыши на элемент списка каналов снимок сразу появляется слева
- **Не мешает воспроизведению**: Снимок отображается только при наведении, автоматически закрывается при двойном щелчке для воспроизведения канала
- **Настраиваемый размер**: По умолчанию 214×120 (16:9), можно изменить в настройках
- **LRU-кэш**: Кэш 30 секунд, повторные запросы одного канала не повторяются в течение 30 секунд
- **Контроль параллелизма**: Максимум 2 параллельных запроса снимков во избежание перегрузки rtp2httpd

## Настройки

На странице **Настройки → Каналы**:

1. Установите флажок **Предпросмотр канала** для включения функции (по умолчанию выключено)
2. При желании измените **Ширину** и **Высоту** (минимум 80×60)
3. Рекомендуется сохранять соотношение 16:9

## Принцип работы

Функция реализована путём отправки HTTP-запроса с заголовком `X-Request-Snapshot: 1` к rtp2httpd для генерации снимка, который возвращается в формате JPEG. SrcBox обеспечивает плавный опыт:

- Асинхронные запросы снимков, не блокирующие UI-поток
- Кэширование в памяти, возврат кэшированных результатов для повторных запросов в течение 30 секунд
- Максимум 2 параллельных запроса для предотвращения перегрузки rtp2httpd

## Сценарии использования

- **Просмотр каналов**: Быстрый просмотр нескольких каналов без воспроизведения
- **Переключение каналов**: Предпросмотр содержимого целевого канала перед переключением
- **Мониторинг на нескольких экранах**: Наведение для предпросмотра текущего кадра любого канала в мультиэкранном режиме
