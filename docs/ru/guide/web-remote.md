# Веб-пульт дистанционного управления

SrcBox предоставляет функцию веб-пульта дистанционного управления, позволяющую удалённо управлять плеером через браузер, включая управление воспроизведением, регулировку громкости, переключение каналов, возврат к эфиру, планирование записей и многое другое.

## Обзор функций

Веб-пульт работает на основе протоколов WebSocket и HTTP и поддерживает следующие функции:

- **Управление воспроизведением**: Воспроизведение, Пауза, Остановка
- **Контроль прогресса**: Перемотка вперёд, назад, Поиск
- **Регулировка громкости**: Изменение громкости, Отключение звука
- **Переключение каналов**: Предыдущий/Следующий канал, Список каналов, Поиск каналов
- **Возврат к эфиру**: Таймшифт, Воспроизведение передачи
- **Планирование**: Напоминания, Запись по расписанию (передняя/фоновая)
- **Управление источниками**: Добавление, выбор, удаление источников воспроизведения
- **Просмотр статуса**: Текущий статус воспроизведения, Информация о программе, Телепрограмма
- **Многоязычная поддержка**: Китайский, Английский, Русский, Традиционный китайский
- **Переключение интерфейса**: Переключение между стандартным пультом и полным интерфейсом одним нажатием, выбор запоминается автоматически
- **Переключение каналов цифрами**: В стандартном пульте можно ввести номер канала для переключения, список каналов показывает номера
- **Доступ по QR-коду**: В настройках отображаются QR-код и ссылка для доступа; отсканируйте код телефоном или скопируйте ссылку, чтобы открыть
- **Доступ по HTTPS**: Один порт обслуживает и http, и https; встроенный самоподписанный сертификат можно установить на телефон
- **Установка на главный экран**: Пульт устанавливается как PWA и открывается на весь экран в отдельном окне

## Включение удалённого управления

1. Откройте окно настроек SrcBox
2. Перейдите на вкладку **Веб-пульт** (в настройках это отдельная вкладка)
3. Установите флажок **Включить веб-пульт**; изменения вступают в силу сразу, перезапуск не требуется
4. (Необязательно) Установите порт доступа (по умолчанию 8899)
5. (Необязательно) Включите защиту паролем и задайте пароль
6. Нажмите кнопку **Сохранить**

## Доступ к удалённому управлению

После включения откройте в браузере:

```
http://localhost:8899
```

Для локального доступа используйте `localhost`. Для удалённого доступа в локальной сети замените `localhost` на IP-адрес компьютера с SrcBox, например:

```
http://192.168.1.100:8899
```

Тот же порт обслуживает и HTTPS (сервер различает протоколы по первому байту), поэтому после установки сертификата можно открыть `https://192.168.1.100:8899` — см. раздел [HTTPS и сертификаты](#https-и-сертификаты) ниже.

### Доступ по QR-коду

После включения на вкладке **Веб-пульт** в окне настроек отображаются текущий адрес доступа и QR-код:

- Отсканируйте QR-код камерой телефона или браузером, чтобы открыть пульт
- Нажмите **Копировать ссылку**, чтобы скопировать адрес доступа
- Когда сертификат готов, QR-код и ссылка ведут на **HTTPS-адрес** (`https://<IP-ПК>:<порт>`; при первом открытии на телефоне сначала нужно установить сертификат); на HTTP-адрес они переключаются только тогда, когда сертификат недоступен
- На вкладке также отображаются **адрес для установки сертификата**, состояние сертификата (включая дату истечения) и кнопка **Перегенерировать сертификат**
- QR-код и ссылка обновляются автоматически при изменении порта; если адрес в локальной сети не найден, проверьте подключение к сети

### HTTPS и сертификаты

Веб-пульт использует **один порт** для HTTP и HTTPS: один и тот же порт принимает и `http://`, и `https://` (сервер смотрит на первый байт и определяет, начинается ли соединение с TLS-рукопожатия), поэтому отдельный порт для HTTPS настраивать не нужно.

Зачем HTTPS:

- Браузер предлагает «Установить приложение» (PWA) и service worker только в защищённом контексте (`https://` или `localhost`); если открыть страницу как `http://192.168.x.x` на телефоне, установить пульт как приложение не получится
- Открытый HTTP-трафик в локальной сети могут прослушивать другие устройства; HTTPS шифрует трафик

При первом включении SrcBox **создаёт** самоподписанный корневой сертификат и сертификат сервера в `%LOCALAPPDATA%\SrcBox\webremote-certs` (корневой действует 10 лет; сертификат сервера — 397 дней и продлевается за 30 дней до истечения). Создавать что-либо вручную не нужно.

Когда телефон открывает `http://192.168.1.100:8899`, кнопка **Установить** на странице сообщает, что соединение идёт по открытому http, и предлагает скачать сертификат:

| Адрес | Файл | Назначение |
|:---|:---|:---|
| `/cert` | `srcbox-ca.crt` (DER) | Установка как доверенного корневого сертификата на Android и Windows |
| `/cert.pem` | `srcbox-ca.pem` | Текстовый формат для сборок Android, которые не читают `.crt` |
| `/cert.mobileconfig` | `srcbox-ca.mobileconfig` | Профиль для iPhone, установка в один шаг |

**Установка сертификата на Android**: Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС → выберите скачанный `srcbox-ca.crt` (если не читается — `.pem`).

**Установка сертификата на iOS**: установите скачанный профиль, затем включите полное доверие для сертификата SrcBox в разделе Настройки → Основные → Об этом устройстве → Настройки доверия сертификатам.

После установки сертификата нажмите **Открыть по HTTPS** в окне (переход на `https://192.168.1.100:8899/`) либо просто замените схему в адресной строке на `https://`.

Можно обойтись и без сертификата: на Android откройте меню браузера → «На главный экран», а затем нажмите кнопку полного экрана (⛶) в шапке; на iOS — «Поделиться» → «На экран Домой», страница откроется на весь экран (сертификат в iOS не требуется). Разница только в том, что такой ярлык не является настоящей установкой PWA.

**Удаление сертификата**: на iPhone удалите профиль SrcBox в разделе «Настройки → Основные → VPN и управление устройством», затем отключите полное доверие в разделе «Настройки доверия сертификатам»; на Android удалите сертификат SrcBox в разделе «Настройки → Безопасность → Шифрование и учётные данные → Доверенные сертификаты → Пользователь»; в Windows удалите SrcBox в `certmgr.msc` в разделе «Доверенные корневые центры сертификации». После удаления нужно снова пользоваться `http://` или установить сертификат заново. Кнопка **Перегенерировать сертификат** на странице настроек выпускает новую пару сертификатов, старые сразу становятся недействительными, и на телефоне сертификат нужно установить заново.

### Доступность HTTPS и продление сертификата

- **Самопроверка при запуске**: при старте SrcBox выполняет одно TLS‑рукопожатие с самим собой по loopback‑адресу. Только если HTTPS действительно работает, страница и QR‑код выдают адрес `https://`. Если HTTPS в текущем окружении невозможен (например, процесс ограничен политикой безопасности или каталог сертификатов недоступен для записи), страница и QR‑код автоматически переходят на `http://`, а загрузка сертификата (`/cert`, `/cert.pem`, `/cert.mobileconfig`) остаётся доступной — телефон больше не получит адрес `https://`, который не открывается.
- **Автоматическое продление после смены сети**: в сертификате сервера перечислены текущие адреса сетевых адаптеров (SAN). При смене IP (продление аренды DHCP, переход на другой Wi‑Fi или Ethernet) SrcBox **перевыпускает сертификат сервера** для нового списка адресов без перезапуска, и телефон перестаёт показывать `ERR_CERT_COMMON_NAME_INVALID`; корневой сертификат не меняется, установленный на телефоне CA продолжает работать.
- **Для голосового управления нужен HTTPS**: микрофон телефона доступен только в защищённом контексте (`https://` или `localhost`). По `http://192.168.x.x` страница сообщает, что контекст не защищён, и панель голосового управления не может записывать — установите сертификат, как описано выше, и откройте страницу по `https://`.

### Установка на главный экран (PWA)

Страница пульта — это PWA (`manifest.json` + service worker), её можно установить на главный экран телефона и открывать на весь экран как обычное приложение:

- **Android (Chrome / Edge)**: в защищённом контексте (https или localhost) на странице появляется кнопка **Установить**; нажмите её и выберите «Установить приложение». Если браузер не предлагает установку, откройте меню браузера → «Установить приложение» или «На главный экран»
- **iOS (Safari)**: нажмите «Поделиться» → «На экран Домой»; это единственный способ установки в iOS
- В режиме отдельного окна (standalone) кнопка установки больше не показывается; после выбора «Больше не показывать» она тоже скрывается
- После установки пульт открывается в отдельном окне без адресной строки; кнопка полного экрана (⛶) в шапке работает и по обычному http

## Описание интерфейса

Кнопка в правом верхнем углу переключает между двумя интерфейсами, выбор сохраняется в браузере:

- **Стандартный пульт**: Удобная для вертикального экрана телефона раскладка пульта (кнопки направления, цифровые кнопки, кнопки громкости, переключение источника/без звука)
- **Полный интерфейс**: Полная страница со статусом, управлением воспроизведением, списком каналов, телепрограммой и управлением источниками (по умолчанию)

### Стандартный пульт

| Кнопка | Функция |
|--------|---------|
| ▲ Предыдущий канал | Переключить на предыдущий канал |
| ▼ Следующий канал | Переключить на следующий канал |
| ◀ Предыдущий источник | Переключить на предыдущий источник |
| ▶ Следующий источник | Переключить на следующий источник |
| OK | Переключение воспроизведения / паузы |
| Громкость − / Громкость + | Уменьшить / увеличить громкость на 5 |
| Цифровые кнопки 0-9 | Ввод номера канала, до 3 цифр, автоматическое переключение через 1.2 с после остановки ввода |
| ⌫ | Очистить введённый номер |
| ✓ | Немедленно переключить на введённый канал |
| Переключить источник / Без звука | Переключить источник / переключить без звука |
| Полный экран / Закрыть | Переключить полноэкранный режим / закрыть плеер |

Интерфейс выполнен в стиле неоморфизма (Neumorphism): по умолчанию светлый, кнопка 🌙 / ☀️ в правом верхнем углу переключает на тёмный неоморфный стиль.

### Область статуса

- Текущий режим воспроизведения (Прямой эфир/Возврат/Таймшифт/Запись/Остановлен)
- Название и логотип текущего канала
- Название и время текущей программы

### Область управления воспроизведением

| Кнопка | Функция |
|--------|---------|
| Полный экран | Переключение полноэкранного режима |
| Воспроизведение | Начать воспроизведение |
| Пауза | Приостановить воспроизведение |
| Стоп | Остановить воспроизведение |
| Без звука | Переключение звука |
| Предыдущий канал | Переключить на предыдущий канал |
| Следующий канал | Переключить на следующий канал |
| Переключить источник | Переключить источник воспроизведения |
| Выход | Закрыть плеер |
| Обновить | Обновить данные статуса |

### Область быстрого управления

| Кнопка | Функция |
|--------|---------|
| Таймшифт | Включить/выключить режим таймшифта для текущего канала; состояние кнопки синхронизируется со статусом плеера |
| -10с | Перемотка на 10 секунд назад |
| +10с | Перемотка на 10 секунд вперёд |

### Область регулировки громкости

- Ползунок громкости: Регулировка уровня громкости
- Кнопка без звука: Переключение звука

### Список каналов

- Отображение всех доступных каналов и избранного
- Нажмите название канала для переключения
- Избранные каналы отображаются вверху списка со звездочкой
- Каждый канал отображает свой номер; номера идут непрерывно в порядке групп плейлиста и не сбрасываются внутри группы, соответствуя цифровым кнопкам стандартного пульта один к одному (избранные каналы используют номер своей группы)

### Телепрограмма (EPG)

- Отображение списка программ текущего канала (по умолчанию сегодняшние)
- Нажмите на программу для возврата к эфиру
- Поддерживаются три кнопки действий:
  - **Смотреть** (красная): сразу перейти на этот канал и смотреть текущую передачу
  - **Повтор** (фиолетовая): воспроизвести прошедшую передачу на канале, поддерживающем catch-up или таймшифт
  - **Напоминание** (синяя): поставить напоминание о передаче

### Значки программ

| Значок | Цвет | Значение |
|--------|------|----------|
| LIVE | Красный | Прямой эфир |
| Повтор | Фиолетовый | Текущий повтор |
| Напоминание | Синий (`#1e90ff`) | Напоминание установлено |

### Голосовое управление (офлайн)

Кнопка **микрофона** на странице открывает панель «Голосовое управление»:

![Панель голосового управления](../../screenshots/web-remote-voice-light.png)

- Нажмите большую кнопку микрофона, чтобы начать говорить, и ещё раз — чтобы закончить; **запись идёт на телефоне** (16 кГц, моно), фрагменты загружаются в плеер
- Плеер распознаёт речь **локальной офлайн‑моделью** (SenseVoice-Small, int8, около 228 МБ, **без сети**) — ни аудио, ни результат не покидают ваш компьютер
- Распознанный текст и подходящие каналы показываются в панели (скажите «3 台» — появится `CCTV3`); после команды панель остаётся открытой, можно говорить дальше
- Поле ввода внизу панели отправляет **текстовую команду** с тем же результатом, что и голос

Что можно сказать:

| Фраза | Результат |
|------|------|
| `湖南卫视` / `CCTV3` / `3 台` | Переключение по названию или номеру канала (омофоны вроде «2 太 / 2 胎» тоже распознаются) |
| `下一个台` / `上一个台` | Следующий / предыдущий канал |
| `换源` | Следующий источник текущего канала |
| `音量 40` / `音量加` / `静音` | Задать громкость, прибавить или выключить звук |
| `快进 30 秒` / `后退 15 秒` | Относительный переход (работает в архиве и timeshift) |
| `回看今天的新闻联播` | Найти эту передачу в телепрограмме канала и включить её из архива |
| `现在在播什么` | Озвучить, что идёт сейчас |

Модель скачивается при первом использовании: **Настройки → Веб‑пульт → Офлайн‑голос** (с прогрессом и повтором при ошибке); там же настраиваются слова активации, свои правила фраз и шаг громкости.

> Микрофон телефона доступен только в защищённом контексте (`https://` или `localhost`): по `http://192.168.x.x` страница сообщает, что контекст не защищён, и запись не стартует — установите сертификат, как описано в разделе *HTTPS и сертификаты* выше, и откройте страницу по `https://`.

### Управление источниками (развернуть)

- Отображение всех сохранённых источников воспроизведения
- Выбранный источник подсвечивается
- Поддержка выбора, добавления, удаления источников

### Управление напоминаниями (развернуть)

- Отображение всех запланированных напоминаний
- Поддержка отмены напоминания
- Показ канала, названия программы, времени, типа действия

### Управление записями (развернуть)

- Отображение всех задач записи
- Поддержка остановки текущих записей
- Поддержка удаления завершённых/неудачных записей

## Настройки безопасности

### Защита паролем

После включения защиты паролем для доступа к странице управления требуется пароль:

1. Установите флажок **Требовать пароль** в настройках
2. Задайте пароль доступа
3. Сохраните настройки

Для использования функций управления требуется ввод пароля.

### Примечания

- После включения служба прослушивает **все сетевые интерфейсы** компьютера (`0.0.0.0`), поэтому любое устройство в той же локальной сети, зная адрес и порт, может получить доступ; по умолчанию **пароль не включён**, рекомендуется включить «Требовать пароль»
- Для доступа в локальной сети убедитесь, что брандмауэр разрешает соответствующий порт
- Рекомендуется включить защиту паролем для безопасности
- Открытый `http://`-трафик в локальной сети могут прослушивать другие устройства; установите сертификат и перейдите на `https://` (см. [HTTPS и сертификаты](#https-и-сертификаты))
- Для установки на главный экран нужен защищённый контекст (https или localhost); по обычному http доступно только «На главный экран»
- Переключатели **Показывать список каналов** и **Показывать программу** управляют отображением соответствующих блоков на странице пульта: при выключении соответствующий блок на странице не отображается
- Поле **Максимум программ в телепрограмме** (Max EPG items) задаёт, сколько программ показывается в телепрограмме: от 5 до 500, по умолчанию 50
- После изменения порта обновите страницу браузера

## Справочник WebSocket API

Помимо операций через браузерный интерфейс, вы также можете программно управлять через WebSocket API.

### Подключение

```javascript
const ws = new WebSocket('ws://localhost:8899');
```

### Аутентификация (при включённом пароле)

```json
// Отправка
{ "action": "auth", "password": "ваш_пароль" }

// Получение
{ "success": true, "requireAuth": true }
```

### Общий формат ответа

Все операции возвращают JSON-ответ при успехе или `{ "error": "сообщение об ошибке" }` / `{ "success": false }` при ошибке.

### Список API

#### Управление воспроизведением

| Action | Параметры | Описание |
|--------|------------|----------|
| `play` | - | Воспроизведение/Продолжить |
| `pause` | - | Пауза |
| `stop` | - | Остановка |
| `volume` | `volume` (0-100) | Установить громкость |
| `fullscreen` | - | Полный экран |
| `seek` | `seconds` (+/- число) | Перемотка на секунды |

#### Управление каналами

| Action | Параметры | Описание |
|--------|------------|----------|
| `channel` | `channelId` | Переключить канал |

Кнопки «Предыдущий канал» / «Следующий канал» на странице сами вычисляют id целевого канала по текущему списку каналов и затем вызывают `channel`; в самом WebSocket-интерфейсе действий `prevChannel` / `nextChannel` нет (такой вызов вернёт `Unknown action`).

#### Управление скоростью

| Action | Параметры | Описание |
|--------|------------|----------|
| `setSpeed` | `speed` (0.5/1.0/2.0) | Установить скорость |
| `setTimeshift` | `enabled` (true/false) | Включить/выключить таймшифт |

#### Возврат к эфиру

| Action | Параметры | Описание |
|--------|------------|----------|
| `replayProgram` | `channelId`, `programTitle`, `start` (ISO), `end` (ISO) | Вернуться к указанной программе |

#### Запрос статуса

| Action | Возвращает | Описание |
|--------|------------|----------|
| `getStatus` | `{ playing, mode, channel, volume, ... }` | Получить статус воспроизведения |
| `getChannels` | `{ groups: [...], favorites: [...] }` | Получить список каналов |
| `getEpg` | `{ channelId, programs: [...] }` | Получить телепрограмму |
| `getSources` | `{ sources: [...] }` | Получить список источников |
| `getReminders` | `{ reminders: [...] }` | Получить список напоминаний |
| `getRecordings` | `{ recordings: [...] }` | Получить список записей |

#### Управление напоминаниями

| Action | Параметры | Описание |
|--------|------------|----------|
| `addReminder` | `channelId`, `startAt` (ISO), `endTime` (ISO), `action`, `programTitle`, `preAlertSeconds`, `recordDurationMin` | Добавить напоминание |
| `cancelReminder` | `id` | Отменить напоминание |

#### Управление записями

| Action | Параметры | Описание |
|--------|------------|----------|
| `stopRecording` | `id` | Остановить запись |
| `deleteRecording` | `id` | Удалить запись |

#### Управление источниками

| Action | Параметры | Описание |
|--------|------------|----------|
| `selectSource` | `name` или `url` | Выбрать источник |
| `addSource` | `name`, `url` | Добавить источник |
| `removeSource` | `name` или `url` | Удалить источник |
| `prevSource` | - | Предыдущий источник |
| `nextSource` | - | Следующий источник |

#### Прочее

| Action | Параметры | Описание |
|--------|------------|----------|
| `exit` | - | Закрыть плеер |
| `switchSource` | - | Переключить источник |

## Устранение неполадок

### Не удаётся открыть страницу управления

1. Подтвердите, что веб-пульт включён в настройках
2. Проверьте, не занят ли порт (по умолчанию 8899)
3. Проверьте настройки брандмауэра
4. Убедитесь, что плеер SrcBox запущен

### Страница пустая

1. Попробуйте обновить страницу
2. Очистите кеш браузера
3. Используйте другой браузер
4. Проверьте, включена ли защита паролем

### Операции не отвечают

1. Убедитесь, что SrcBox воспроизводит
2. Проверьте сетевое подключение
3. Попробуйте перезапустить SrcBox

## Техническая реализация

Веб-пульт использует следующие технологии:

- **WebSocket**: Двусторонняя связь для команд управления воспроизведением
- **HTTP**: Запросы статуса и обслуживание статических ресурсов
- **JSON**: Формат обмена данными
- **Чистый HTML/CSS/JS**: Без внешних зависимостей

Сервер прослушивает порт 8899 по умолчанию, веб-интерфейс доступен через браузер без дополнительного ПО.
