# Веб-пульт дистанционного управления

SrcBox предоставляет функцию веб-пульта дистанционного управления, позволяющую удалённо управлять плеером через браузер, включая управление воспроизведением, регулировку громкости, переключение каналов, возврат к эфиру, планирование записей и многое другое.

## Обзор функций

Веб-пульт работает на основе протоколов WebSocket и HTTP и поддерживает следующие функции:

- **Управление воспроизведением**: Воспроизведение, Пауза, Остановка
- **Контроль прогресса**: Перемотка вперёд, назад, Поиск
- **Регулировка громкости**: Изменение громкости, Отключение звука
- **Переключение каналов**: Предыдущий/Следующий канал, Список каналов, Поиск каналов
- **Возврат к эфиру**: Таймшифт, Воспроизведение передачи
- **Планирование**: Напоминания, Запись по расписанию (передняя/фоновая)
- **Управление источниками**: Добавление, выбор, удаление источников воспроизведения
- **Просмотр статуса**: Текущий статус воспроизведения, Информация о программе, Телепрограмма
- **Многоязычная поддержка**: Китайский, Английский, Русский, Турецкий

## Включение удалённого управления

1. Откройте окно настроек SrcBox
2. Перейдите на вкладку **Веб-пульт**
3. Установите флажок **Включить веб-пульт**
4. (Необязательно) Установите порт доступа (по умолчанию 8899)
5. (Необязательно) Включите защиту паролем и задайте пароль
6. Нажмите кнопку **Сохранить**

## Доступ к удалённому управлению

После включения откройте в браузере:

```
http://localhost:8899
```

Для локального доступа используйте `localhost`. Для удалённого доступа в локальной сети замените `localhost` на IP-адрес компьютера с SrcBox, например:

```
http://192.168.1.100:8899
```

## Описание интерфейса

### Область статуса

- Текущий режим воспроизведения (Прямой эфир/Возврат/Таймшифт/Запись/Остановлен)
- Название и логотип текущего канала
- Название и время текущей программы

### Область управления воспроизведением

| Кнопка | Функция |
|--------|---------|
| Полный экран | Переключение полноэкранного режима |
| Воспроизведение | Начать воспроизведение |
| Пауза | Приостановить воспроизведение |
| Стоп | Остановить воспроизведение |
| Без звука | Переключение звука |
| Предыдущий канал | Переключить на предыдущий канал |
| Следующий канал | Переключить на следующий канал |
| Переключить источник | Переключить источник воспроизведения |
| Выход | Закрыть плеер |
| Обновить | Обновить данные статуса |

### Область быстрого управления

| Кнопка | Функция |
|--------|---------|
| Таймшифт | Включить/выключить режим таймшифта |
| -10с | Перемотка на 10 секунд назад |
| +10с | Перемотка на 10 секунд вперёд |
| 0.5x | Скорость 0.5x |
| 1x | Нормальная скорость |
| 2x | Скорость 2x |

### Область регулировки громкости

- Ползунок громкости: Регулировка уровня громкости
- Кнопка без звука: Переключение звука

### Список каналов

- Отображение всех доступных каналов и избранного
- Нажмите название канала для переключения
- Избранные каналы отображаются вверху списка со звездочкой

### Телепрограмма (EPG)

- Отображение списка программ текущего канала (по умолчанию сегодняшние)
- Нажмите на программу для возврата к эфиру
- Поддерживаются три кнопки действий:
  - **Возврат** (Фиолетовый): Вернуться к aired-программе
  - **Таймшифт** (Синий): Таймшифт текущей программы
  - **Напоминание** (Зелёный): Запланировать напоминание
  - **Запись** (Оранжевый): Запланировать фронтальную запись

### Значки программ

| Значок | Цвет | Значение |
|--------|------|----------|
| LIVE | Красный | Прямой эфир |
| Возврат | Фиолетовый | Текущий возврат |
| Напоминание | Зелёный | Напоминание установлено |
| Следующая | Оранжевый | Следующая программа |

### Управление источниками (развернуть)

- Отображение всех сохранённых источников воспроизведения
- Показ состояния здоровья источника (Зелёный=ОК, Красный=Ошибка)
- Поддержка выбора, добавления, удаления источников

### Управление напоминаниями (развернуть)

- Отображение всех запланированных напоминаний
- Поддержка отмены напоминания
- Показ канала, названия программы, времени, типа действия

### Управление записями (развернуть)

- Отображение всех задач записи
- Поддержка остановки текущих записей
- Поддержка удаления завершённых/неудачных записей

## Настройки безопасности

### Защита паролем

После включения защиты паролем для доступа к странице управления требуется пароль:

1. Установите флажок **Требовать пароль** в настройках
2. Задайте пароль доступа
3. Сохраните настройки

Для использования функций управления требуется ввод пароля.

### Примечания

- По умолчанию удалённое управление доступно только локально (localhost)
- Для доступа в локальной сети убедитесь, что брандмауэр разрешает соответствующий порт
- Рекомендуется включить защиту паролем для безопасности
- После изменения порта обновите страницу браузера

## Справочник WebSocket API

Помимо операций через браузерный интерфейс, вы также можете программно управлять через WebSocket API.

### Подключение

```javascript
const ws = new WebSocket('ws://localhost:8899');
```

### Аутентификация (при включённом пароле)

```json
// Отправка
{ "action": "auth", "password": "ваш_пароль" }

// Получение
{ "success": true, "requireAuth": true }
```

### Общий формат ответа

Все операции возвращают JSON-ответ при успехе или `{ "error": "сообщение об ошибке" }` / `{ "success": false }` при ошибке.

### Список API

#### Управление воспроизведением

| Action | Параметры | Описание |
|--------|------------|----------|
| `play` | - | Воспроизведение/Продолжить |
| `pause` | - | Пауза |
| `stop` | - | Остановка |
| `volume` | `volume` (0-100) | Установить громкость |
| `fullscreen` | - | Полный экран |
| `seek` | `seconds` (+/- число) | Перемотка на секунды |

#### Управление каналами

| Action | Параметры | Описание |
|--------|------------|----------|
| `channel` | `channelId` | Переключить канал |
| `prevChannel` | - | Предыдущий канал |
| `nextChannel` | - | Следующий канал |

#### Управление скоростью

| Action | Параметры | Описание |
|--------|------------|----------|
| `setSpeed` | `speed` (0.5/1.0/2.0) | Установить скорость |
| `setTimeshift` | `enabled` (true/false) | Включить/выключить таймшифт |

#### Возврат к эфиру

| Action | Параметры | Описание |
|--------|------------|----------|
| `replayProgram` | `channelId`, `programTitle`, `start` (ISO), `end` (ISO) | Вернуться к указанной программе |

#### Запрос статуса

| Action | Возвращает | Описание |
|--------|------------|----------|
| `getStatus` | `{ playing, mode, channel, volume, ... }` | Получить статус воспроизведения |
| `getChannels` | `{ groups: [...], favorites: [...] }` | Получить список каналов |
| `getEpg` | `{ channelId, programs: [...] }` | Получить телепрограмму |
| `getSources` | `{ sources: [...] }` | Получить список источников |
| `getReminders` | `{ reminders: [...] }` | Получить список напоминаний |
| `getRecordings` | `{ recordings: [...] }` | Получить список записей |

#### Управление напоминаниями

| Action | Параметры | Описание |
|--------|------------|----------|
| `addReminder` | `channelId`, `startAt` (ISO), `endTime` (ISO), `action`, `programTitle`, `preAlertSeconds`, `recordDurationMin` | Добавить напоминание |
| `cancelReminder` | `id` | Отменить напоминание |

#### Управление записями

| Action | Параметры | Описание |
|--------|------------|----------|
| `stopRecording` | `id` | Остановить запись |
| `deleteRecording` | `id` | Удалить запись |

#### Управление источниками

| Action | Параметры | Описание |
|--------|------------|----------|
| `selectSource` | `name` или `url` | Выбрать источник |
| `addSource` | `name`, `url` | Добавить источник |
| `removeSource` | `name` или `url` | Удалить источник |
| `prevSource` | - | Предыдущий источник |
| `nextSource` | - | Следующий источник |

#### Прочее

| Action | Параметры | Описание |
|--------|------------|----------|
| `exit` | - | Закрыть плеер |
| `switchSource` | - | Переключить источник |

## Устранение неполадок

### Не удаётся открыть страницу управления

1. Подтвердите, что веб-пульт включён в настройках
2. Проверьте, не занят ли порт (по умолчанию 8899)
3. Проверьте настройки брандмауэра
4. Убедитесь, что плеер SrcBox запущен

### Страница пустая

1. Попробуйте обновить страницу
2. Очистите кеш браузера
3. Используйте другой браузер
4. Проверьте, включена ли защита паролем

### Операции не отвечают

1. Убедитесь, что SrcBox воспроизводит
2. Проверьте сетевое подключение
3. Попробуйте перезапустить SrcBox

## Техническая реализация

Веб-пульт использует следующие технологии:

- **WebSocket**: Двусторонняя связь для команд управления воспроизведением
- **HTTP**: Запросы статуса и обслуживание статических ресурсов
- **JSON**: Формат обмена данными
- **Чистый HTML/CSS/JS**: Без внешних зависимостей

Сервер прослушивает порт 8899 по умолчанию, веб-интерфейс доступен через браузер без дополнительного ПО.
