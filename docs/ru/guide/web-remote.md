# Web 远程控制

SrcBox 提供 Web 远程控制功能，允许您通过浏览器远程操控播放器，实现播放控制、音量调节、频道切换等操作。

## 功能概述

Web 远程控制基于 WebSocket 和 HTTP 协议实现，支持以下功能：

- **播放控制**：播放、暂停、停止
- **进度控制**：快进、快退、跳转
- **音量调节**：音量增减、静音
- **频道切换**：上下换台、频道列表
- **状态查看**：当前播放状态、节目信息
- **多语言支持**：中文、英文、俄文等

## 启用远程控制

1. 打开 SrcBox 设置窗口
2. 切换到 **Web 远程控制** 选项卡
3. 勾选 **启用 Web 远程控制**
4. （可选）设置访问端口（默认 8899）
5. （可选）启用密码保护，设置访问密码
6. 点击 **保存** 按钮

## 访问远程控制

启用后，在浏览器中访问：

```
http://localhost:8899
```

如果是本机访问，直接使用 `localhost`。如果是局域网远程访问，请将 `localhost` 替换为 SrcBox 所在电脑的 IP 地址。

## 界面说明

### 状态显示区

- 当前播放状态（直播/回放/时移）
- 当前频道名称和 Logo
- 当前节目名称和播放时间

### 播放控制区

| 按钮 | 功能 |
|------|------|
| 播放/暂停 | 切换播放状态 |
| 停止 | 停止播放 |
| 快退 | 快退 10 秒 |
| 快进 | 快进 10 秒 |

### 频道控制区

| 按钮 | 功能 |
|------|------|
| 上一频道 | 切换到上一个频道 |
| 下一频道 | 切换到下一个频道 |
| 频道列表 | 显示/隐藏频道列表 |

### 音量控制区

| 控件 | 功能 |
|------|------|
| 音量滑块 | 调节音量大小 |
| 静音按钮 | 切换静音状态 |

### 频道列表

- 显示所有可用频道
- 支持搜索过滤
- 点击频道名称即可切换播放

### EPG 节目单

- 显示当前频道的节目列表
- 支持翻页查看更多节目
- 显示节目时间和简介

## 安全设置

### 密码保护

启用密码保护后，访问远程控制页面需要输入密码：

1. 在设置中勾选 **需要密码访问**
2. 设置访问密码
3. 保存设置

访问时需要输入密码才能使用远程控制功能。

### 注意事项

- 默认情况下，远程控制仅允许本地访问（localhost）
- 如需局域网访问，请确保防火墙允许对应端口
- 建议启用密码保护以确保安全
- 更改端口后需要刷新浏览器页面

## 故障排除

### 无法访问远程控制页面

1. 确认已在设置中启用 Web 远程控制
2. 检查端口是否被占用（默认 8899）
3. 检查防火墙设置
4. 确认 SrcBox 播放器正在运行

### 页面显示空白

1. 尝试刷新页面
2. 清除浏览器缓存
3. 使用其他浏览器访问
4. 检查是否启用了密码保护

### 操作无响应

1. 确认 SrcBox 播放器正在播放
2. 检查网络连接是否正常
3. 尝试重新启动 SrcBox 播放器

## 技术实现

Web 远程控制采用以下技术：

- **WebSocket**：实时双向通信，用于播放控制指令
- **HTTP**：状态查询和静态资源服务
- **JSON**：数据交换格式
- **原生 HTML/CSS/JS**：无外部依赖

服务端默认监听端口 8899，Web 界面通过浏览器访问，无需额外安装软件。
