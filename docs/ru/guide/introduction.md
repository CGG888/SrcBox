# 项目介绍

**源匣 (SrcBox)** 是一款专为 Windows 平台打造的高性能、现代化 IPTV 播放器。

## 概述

SrcBox 基于强大的 **libmpv** 播放内核构建，结合 **WPF** 的现代化界面设计，为用户提供流畅、稳定的直播观看体验。它不仅支持 M3U 播放列表、EPG 电子节目单、回看、时移、录播等核心功能，还针对 IPTV 场景进行了深度优化。

## 技术架构

| 组件 | 技术 |
|------|------|
| 播放内核 | libmpv |
| UI 框架 | WPF + ModernWpf |
| 语言 | C# (.NET 8) |
| 录播同步 | WebDAV |
| 远程控制 | WebSocket + HTTP |

## 主要功能

### 核心播放
- M3U 播放列表解析（本地/远程）
- EPG 电子节目单（XMLTV 格式）
- 直播时移与节目回放
- 硬件加速解码支持

### 特色功能
- **FCC 快速切台**：毫秒级极速换台体验
- **Web 远程控制**：通过浏览器远程操控
- **音频优化**：音量增益、最大音量、音频延迟
- **去交错处理**：针对隔行扫描视频优化
- **WebDAV 录播**：本地录播配合云端同步

### 用户体验
- 深色/浅色主题自适应
- 多语言界面（简/繁/英/俄）
- 频道收藏与历史记录
- 节目预约提醒

## 适用场景

- 观看 IPTV 直播电视
- 录播精彩节目内容
- 回看错过的电视节目
- 远程控制播放器

## 系统要求

- Windows 10/11
- .NET 8 Runtime
- 网络连接（用于直播和 EPG）
