# О проекте

**SrcBox** — это высокопроизводительный, современный IPTV плеер, разработанный исключительно для платформы Windows. Построен на мощном ядре воспроизведения **libmpv** с современным интерфейсом **WPF**, обеспечивая плавный и стабильный просмотр прямых трансляций.

## Ключевые функции

### FCC Мгновенное переключение
Технология, оптимизированная для IPTV с миллисекундным переключением каналов, устраняющая долгое ожидание.

### M3U + EPG
- Локальная/удалённая поддержка M3U плейлистов
- Полная электронная телепрограмма XMLTV (gz)
- Автоматическое переключение по дням, интеллектуальное сопоставление программ

### Timeshift и Архив
- Перемотка прямого эфира в реальном времени
- Автогенерация ссылок на архив по шаблону
- Перемотка ограничена границами программы

### Мультиэкран
Одновременный просмотр 4/6/9 экранов, быстрое переключение цифровыми клавишами, идеально для мониторинга или многозадачности.

### Запись по расписанию
- Передний/фоновый режим записи
- Автоматическая остановка по таймеру
- Синхронизация с WebDAV

### Веб-пульт
Управляйте плеером из любого браузера: воспроизведение, громкость, переключение каналов.

## Обзор функций

### Воспроизведение
- Воспроизведение/Пауза/Стоп/Перемотка вперёд/назад
- Регулировка громкости + отключение звука
- Задержка аудио (-100с~+100с)
- Ускоренное воспроизведение (0.5×~5.0×)

### Управление каналами
- Управление группами с сортировкой
- Быстрый поиск
- Избранное
- История просмотра

### Оптимизация видео
- Автоматическое переключение аппаратного декодирования
- Деинтерлейсинг (1080i/720i)
- Автоматическое переключение источника

### Интерфейс
- Адаптация тёмной/светлой темы
- Плавающая панель управления в полноэкранном режиме
- Боковые панели (список каналов/EPG)
- Компактный режим окна

### Мультиязычность
- Упрощённый китайский
- Традиционный китайский
- English
- Русский
