# Функциональные возможности

## Основные функции воспроизведения
- **Управление**: Воспроизведение/Пауза, Стоп, Перемотка, Перетаскивание.
- **Громкость**: Ползунок, поддержка отключения звука (0-100).
- **Усиление громкости**: Регулировка от -200dB до +60dB.
- **Макс. громкость**: Ограничение от 100% до 1000%.
- **Аудио задержка**: Регулировка от -100с до +100с для синхронизации.
- **Индикация**: Статус Прямой эфир / Архив / Timeshift.

## Функции IPTV

### Парсинг M3U
Поддержка локальных и удалённых M3U плейлистов, совместимость с UTF-8/GB18030. Расширенные атрибуты `#EXTINF`.

### EPG
Поддержка XMLTV (gz), переключение по дням, автоматическое сопоставление `tvg-id`.
[Подробнее](./epg)

### Скорость воспроизведения
- Только для Timeshift/Архива; прямой эфир не поддерживает
- Скорости: 0.5×, 0.75×, 1.0×, 1.25×, 1.5×, 1.75×, 2.0×, 3.0×, 5.0×
- Автоматическая коррекция высоты звука

### Деинтерлейсинг (Deinterlace)
- Оптимизация для 1080i/720i чересстрочного видео
- Режимы: Автоматический / Принудительный / Выключен
- Алгоритмы: yadif (по умолчанию) / bwdif (лучше)
- Настройки поля: Автоматически / TFF / BFF
- Предпросмотр в реальном времени

### Управление каналами
Группировка, поиск, избранное и история (локально).

### Значки R/T
- R: доступен архив; T: доступен timeshift
- Подсказки локализованы (ZH/EN/RU/TW)

### Напоминания и автозапуск
- Напоминания с режимами "только напомнить" и "автозапуск"
- Единый список; чекбоксы для удаления
- Единые точки входа из трея/меню

### Минимальный режим
Компактное окно с верхней панелью и основными контролами.

## Мультиэкран (v1.1.9 НОВОЕ)

Поддержка 4/6/9 экранов одновременно, идеально для мониторинга или просмотра нескольких каналов.

### Функции
- **Режимы мультиэкрана**: 4, 6 или 9 экранов одновременно
- **Быстрый выбор**: Клавиши 1-9 для выбора соответствующего экрана
- **Переключение каналов**: Клавиши ↑↓ для предыдущего/следующего канала
- **Переключение источников**: Клавиши ←→ для предыдущего/следующего источника
- **Меню трея**: Добавлено подменю мультиэкрана в контекстное меню трея

### Горячие клавиши
| Клавиша | Функция |
|---------|---------|
| `Ctrl+4` | Открыть 4-экранный режим |
| `Ctrl+6` | Открыть 6-экранный режим |
| `Ctrl+9` | Открыть 9-экранный режим |
| `1-9` | Выбрать соответствующий экран |
| `↑/↓` | Переключить канал |
| `←/→` | Переключить источник |

## Запланированная запись (v1.1.9 НОВОЕ)

Поддержка фронтального и фонового режимов запланированной записи.

### Фронтальная запись
- Экран переходит на записываемый канал во время записи
- Поддержка пользовательской длительности с автоостановкой
- Отображение таймера записи

### Фоновая запись
- Сохраняет текущий канал без переключения
- Поддержка автоостановки по таймеру
- Уведомление Toast о завершении записи

### Уведомление о завершении
- Toast уведомление при завершении записи
- Автоскрытие через 5 секунд
- Различие提示 для фронтальной/фоновой записи

## Выбор декодера (v1.1.9 НОВОЕ)

Поддержка аппаратных и программных декодеров с динамическим переключением во время воспроизведения.

### Опции декодера
- **Авто**: Автоматический выбор лучшего декодера
- **D3D11VA**: Windows Video Acceleration (по умолчанию)
- **DXVA2**: DirectX Video Acceleration
- **NVDEC**: Декодирование NVIDIA GPU
- **ПО**: Программное декодирование CPU
