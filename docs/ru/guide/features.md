# Функциональные возможности

## Управление воспроизведением

- **Управление**: Воспроизведение/Пауза, Стоп, Перемотка, Перетаскивание
- **Громкость**: Ползунок + Отключение звука (0-100)
- **Аудио настройки**: Усиление (-200dB~+60dB), Макс. громкость (100%~1000%), Задержка (-100s~+100s)
- **Индикация статуса**: Статус Прямой эфир / Архив / Timeshift в оверлее
- **Ускоренное воспроизведение**: В режиме timeshift/архива 0.5×~5.0× с коррекцией тона

## Быстрое переключение каналов (FCC)

Технология быстрого переключения каналов, оптимизированная для IPTV, миллисекундное переключение, никаких долгих ожиданий.

## Программа и Архив

### Парсинг M3U
Поддержка локальных и удалённых M3U плейлистов, совместимость с UTF-8/GB18030, расширенные атрибуты `#EXTINF`.

### EPG Телепрограмма
Поддержка XMLTV (gz), автоматическое переключение по дням, интеллектуальное сопоставление `tvg-id`.
[Настройка](./epg)

### Архив (Catchup)
Автоматическая генерация URL архива по шаблону (например, `{utc:yyyyMMddHHmmss}`), не пропустите интересные программы.
[Использование](./catchup-timeshift)

## Мультиэкран

Поддержка 4/6/9 экранов одновременно, идеально для мониторинга или многозадачности.

| Горячая клавиша | Функция |
|-----------------|---------|
| `Ctrl+4/6/9` | Открыть соответствующий режим мультиэкрана |
| `1-9` | Выбрать соответствующий экран |
| `↑/↓` | Переключить канал |
| `←/→` | Переключить источник |

## Запланированная запись

Поддержка фронтального и фонового режимов записи с автоматическим уведомлением о завершении.

- **Фронтальная запись**: Экран переходит на записываемый канал, автоостановка по таймеру
- **Фоновая запись**: Сохраняет текущий канал, автоостановка по расписанию
- **WebDAV синхронизация**: Автозагрузка записей на WebDAV сервер

## Веб-пульт

Дистанционное управление плеером через браузер, контролируйте ТВ отовсюду.

- Управление воспроизведением, регулировка громкости, переключение каналов
- Просмотр статуса в реальном времени, информация о программе
- Защита паролем (опционально)

[Подробное руководство](./web-remote)

## Управление каналами

- **Группы**: Управление группами каналов с сортировкой
- **Поиск**: Быстрый поиск каналов
- **Избранное**: Добавление каналов в избранное
- **История**: История воспроизведения, локальное хранение
- **Значки R/T**: Быстрая идентификация каналов с поддержкой Архива(R) или Timeshift(T)

## Выбор декодера

Поддержка аппаратных и программных декодеров с динамическим переключением во время воспроизведения:

| Декодер | Описание |
|---------|---------|
| Авто | Автоматический выбор лучшего декодера |
| D3D11VA | Windows Video Acceleration (по умолчанию) |
| DXVA2 | DirectX Video Acceleration |
| NVDEC | Декодирование NVIDIA GPU |
| Программный | Декодирование CPU |

## Оптимизация видео

### Деинтерлейсинг
Оптимизация для 1080i/720i чересстрочного видео:
- Три режима: Авто / Принудительный / Выключен
- Два алгоритма: yadif (по умолчанию) / bwdif (лучше качество)
- Настройки поля: Авто / ТFF / BFF

## Полноэкранное взаимодействие

- **Двойной клик** или `Enter` для полноэкранного режима
- **Плавающая панель управления**: Автоотображение при движении мыши вниз
- **Боковая панель**: Мышь у края показывает список каналов (справа) или EPG (слева)
- **ESC** для выхода из полноэкранного режима

## Особенности интерфейса

- **Тёмная/Светлая тема**: Идеальная адаптация для Windows 10/11
- **Компактный режим**: Компактная форма окна для просмотра на маленьком экране
- **Мультиязычность**: Поддержка упрощённого/традиционного китайского, английского, русского

| `Ctrl+/` | Справка по горячим клавишам |
