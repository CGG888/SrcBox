# Дорожная карта (Roadmap)

Мы стремимся постоянно улучшать опыт просмотра IPTV.

## Планы на будущее

- [ ] **Умные рекомендации**: AI рекомендации программ на основе истории просмотров.
- [ ] **Облачная запись (PVR)**: Поддержка записи передач в удалённое хранилище.
- [ ] **Улучшенное A/V**: Поддержка динамических метаданных HDR10+, оптимизация декодирования 8K 120fps.
- [ ] **Интерактивность**: Голосовые комментарии (Speech-to-Text), вход в облачный гейминг с низкой задержкой.
- [ ] **Защита авторских прав**: Проверка на блокчейне.
- [ ] **Анимации уведомлений**: Напоминания с анимацией появления/скольжения.
- [ ] **Настраиваемые чипы**: Шаблоны внешнего вида для иконок/цветов/скругления.

## Реализованные функции

### Основное воспроизведение
- [x] **Timeshift**: Сдвиг во времени на основе `catchup-source` с перемоткой в реальном времени, перемотка ограничена границами программы.
- [x] **EPG**: Парсинг и отображение XMLTV (gz), поддержка суффиксов типов каналов CCTV/Образование.
- [x] **Архив (Catchup)**: Автоматическая генерация URL архива по шаблонам.
- [x] **Парсинг M3U**: Поддержка локальных/удалённых плейлистов и атрибутов `#EXTINF`, формат TXT.
- [x] **Двоичный кэш M3U**: Двоичный кэш с проверкой ETag/Last-Modified, загрузка за миллисекунды.
- [x] **Управление каналами**: Группировка, поиск, избранное, сортировка групп.

### Оптимизация воспроизведения
- [x] **Оптимизация**: Быстрое переключение FCC, оптимизация UDP multicast, авто-переключение.
- [x] **Аппаратное декодирование**: `d3d11va` включено по умолчанию, несколько опций декодера (D3D11VA/DXVA2/NVDEC/ПО).
- [x] **Мультиэкран (v1.1.9)**: 4/6/9 экранов одновременно, выбор клавишами 1-9, переключение источников.
- [x] **Веб-удалённое управление**: Управление проигрывателем через браузер.

### Функции записи
- [x] **Локальная запись**: Локальная запись, загрузка на WebDAV, очередь загрузок.
- [x] **Запланированная запись (v1.1.9)**: Режимы фронтальной/фоновой записи, уведомление о завершении записи Toast.

### Интерфейс и взаимодействие
- [x] **Минимальный режим**: Компактное окно, синхронизация состояний.
- [x] **Напоминания**: Напоминания, список напоминаний, автозапуск.
- [x] **UI/UX**: Полноэкранный оверлей, боковая панель, многоязычность (ZH/EN/ZH-TW/RU).
- [x] **Горячие клавиши**: Полная поддержка горячих клавиш, окно справки по клавишам.
- [x] **Окно настроек**: Изменяемый размер, оптимизированные цвета тёмной/светлой темы.
- [x] **Память режима закрытия (v1.1.9)**: Запомнить выбор пользователя (выход или сворачивание в трей).

### Новые функции v1.1.9
- Мультиэкран: 4/6/9 экранов одновременно, выбор 1-9, ↑↓ переключение каналов, ←→ переключение источников
- Меню мультиэкрана в трее: Добавлено подменю мультиэкрана в контекстное меню трея
- Запланированная запись: Режимы фронтальной/фоновой записи, уведомление Toast о завершении
- Выбор декодера: Авто/D3D11VA/DXVA2/NVDEC/ПО, динамическое переключение во время воспроизведения
- Окно справки по клавишам: ShortcutsWindow для справки по горячим клавишам
- Рефакторинг меню: Классификация по функциональным областям, поддержка формата TXT
- Рефакторинг окна настроек: 12 вкладок объединено в 7
- Улучшения таймшифта: Перемотка в пределах границ программы, непрерывное воспроизведение, автопереход
- Обновление выпадающего списка M3U: Автообновление после добавления нового источника
- Оптимизация кэша mpv: Динамический контроль кэша в зависимости от состояния записи

### Обновления v1.1.2+
- Чипы статуса EPG: Прямой эфир = красный; Архив = зелёный; клик запускает канал
- Индикатор текущего: подсветка строки; зелёная полоса при архиве
- Напоминания: единый список; центрирование; чекбоксы; трей/меню
- Управление M3U: пакетное удаление; редактирование; трей
- Системный трей: Открыть/Напоминания/М3U/Настройки/Выход
- Подтверждение закрытия: ×/ESC = диалог; "Нет" = трей
- Синхронизация тем заголовков
- Скорость воспроизведения: 3×/5× с коррекцией звука
