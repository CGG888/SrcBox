# Дорожная карта (Roadmap)

Мы стремимся постоянно улучшать опыт просмотра IPTV.

## <span style="font-size:1.2em">✨</span> Выполнено

### Основное воспроизведение

<span style="color:#22c55e">✔</span> **FCC Мгновенное переключение** - Миллисекундное переключение каналов, оптимизировано для IPTV<br>
<span style="color:#22c55e">✔</span> **M3U Плейлисты** - Локальная/удалённая поддержка, UTF-8/GB18030 кодировка, атрибуты `#EXTINF`<br>
<span style="color:#22c55e">✔</span> **M3U Бинарный кэш** - Проверка ETag/Last-Modified, загрузка за миллисекунды<br>
<span style="color:#22c55e">✔</span> **EPG Телепрограмма** - Парсинг XMLTV (gz), поддержка суффиксов CCTV/Образование<br>
<span style="color:#22c55e">✔</span> **Архив (Catchup)** - Автогенерация URL архива по шаблону, возврат к эфиру с таймшифтом<br>
<span style="color:#22c55e">✔</span> **Timeshift** - Перемотка в реальном времени, в пределах границ программы<br>
<span style="color:#22c55e">✔</span> **Управление каналами** - Группы, поиск, избранное, история, сортировка групп<br>
<span style="color:#22c55e">✔</span> **RTP Прямой адрес** - UDP оптимизация, снижение задержки

### Оптимизация воспроизведения

<span style="color:#22c55e">✔</span> **Аппаратное декодирование** - D3D11VA/DXVA2/NVDEC/ПО автопереключение<br>
<span style="color:#22c55e">✔</span> **Деинтерлейсинг** - Оптимизация 1080i/720i, алгоритмы yadif/bwdif<br>
<span style="color:#22c55e">✔</span> **Настройки аудио** - Усиление, макс. громкость, задержка<br>
<span style="color:#22c55e">✔</span> **Ускоренное воспроизведение** - Режим timeshift/catchup 0.5×~5.0×, коррекция тона<br>
<span style="color:#22c55e">✔</span> **Автопереключение источника** - Автоматическое переключение при сбое источника<br>
<span style="color:#22c55e">✔</span> **Предварительное подключение** - Предварительное соединение, ускорение переключения каналов

### Мультиэкран и запись

<span style="color:#22c55e">✔</span> **Мультиэкран** - 4/6/9 экранов одновременно, быстрый выбор цифровыми клавишами<br>
<span style="color:#22c55e">✔</span> **Локальная запись** - Запись напрямую на локальный диск<br>
<span style="color:#22c55e">✔</span> **WebDAV загрузка** - Автоматическая загрузка после записи<br>
<span style="color:#22c55e">✔</span> **Запись по расписанию** - Фронтальный/фоновый режимы, автоостановка по таймеру

### Интерфейс и взаимодействие

<span style="color:#22c55e">✔</span> **Тёмная/светлая тема** - Идеальная адаптация для Windows 10/11<br>
<span style="color:#22c55e">✔</span> **Полноэкранный оверлей** - Контрольная панель при наведении мыши<br>
<span style="color:#22c55e">✔</span> **Боковые панели** - Список каналов (справа) и EPG (слева)<br>
<span style="color:#22c55e">✔</span> **Компактный режим** - Компактная форма окна<br>
<span style="color:#22c55e">✔</span> **Системный трей** - Постоянный значок с меню быстрого доступа<br>
<span style="color:#22c55e">✔</span> **Горячие клавиши** - Полная поддержка с окном справки<br>
<span style="color:#22c55e">✔</span> **Память режима закрытия** - Запомнить выбор выход/свернуть в трей<br>
<span style="color:#22c55e">✔</span> **Предпросмотр канала** - Миниатюра при наведении, настраиваемый размер<br>
<span style="color:#22c55e">✔</span> **Окно отладки** - Просмотр логов в реальном времени, переключение режима отладки

### Удалённое управление и синхронизация

<span style="color:#22c55e">✔</span> **Веб-удалённое управление** - Управление плеером через браузер, полное управление воспроизведением, возврат, напоминания, запись<br>
<span style="color:#22c55e">✔</span> **Напоминания о программах** - Уведомления с опцией автозапуска<br>
<span style="color:#22c55e">✔</span> **Мультиязычность** - Упрощённый/Традиционный китайский, English, Русский

### Здоровье источников и стабильность

<span style="color:#22c55e">✔</span> **Проверка здоровья источников** - Фоновая проверка HTTP HEAD, отображение статуса в реальном времени<br>
<span style="color:#22c55e">✔</span> **Индикатор состояния источника** - В списке каналов отображается здоровье источника (зелёный/красный эллипс)<br>
<span style="color:#22c55e">✔</span> **Контекстное меню источника** - Просмотр статуса всех источников, задержки, переключение источника<br>
<span style="color:#22c55e">✔</span> **Автоматическая деградация источника** - Автоматическое переключение на здоровый резервный источник при сбое основного
