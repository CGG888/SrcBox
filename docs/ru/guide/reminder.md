# Функция напоминаний

SrcBox предоставляет мощную функцию напоминаний, поддерживающую уведомления о напоминаниях, автоматическое воспроизведение по расписанию и запланированную запись - ваш незаменимый помощник для просмотра IPTV трансляций.

## Обзор функций

| Функция | Описание |
|---------|----------|
| **Уведомление** | Напоминание перед началом программы, без автовоспроизведения |
| **Автозапуск** | Автоматическое переключение на целевой канал в запланированное время |
| **Запланированная запись** | Автозапуск записи в запланированное время (фронтальный/фоновый режим) |

---

## Уведомление о напоминании

Всплывающее уведомление перед началом программы, пользователь может выбрать смотреть или игнорировать.

### Функции
- Предварительное уведомление (настраиваемое время)
- Toast уведомление в правом нижнем углу, без захвата фокуса
- Поддержка режима только напоминания

### Использование
1. Выберите целевую программу в EPG
2. Нажмите правую кнопку → "Запланировать"
3. Выберите режим "Только напомнить"
4. Ждите уведомления

---

## Автоматическое воспроизведение по расписанию

Автоматическое переключение на целевой канал и воспроизведение в запланированное время.

### Функции
- Автовоспроизведение целевого канала вовремя
- Поддержка запуска с позиции таймшифта
- Автопереключение на целевой канал

### Использование
1. Выберите целевую программу в EPG
2. Нажмите правую кнопку → "Запланировать"
3. Выберите режим "Автозапуск"
4. Автопереключение и воспроизведение в запланированное время

---

## Запланированная запись (v1.1.9 НОВОЕ)

Автозапуск записи в запланированное время, поддержка фронтального и фонового режимов.

### Фронтальная запись

Экран переходит на записываемый канал во время записи.

| Функция | Описание |
|---------|----------|
| Переход экрана | Переключение на записываемый канал |
| Онлайн просмотр | Можно видеть записываемое изображение |
| Пользовательская длительность | Установка длительности записи, автоостановка вовремя |
| Отображение таймера | Показывает время записи |

### Фоновая запись

Сохраняет текущий канал без переключения.

| Функция | Описание |
|---------|----------|
| Без прерывания | Сохраняет текущее воспроизведение |
| Фоновый режим | Запись идёт в фоне |
| Автоостановка | Поддержка автоостановки по таймеру |
| Уведомление о завершении | Toast уведомление при завершении записи |

### Уведомление о завершении записи

- Toast уведомление при завершении записи
- Автоскрытие через 5 секунд
- Дифференцированные уведомления для фронтальной/фоновой записи

### Использование

1. Выберите целевую программу в EPG
2. Нажмите правую кнопку → "Запланировать"
3. Выберите режим "Фронтальная запись" или "Фоновая запись"
4. При желании установите длительность записи
5. Автозапуск записи в запланированное время

## Список напоминаний

Управление всеми созданными напоминаниями.

### Функции
- Окно управления с одним экземпляром
- Пакетное удаление с чекбоксами
- Выбрать всё / Инвертировать
- Фильтр состояния (v1.1.9 НОВОЕ)
- Кнопка обновления (v1.1.9 НОВОЕ)
- Окно остаётся над проигрывателем

### Точки входа
- Контекстное меню трея → Напоминания
- Выпадающее меню → Управление напоминаниями
- Контекстное меню → Список напоминаний

---

## Горячие клавиши

| Клавиша | Функция |
|---------|---------|
| `R` | Начать/остановить запись |

## Связанные настройки

Связанные настройки напоминаний можно настроить в окне настроек:
- Время предварительного напоминания
- Режим напоминания по умолчанию
- Путь сохранения записи
- Способ уведомления о завершении записи
