# 路线图 (Roadmap)

我们致力于持续提升 IPTV 观看体验。

## 未来计划

- [ ] 智能推荐：基于观看习惯的 AI 节目推荐
- [ ] 云端录制 (PVR)：支持连接远程存储进行节目录制
- [ ] 高级视听体验：HDR10+ 动态元数据支持、8K 120fps 解码优化
- [ ] 互动功能：语音弹幕（语音转字幕）、低延迟云游戏入口
- [ ] 版权保护：区块链版权校验（防篡改溯源）
- [ ] 通知动画：预约通知淡入/滑入、居中弹窗动效
- [ ] 芯片可定制：直播/回放芯片图标/色彩/圆角的外观模板化

## 已实现功能

### 核心播放
- [x] **时移 (Time-Shift)**：基于 `catchup-source` 的回放式时移，支持实时拖动回看，快进快退限制在节目边界内。
- [x] **EPG 电子节目单**：支持 XMLTV (gz) 解析与展示，支持央视/教育台频道类型后缀。
- [x] **频道回看**：基于模板自动生成回放 URL。
- [x] **M3U 解析**：支持本地/远程列表及 `#EXTINF` 扩展属性，支持 TXT 格式。
- [x] **M3U 二进制缓存**：ETag/Last-Modified 验证的二进制缓存，毫秒级加载。
- [x] **频道管理**：分组、搜索、收藏功能，支持分组排序。

### 播放优化
- [x] **直播优化**：FCC 快速切台、UDP 组播优化、自动换源。
- [x] **硬件解码**：默认开启 `d3d11va`，支持多种解码器选择（D3D11VA/DXVA2/NVDEC/软件）。
- [x] **多屏播放 (v1.1.9)**：支持 4/6/9 屏幕同时播放，1-9 数字键选择，源切换。
- [x] **Web 远程控制**：通过浏览器远程控制播放器。

### 录制功能
- [x] **本地录播**：本地录播、WebDAV 上传、上传队列。
- [x] **预约录制 (v1.1.9)**：前台/后台两种预约录制模式，录制完成 Toast 通知。

### 界面与交互
- [x] **精简模式**：精简窗口、顶栏交互、窗口态/全屏态状态同步。
- [x] **预约能力**：预约通知、预约列表、到点自动播放策略。
- [x] **UI/UX**：全屏悬浮控制、侧边抽屉、多语言支持（中/英/繁中/俄语）。
- [x] **快捷键**：完整的键盘快捷键支持，支持快捷键帮助窗口。
- [x] **设置窗口**：可调节大小，深/浅色模式配色优化。
- [x] **关闭模式记忆 (v1.1.9)**：记住用户选择（退出或最小化到托盘）。

### v1.1.9 新功能
- 多屏播放：4/6/9 屏幕同时播放，1-9 选择屏幕，↑↓ 切换频道，←→ 切换源
- 托盘多屏菜单：托盘右键菜单添加多屏播放子菜单
- 预约录制：前台/后台录制模式，录制完成 Toast 通知
- 解码器选择：自动/D3D11VA/DXVA2/NVDEC/软件，播放时动态切换
- 快捷键帮助窗口：ShortcutsWindow 快捷键说明窗口
- 菜单系统重构：按功能域分类，TXT 格式支持
- 设置窗口重构：12 标签整合为 7 标签
- 时移增强：节目边界内快进快退、连续播放、节目结束自动跳转
- M3U 下拉刷新：添加新链接后自动刷新
- mpv 缓存优化：录制状态动态控制缓存

### v1.1.2+ 交互更新
- EPG 状态芯片：直播=红填充、回放=绿填充；点击直播芯片即播放
- 当前播放标识：整行高亮；回放播放中左侧绿色竖线
- 预约通知：列表单实例、首次居中、复选框批删、托盘/右键/下拉入口一致
- M3U 管理：批量删除、单条编辑、托盘入口、全屏可见
- 托盘常驻：打开/预约/管理 M3U/设置/退出
- 退出确认：×/ESC 仅关闭弹窗；”否”最小化托盘（全屏先退出全屏）
- 深浅色标题栏：预约列表、M3U 管理、预约提醒、退出框在创建后即时匹配主题
- 倍速控制：支持时移/回放的倍速播放（含 3×/5×），自动音高校正；直播不支持
