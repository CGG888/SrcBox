# 用苹果语音控制播放器（Siri + 快捷指令）

用 **iPhone / iPad / Apple Watch 上的 Siri** 直接控制电脑上的 SrcBox：说一句「换到 5 台」「下一个台」「音量 40」「回看今天的新闻联播」，播放器立刻执行，手机还会把结果念出来。

整套方案只用苹果**自带的「快捷指令」App**（不需要装任何第三方 App），配合 SrcBox 内置的语音接口 `/api/voice`：

```
你说 → Siri 唤醒「快捷指令」 → 快捷指令的「听写文本」听你说 → GET /api/voice?text=…&token=…
     → SrcBox 本地解析并执行（换台/音量/回看/节目单…）→ 返回 JSON → 快捷指令「朗读」结果
```

语义解析完全在 **SrcBox 本机**完成（同一套代码同时服务遥控页面和这个接口），音频和识别结果都不会上传到任何云服务。

> 想让 Siri 听懂的是**自然语言**而不是固定几个词，就必须用下面的「方案一」：Siri 负责启动快捷指令，句子的内容由快捷指令的「听写文本」采集后再发给播放器。

---

## 0. 前置条件

### SrcBox 端（Windows 电脑）

1. **设置 → Web 远程控制** → 勾选 **启用 Web 远程控制**（默认端口 `8899`），点保存，立即生效，无需重启。
2. 同一页找到 **语音密钥（Token）**：首次启动时自动生成 12 位随机串并写入设置（若之前配过「需要密码访问」，密钥就是那个访问密码）。记下它，下一步要填进快捷指令。
3. 确认电脑的**局域网 IP**：设置页的 **Web 远程控制** 选项卡显示访问地址与二维码，形如 `127.0.0.1:8899` / `192.168.1.100:8899`；用 `ipconfig` 也能看到 IPv4 地址。**不要用 `127.0.0.1`**，手机访问必须用电脑的局域网 IP。
4. **放行防火墙**：Windows 首次会弹出「允许 SrcBox 在此网络通信」的对话框，勾选**专用网络**并允许；如果当时点了取消，到「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」里给 SrcBox 打勾，或手动放行 TCP `8899`。

### iPhone / iPad 端

- iOS 15 或更高（「听写文本」「获取 URL 内容」都是系统自带动作）。
- 手机与电脑在**同一个局域网**（同一个路由器 / 同一个 Wi-Fi）。
- 快捷指令需要 **本地网络访问权限**：第一次运行时会弹窗，必须选「允许」；误点了「不允许」就到 **设置 → 隐私与安全性 → 本地网络** 里重新打开「快捷指令」的开关。

> **不需要装 HTTPS 证书**。局域网内的 `http://192.168.x.x:8899` 对「快捷指令」的请求是放行的；证书只在用 Safari 打开遥控页面、并且要在页面上按麦克风录音时才需要（见 [Web 远程控制](./web-remote#https-与证书)）。

## 1. 与播放器建立连接（先做自检）

在写快捷指令之前，先用手机确认接口通不通。打开手机 Safari，在地址栏输入（把 IP 和 token 换成你自己的）：

```
http://192.168.1.100:8899/api/voice?token=你的密钥&text=现在在播什么
```

看到类似下面的 JSON 就说明通了，并且**播放器已经执行了这条指令**：

```json
{
  "type": "voice",
  "verb": "epg_now",
  "success": true,
  "executed": true,
  "text": "现在在播什么",
  "spoken": "CCTV1 正在播出 新闻联播（19:00-19:30）",
  "options": []
}
```

对不通报错时的含义：

| 返回 | 含义 | 处理 |
|:---|:---|:---|
| `{"success":false,"error":"unauthorized"}`（HTTP 401） | token 不对 | 回到设置页复制**语音密钥**，注意不要带空格 |
| `{"success":false,"error":"forbidden"}`（HTTP 403） | 请求不是来自私有网段 | 手机上关掉 VPN / 代理，确认连的是家里 Wi-Fi |
| `{"success":false,"error":"not_ready"}`（HTTP 503） | Web 遥控还没启用 | 检查「启用 Web 远程控制」是否勾选并已保存 |
| 打不开、超时 | 网络/防火墙 | 见下面的[故障排查](#7-故障排查) |

> 参数用 `&` 分隔（`text` 在前、`token` 在后都可以）。只有在浏览器地址栏里手输时才需要担心中文和空格；**快捷指令会自动做 URL 编码**，这一步不用手工处理。

## 2. 方案一（推荐）：一个快捷指令听你说话

思路：快捷指令自己听写，把听到的整句话发给播放器，语义由 SrcBox 解析。

### 步骤

1. 打开 **快捷指令** App → 右上角 **+** 新建。
2. 添加动作 **听写文本**（Dictate Text）：
   - 语言：**中文（普通话）**（英文口令就选英语，俄语选俄语）
   - **停止聆听**：改为 **暂停后**（不要用「短暂停顿」——Siri 会只截到前两个字）
   - 启用 **语音反馈**（可选）：听写时手机有提示音，手感更好
3. 添加动作 **URL**：
   - 输入（点键盘上方的变量选择器，选「听写文本」的 **听写结果**）：

     ```
     http://192.168.1.100:8899/api/voice?token=你的密钥&text=[听写结果]
     ```

4. 添加动作 **获取 URL 内容**（Get Contents of URL）：
   - URL：选上一步的 **URL**
   - 方法：**GET**
   - 不要在「请求体」里写任何东西；**也不要再往 URL 里加参数**
5. 添加动作 **从输入获取字典值**（Get Dictionary Value）：
   - 获取：**值**；键填 `spoken`（也可以填 `success` / `verb` / `options`）
   - 输入：选「获取 URL 内容」的 **内容**
6. 添加动作 **朗读文本**（Speak Text）：输入选上一步的 **字典值**，语言选中文。这样手机也会把结果念出来；不方便开声音时删掉它或换成 **显示结果** 即可。
7. 点顶部名称，把快捷指令改名为一个**好念的触发词**，例如 `遥控器`、`播放器遥控`（用英文 Siri 就说 `Remote`）。
8. 运行一次：正常的话手机会提示权限（麦克风 / 听写 / 本地网络），全部允许，然后说「换到 2 台」，电脑应该立刻换台。

### 之后的用法

```
你：嘿 Siri，遥控器
Siri：（叮）说完请说：请说
你：回看今天的新闻联播
Siri：（朗读）正在回看 新闻联播
```

**要点：口令必须包含快捷指令的名字**（「嘿 Siri，遥控器」），Siri 只能启动一个快捷指令，它不会把后面那半句自然语言传进去——所以句子交给快捷指令的「听写文本」来听。

## 3. 方案二：一个动作一个快捷指令（真正的「一句话直达」）

方案一每次都要「先喊名字再说话」两步。如果你只想要几个高频动作、且希望**一句话完成**，就为每个动作做一个只含「获取 URL 内容 + 朗读文本」的快捷指令——这时后面那半句就是 Siri 的口令本身，直接被播放器执行。

命名的技巧：**把动作说全**，因为 Siri 是靠名字匹配的。

| 快捷指令名称 | URL |
|:---|:---|
| `换到一台` | `http://192.168.1.100:8899/api/voice?token=密钥&action=channel&target=1` |
| `下一个台` | `…/api/voice?token=密钥&action=channel_step&target=1` |
| `上一个台` | `…/api/voice?token=密钥&action=channel_step&target=-1` |
| `换个源` | `…/api/voice?token=密钥&action=switch_stream` |
| `静音` | `…/api/voice?token=密钥&action=toggle_mute` |
| `音量到40` | `…/api/voice?token=密钥&action=volume_set&target=40` |
| `暂停播放` | `…/api/voice?token=密钥&action=pause` |
| `继续播放` | `…/api/voice?token=密钥&action=play` |
| `停止播放` | `…/api/voice?token=密钥&action=stop` |
| `全屏` | `…/api/voice?token=密钥&action=fullscreen` |

说「嘿 Siri，换到一台」即可，**不需要**再说第二句。

> 这些 `action` 是接口的**免自然语言通道**：不用经过分词和模糊匹配，命中率 100%，适合反应要快、句子又固定的场景。频道号写在 `target` 里即可（`1`、`5`、`12`…）。

想一劳永逸的话，可以用系统里现成的导入方式建这些快捷指令（Siri 会引导你添加动作）：在 iPhone 上打开 `快捷指令 → 新建`，或直接用 iCloud 链接分享给家人；也可以把上表当成清单逐个手建。

## 4. 完整的语音指令清单

方案一（自然语言）能听懂的句子，与遥控页面完全一致：

| 说法 | 结果 |
|:---|:---|
| `湖南卫视` / `CCTV3` / `3 台` / `三台` | 按台名或频道号换台（「2 太 / 2 胎」这类同音字也能纠错） |
| `下一个台` / `上一个台` / `第一个频道` / `最后一个台` | 上下换台、跳到首/末频道 |
| `换源` / `换下一个源` / `换上一路` | 切换当前频道的播放源（线路） |
| `播放列表` / `频道列表` | 切换 M3U 频道数据源 |
| `播放` / `暂停` / `继续` / `停止` | 播放控制 |
| `全屏` / `退出` | 切全屏、退出播放器 |
| `音量 40` / `音量调到 40` | 直接设定音量 |
| `音量加` / `大声点` / `小点` / `音量 30 大点` | 相对调整音量（步进可在设置页配置） |
| `静音` / `取消静音` | 静音开关 |
| `快进 30 秒` / `后退 15 秒` | 相对跳转（回看、时移中生效） |
| `现在在播什么` / `正在播什么` | 播报当前频道正在播出的节目 |
| `回看今天的新闻联播` / `回看昨天的焦点访谈` | 在节目单里找到该节目并开始回看 |
| `回看今天有什么节目` | 不指定频道时扫描全部频道 |

还可以在 **设置 → Web 远程控制 → 语音规则** 里加自己的短语规则（一行一条，`短语 = action:target`），自定义短语优先于内置语法，例如：

```
看球 = channel:5
把声音开到最大 = volume_set:100
```

> 界面语言、语音识别语言、Siri 语言三者建议一致：快捷指令里「听写文本」选中文，SrcBox 设置里的语音语言留空即跟随程序语言。俄语口令（`следующий канал`、`сделай тише`）和英文口令（`next channel`、`volume 40`）同样是内置的。

## 5. 接口参考（`GET /api/voice`）

只读 GET，**限私有网段**（RFC1918 / APIPA / CGNAT / IPv6 ULA 与链路本地）。

| 参数 | 说明 |
|:---|:---|
| `text` | 一句话自然语言指令（中文/英文/俄语），会走完整的解析、纠错与候选逻辑 |
| `action` | 免自然语言的动作名，见下表；与 `target` 搭配 |
| `target` | 动作参数：频道号 / 频道名 / 源名 / 秒数 / 音量值 |
| `token` | 语音密钥，不匹配返回 401；密钥为空时不校验（不建议） |
| `lang` | 覆盖语言（`zh-CN`、`en-US`、`ru-RU`、`zh-TW`），一般省略 |
| `dry` | `dry=1` / `dry=true`：**只解析不执行**，用于做菜单 |

`action` 可用值：

| action | target 示例 | 含义 |
|:---|:---|:---|
| `channel`（同 `switch_channel`、`channel_number`） | `5` 或 `CCTV5` | 换台 |
| `channel_step` | `1` / `-1` / `first` / `last` | 上下/首末台 |
| `switch_stream`（同 `source`、`next_source`） | 源名或 URL，省略则走下一个源 | 换个线路 |
| `playlist`（同 `load_m3u`、`m3u`） | 数据源名或 URL | 换频道列表 |
| `play`（同 `resume`） / `pause` / `stop` | — | 播放控制 |
| `mute`（同 `toggle_mute`） | — | 静音开关 |
| `volume_set`（同 `volume`） | `40` | 设定音量 |
| `volume_step`（同 `volume_up`、`volume_down`） | `10` / `-10` | 相对调整 |
| `fullscreen` / `exit` | — | 全屏 / 退出 |
| `seek` | `30` / `-15` | 相对跳转秒数 |
| `epg_now`（同 `epg`） | 频道号或名，省略为当前频道 | 现在在播什么 |
| `epg_replay`（同 `replay`） | 节目名/时间提示 | 回看 |

返回（`Content-Type: application/json`，`Cache-Control: no-store`）：

```json
{
  "type": "voice",
  "verb": "channel",
  "rule": "action:channel",
  "confidence": 1,
  "success": true,
  "executed": true,
  "text": "5",
  "spoken": "已切换到 CCTV5，5台",
  "options": [
    {
      "kind": 0,
      "id": "cctv5",
      "title": "CCTV5",
      "subtitle": "5台 · 央视频",
      "number": 5,
      "score": 1,
      "action": "channel",
      "payload": { "channelId": "cctv5" }
    }
  ]
}
```

- `spoken` 就是给你朗读 / 播报的那句话，**快捷指令里绑定它**（JSON 是 camelCase）。
- `kind` 是数字：`0` 频道、`1` 源、`2` 频道列表、`3` 节目、`4` 播放器动作。
- 语句有歧义时 `success=true` 而 `executed=false`，`options` 里是候选（最多 12 条），阅读器读到「找到 N 个候选频道，请选择」。手机上不好点选，所以对快捷指令来说**说清楚**（完整台名或频道号）体验最好。
- `dry=1` 时只返回解析结果和候选，不动播放器，适合做「候选菜单」类快捷指令。

## 6. 进阶

**Apple Watch / CarPlay / 耳机**：手表上直接对 Siri 说「嘿 Siri，下一个台」，走的是同一套快捷指令，无需手机解锁（第一次授权后即可）。

**HomePod / Siri 免持**：HomePod 不能访问局域网内的电脑，所以用 iPhone 的 Siri 即可，别指望 HomePod 直连。

**快捷指令放到主屏幕**：把方案一的快捷指令「添加到主屏幕」，点图标即开始听写，等同遥控页面上的麦克风按钮。

**用 `dry=1` 做菜单**：`…&action=channel&target=新闻&dry=1` 返回候选列表，配合「从列表中选取」可以做「说个大概、点一下确认」的流程。

**多台电脑 / 多个房间**：把 URL 里的 IP 换成对应电脑，复制一份快捷指令，命名为 `客厅遥控`、`卧室遥控`。

**和遥控页面配合**：手机浏览器打开 `https://192.168.1.100:8899`（或用 `http://` 打开后点页面右上角全屏）也能说话——页面上的麦克风是**本地离线识别**，逐字上传、不联网。两条路各有用途：

| 方式 | 优点 | 限制 |
|:---|:---|:---|
| 快捷指令 + Siri | 真正免提、息屏也能用、可念回结果 | 需先喊出快捷指令名（方案一）；只能在局域网内 |
| 遥控页面麦克风 | 直接说不用喊名字、彻底不联网 | 要打开页面、不能息屏；`http://192.168.x.x` 下不可用，需装证书走 `https://` |
| 手机键盘听写 | 零配置、随时可用 | 需打开输入框手动点一下 |

## 7. 故障排查

| 现象 | 原因 | 处理 |
|:---|:---|:---|
| 快捷指令报「无法连接到服务器」/ 超时 | 手机和电脑不在同一网段，或防火墙拦了 | 确认同一 Wi-Fi；防火墙放行 SrcBox 或 TCP 8899；手机别开 VPN |
| 快捷指令报「快捷指令想要访问本地网络」并失败 | 权限被拒 | 设置 → 隐私与安全性 → 本地网络 → 打开「快捷指令」 |
| HTTP 401 | token 不一致 | 复制设置页的**语音密钥**；若开过「需要密码访问」，密钥等于那个密码 |
| HTTP 403 | 请求源被判定为公网 | 关掉 VPN/代理；确认请求的是 `192.168.x.x` 这类内网地址 |
| HTTP 503 `not_ready` | Web 遥控未启用 | 勾选「启用 Web 远程控制」并保存 |
| 返回 `success=false`、`spoken` 是「没听懂」 | 句子没命中语法 | 说法见[指令清单](#4-完整的语音指令清单)；也可在设置里加自定义规则 |
| 说了一整句，播放器只收到前两个字 | 「听写文本」用了「短暂停顿」 | 改成 **暂停后**，并把句子连起来说 |
| Siri 说「没有找到名为…的快捷指令」 | 快捷指令名和口令不一致 | 把快捷指令改名成你念的那个词（如 `遥控器`） |
| 方案二说「嘿 Siri，换到一台」没反应 | Siri 只在名字上做匹配 | 名称写成完整动作，或改用方案一 |
| 换了路由器 / IP 变了 | DHCP 重新分配 | 用新 IP 更新快捷指令里的 URL，或给电脑设静态 IP / DHCP 保留 |
| 想确认到底发生了什么 | — | 看 SrcBox 日志：被拒绝的请求会记 `[WebRemote] /api/voice rejected: token mismatch` / `refused: non private address`；识别与执行会记 `[WebRemote] voiceCommand: "…"` |

## 8. 安全提醒

- `token` 就是遥控器密码：**不要把带 token 的 URL 发到群里或截图公开**。密钥泄露就在 **设置 → Web 远程控制** 里清空「语音密钥」并保存，重启后会自动生成新的（旧链接立即失效）。
- 接口**只接受私有网段**的请求，公网无法直接访问；不要为了让外面能用而做端口映射（`/api/voice` 是明文 HTTP，也无速率限制）。
- 可选加固：勾选「需要密码访问」并把密码设复杂一点，语音密钥会直接复用该密码；同时遥控页面也会要求登录。
- 不放心可以随时整体关掉：「启用 Web 远程控制」取消勾选并保存，接口即停。
