# 用安卓语音控制播放器（助手 + 自定义命令）

> **前置阅读**：[用苹果语音控制播放器](./apple-voice-control)。苹果走的是「快捷指令 + Siri」；安卓没有统一的入口，**厂商助手各不相同**，所以这条路要按你的手机品牌挑一条走。两篇教程用的是**同一个接口** `/api/voice`，指令、token、返回格式完全一致。

安卓的核心思路只有一句：**让手机的语音助手执行一条自定义命令，这条命令把整句话发给播放器。**

```
你说话 → 手机内置助手（小爱 / 小艺 / Bixby / Gemini / Jovi…）→ 自定义命令
      → 打开一个链接 或 调用自动化 App 发一个 HTTP 请求 → GET /api/voice?text=…&token=…
      → SrcBox 本机解析并执行 → 返回 JSON → 手机朗读 / 自动打开遥控页面
```

> 安卓与苹果最大的差别：安卓助手**不支持**「先启动一个动作、再听你补一句话」。所以要么一句话直达（自定义命令），要么用自动化 App 的「弹输入框 → 听写」补上第二步（第 2 章）。下面第 0 章先帮你判断手机支持哪条路。

---

## 0. 统计：你的手机走哪条路

### 0.1 三种接法的能力对比

| 接法 | 需要装什么 | 能否带一句自由说的话 | 是否联网 | 适合谁 |
|:---|:---|:---|:---|:---|
| **A. 助手自定义命令 → 打开链接** | 不装（用浏览器 / 主屏图标） | 不能，命令即动作 | 只需局域网 | 只想说几句固定话，零成本 |
| **B. 助手自定义命令 → 快捷指令类 App** | 一个「HTTP 快捷方式」App | **能**（App 内听写 / 弹窗） | 只需局域网 | 想要「换到 5 台」「回看…」这类自由说法 |
| **C. 智能家居 / 例程自动化** | 需要账号与云 | 能（走平台语音解析） | **需要公网** | 家里已有智能家居中枢，且愿意开放外网 |

**推荐顺序：A（先跑通）→ B（追求自由说法）→ C 只在你有智能家居平台且懂端口映射时才考虑。** 本教程重点写 A 与 B，因为它俩全程局域网、不把遥控口令交给云端。

### 0.2 厂商助手对照表

| 厂商 / 助手 | 添加自定义命令的位置（名称可能随版本微调） | 能执行的动作 | 结论 |
|:---|:---|:---|:---|
| 小米 / 红米 · 小爱同学 | 小爱同学 App → 训练计划 / 自定义指令（部分版本在「技能 → 我的技能」） | 打开应用、打开网页、控制米家设备 | **A 可行**；较新版本也能打开应用后由 B 接管 |
| 华为 / 荣耀 · 小艺 | 智慧语音 → 我的 → 自定义指令（部分版本并入「场景」/「智慧生活」自动化） | 打开应用、打开网页、系统开关 | **A 可行**（个别版本只允许打开应用 → 用 B） |
| 三星 · Bixby | Bixby → 日常程序（Routines）→ 添加「若『说出自定义命令』则…」 | 打开应用、打开网页、系统设置、部分 App 动作 | **A 可行**，Bixby 的日常程序触发条件最规范 |
| 一加 / OPPO / realme · 小布 | 小布助手 → 我的 → 自定义指令 / 快捷指令 | 打开应用、打开网页 | **A 可行** |
| vivo / iQOO · Jovi | Jovi → 我的 → 自定义指令 | 打开应用、打开网页 | **A 可行** |
| 原生 / 多数海外机 · Google Assistant / Gemini | 原生助手**没有**自定义命令入口 | — | **只能走 B 或 C**：用助手打开一个 App（如「打开 HTTP 快捷方式」）再由 B 完成 |
| 任何安卓 + 无障碍/语音访问 | 系统「语音访问」、「随选朗读」等 | 点按屏幕元素 | 兜底方案，见第 5 章 |

> 只要在 0.2 里找到你的助手有「自定义指令 / 训练计划 / 日常程序」，就走 A 或 B；表里没有你的品牌，先在助手设置里搜「自定义」「指令」「快捷」「例程」四个词，出现任何一个就能用。

### 0.3 通用前置条件

来源与苹果教程完全一致，只有第 3 条不同：

1. 电脑：**设置 → Web 远程控制** → 勾选 **启用 Web 远程控制**（端口默认 `8899`），保存。
2. 记下同一页的**语音密钥（Token）**，以及电脑的**局域网 IP**（形如 `192.168.1.100`，别用 `127.0.0.1`）。
3. 电脑防火墙放行 SrcBox 或 TCP `8899`；手机与电脑在**同一局域网**（安卓助手多数不需要「本地网络权限」，但浏览器与自动化 App 需要联网权限，正常安装即有）。
4. 手机浏览器先做一次自检（见下一节）。

### 0.4 自检接口

用手机 Chrome 打开：

```
http://192.168.1.100:8899/api/voice?token=你的密钥&text=现在在播什么
```

出现 `{"success":true,…,"spoken":"…"}` 就说明通了，而且播放器会真的执行。

| 返回 | 含义 | 处理 |
|:---|:---|:---|
| `HTTP 401` / `unauthorized` | token 不对 | 复制设置页**语音密钥**，注意别带空格 |
| `HTTP 403` / `forbidden` | 请求不是来自私有网段 | 关掉 VPN / 代理再试 |
| `HTTP 503` / `not_ready` | Web 遥控没启用 | 回去勾选并保存 |
| `HTTP 400` / `missing_text` | 既没 `text` 也没 `action` | 至少带一个 |
| 打不开 / 超时 | 网络或防火墙 | 见第 7 章 |

> 手输中文和空格时浏览器会自动编码；**在自动化 App 里手填 URL 就必须自己编码**（规则与编码结果见 2.4）。

## 1. 接法 A：助手自定义命令 → 打开链接（零安装，先跑通）

原理：助手听出你预设的那句话，就去打开一个网址。而这个网址就是 `/api/voice`，打开即执行。

### 1.1 步骤

1. **准备 IP 与密钥**：`192.168.1.100`、`token=ab12cd34ef56`。
2. **加一条自定义命令**（位置见 0.2 表）。命名与动作示例：

   | 命令名称（你念的话） | 动作 | 目标 |
   |:---|:---|:---|
   | `下一个台` | 打开网页 / 打开链接 | `http://192.168.1.100:8899/api/voice?token=ab12cd34ef56&action=channel_step&target=1` |
   | `上一个台` | 打开网页 | `…&action=channel_step&target=-1` |
   | `音量小一点` | 打开网页 | `…&action=volume_step&target=-10` |
   | `声音大一点` | 打开网页 | `…&action=volume_step&target=10` |
   | `静音` | 打开网页 | `…&action=toggle_mute` |
   | `暂停` | 打开网页 | `…&action=pause` |
   | `换到湖南卫视` | 打开网页 | `…&action=channel&target=%E6%B9%96%E5%8D%97%E5%8D%AB%E8%A7%86` |
   | `现在在播什么` | 打开网页 | `…&text=%E7%8E%B0%E5%9C%A8%E5%9C%A8%E6%92%AD%E4%BB%80%E4%B9%88` |

3. **把浏览器变成「隐形执行器」**：
   - 有些助手只允许「打开应用 / 打开网页」，那就选打开网页，浏览器会闪现一下再回来，属于正常现象。
   - 想更干净：把遥控页面**添加到主屏幕**（Chrome 菜单 →「安装应用 / 添加到主屏幕」），命令改成打开这个图标，页面会以独立窗口出现，还能顺手看到播放状态。
4. **试一句**：「小爱同学，下一个台」「Bixby，音量小一点」。播放器应立刻响应。

> **为什么用 `action=` 而不是 `text=`**：`action` 是接口的**免自然语言通道**，不过分词和模糊匹配，命中率 100%，最适合「一句话=一个固定动作」的助手命令。想按台名换台就写 `action=channel&target=台名（已 URL 编码）`。

### 1.2 适合与不适合

- **适合**：音量、上下台、暂停、静音、换源、全屏——十来条固定命令覆盖日常。
- **不适合**：`换到 12 台`、`回看昨天的焦点访谈` 这类**每次都不一样**的说法。助手只能匹配你预先写好的整句话，所以要用下面的接法 B。

## 2. 接法 B：助手 → 快捷指令类 App（能带一句自由说的话）

原理：助手只负责**打开一个自动化 App**，真正的工作交给 App：App 弹出输入框（或直接听写），把你说的话发给播放器，再把 `spoken` 念出来。

### 2.1 选一个 App

| App | 语言 | 特点 | 适合 |
|:---|:---|:---|:---|
| **HTTP Shortcuts**（免费、开源） | 中文 | 专做「发一个 HTTP 请求」，支持变量、输入框、响应 JSON 取值、朗读、导出/导入 | **首选**，本教程以它为例 |
| **MacroDroid**（免费 + 少量广告） | 中文 | 触发器极多（含「快捷方式」「语音」触发），有 HTTP 请求动作，能配合「输入对话框」+ 变量 | 想连「连接家里 Wi-Fi 就自动换源」这类联动 |
| **Tasker**（付费） | 英文为主 | 最强，HTTP Request + AutoInput + 语音输入都能编 | 已经买了 Tasker、喜欢折腾 |

### 2.2 HTTP Shortcuts 的做法（最省事）

1. 装好后新建一个快捷方式，名称填 `遥控器`；**添加一个「请求文本 / 文本输入」变量**，变量名写 `text`，提示写「说指令」。
2. 加一个 **HTTP 请求** 步骤：
   - 方法：`GET`
   - URL：`http://192.168.1.100:8899/api/voice`
   - 参数：`token` = `你的密钥`，`text` = `{{text}}`（选刚才那个变量）
3. 加一个 **脚本 / JSON 取值** 步骤：从响应里取出 `spoken` 字段。
4. 加一个 **朗读文本（Text to Speech）** 步骤：内容填上一步取到的 `spoken`。
5. 保存，然后在**系统设置 → 应用 → 默认应用 → 辅助/快捷方式**允许它被助手唤起；或用「添加到主屏幕」放一个图标。
6. 手机助手里再加一条自定义命令：`遥控器` → 打开应用「HTTP 快捷方式」并执行该快捷方式（部分助手可选「打开指定快捷方式」；不能选就到第 2.3 节）。

之后再配一条**纯动作**的快捷方式（不带输入框、URL 里直接写 `action=...`），就能做到「小爱同学，下一个台」一句话直达。

### 2.3 助手只能「打开应用」，传不进参数怎么办

这是安卓最常见的卡点，两个现成办法：

- **办法一（省事）**：打开 App 后让它**先听写**。HTTP 快捷方式支持把「文本输入」变量的来源设为语音输入（或调用系统听写键盘的麦克风键），你打开后说一句即可。
- **办法二（全自动）**：用 MacroDroid 搭一条宏：
  1. 触发器：**应用启动**（HTTP 快捷方式 / 遥控页面）；
  2. 动作：**输入对话框**（文本变量 `text`）；
  3. 动作：**HTTP 请求 GET** `…/api/voice?token=…&text=[text]`（MacroDroid 会自动 URL 编码变量）；
  4. 动作：**朗读** 响应里的 `spoken`（用 JSON 取值）。
  这样助手的命令就是「打开遥控器」，后面那句你说什么都能被处理。

> **兜底**：如果连输入对话框都不想点，可让 MacroDroid 直接读**系统语音输入**（它带「语音输入」动作/插件），实现「说一句 → 直接发出去」。

### 2.4 URL 编码对照（手填 URL 时用）

中文与空格不能直接写进 URL，要转成 `%XX`。常用例子：

| 你说的话 | 编码结果 |
|:---|:---|
| `换到5台` | `%E6%8D%A2%E5%88%B05%E5%8F%B0` |
| `现在在播什么` | `%E7%8E%B0%E5%9C%A8%E5%9C%A8%E6%92%AD%E4%BB%80%E4%B9%88` |
| `回看今天的新闻联播` | `%E5%9B%9E%E7%9C%8B%E4%BB%8A%E5%A4%A9%E7%9A%84%E6%96%B0%E9%97%BB%E8%81%94%E6%92%AD` |
| `Следующий канал`（俄语） | `%D0%A1%D0%BB%D0%B5%D0%B4%D1%83%D1%8E%D1%89%D0%B8%D0%B9%20%D0%BA%D0%B0%D0%BD%D0%B0%D0%BB` |

自制办法：把话粘进任意「URL 编码」在线工具，或用电脑 PowerShell 跑一行：

```powershell
[uri]::EscapeDataString('换到5台')   # -> %E6%8D%A2%E5%88%B05%E5%8F%B0
```

> **不要把已经编码的串再编码一次**，否则播放器收到的是 `%E6%8D%A2…` 字面量，只会回「没听懂」。

## 3. 接法 C：智能家居 / 例程自动化（需要外网）

有些人的家里已经有米家、华为智慧生活、Google Home 这类中枢，希望「一句话顺便控制播放器」。这条路可行，但要清楚代价：

| 平台 | 大致做法 | 代价 |
|:---|:---|:---|
| Google Home / Gemini | 用 IFTTT 之类的连接器，让「我说某句话」触发一个 Webhook 去请求 `http://你的公网地址:端口/api/voice?...` | 需要把端口映射到公网（**接口是明文 HTTP、无限速、无失败锁定**），IFTTT 还多一个云账号 |
| 米家 / 华为智慧生活 | 平台的自动化只能调用平台内设备，请求外部 URL 一般要中转服务 | 同上，且规则编辑器通常不开放 HTTP |

**如果你要走 C，务必先做两件事**：

1. 在路由器上**只**给这一个端口做映射，并确认 SrcBox 的「需要密码访问」已开启、密码足够强；
2. 更稳的做法是**把请求接到家里已有的中转设备**（NAS / Home Assistant / 树莓派），由它在局域网内请求 `http://192.168.x.x:8899/api/voice`，公网只暴露中转设备。

**更建议的方案**：不开放任何外部访问——把第 1 章的助手自定义命令（局域网直连）用起来，就已经能满足日常 95% 的口头指令。

## 4. 各品牌设置速查

| 品牌 | 一步步路径 |

| 小米 / 红米 | 小爱同学 → 右下「我的」→ 训练计划（或「技能 → 我的技能」）→ 新建 → 「当我说」填口令 → 「小爱执行」选**打开应用 / 打开网页** → 填上面表里的 URL |

## 5. 进阶

**免提、不用喊命令名（推荐进阶用法）**：把遥控页面装成主屏应用后，页面里的语音面板用的是 **WebView 里的系统语音识别**（安卓由系统/Google 提供，可设为离线识别，音频不出手机）。再让助手把「打开遥控器」当成自定义命令，就成了「说一句 → 页面打开 → 直接说指令」的免提链路。注意：以 `http://192.168.x.x` 打开时浏览器会视为非安全上下文，麦克风按钮可能不可用；装一次自签证书改用 `https://` 即可（见 [Web 远程控制](./web-remote#https-与证书)）。

**一次说完整句（接法 B 的高级玩法）**：在 HTTP 快捷方式里把变量来源设为「语音输入」，则「小爱同学，遥控器」打开 App 后你直接说「回看昨天的焦点访谈」，识别与会话由 HTTP 快捷方式负责，播放器只做语义解析——这等价于苹果端的方案一。

**多台电脑 / 多个房间**：复制一份快捷方式或自定义命令，把 IP 改掉，命名 `客厅遥控`、`卧室遥控`。

**候选菜单**：URL 里加 `&dry=1` 只解析不执行，返回候选列表（最多 12 条）。适合做「说个大概 → 屏幕列出来 → 点一下确认」的流程。

**联动场景**：MacroDroid / Tasker 里可以把「连接家里 Wi-Fi」当触发条件，自动把遥控 URL 里的 IP 换成当前网段，出门在外也不会请求错地址。

## 6. 故障排查

| 现象 | 原因 | 处理 |
|:---|:---|:---|
| 助手说「还没学会这个技能」 | 自定义命令没保存 / 口令不一致 | 检查命令名与你念的话逐字一致；部分助手要求先唤醒再念 |
| 浏览器打开了，但播放器没反应 | URL 里的中文没编码，或 token 写错 | 按 2.4 编码；对照 0.4 的自检表看返回码 |
| 助手把整句当成搜索词 | 动作选成了「搜索」而不是「打开网页」 | 在自定义命令里把动作改成打开网页/打开链接 |
| `HTTP 401` | token 不对（或含空格） | 回设置页复制语音密钥 |
| `HTTP 403` | 手机走了 VPN / 代理 | 关闭 VPN、代理或分流规则后重试 |
| `HTTP 503 not_ready` | Web 遥控没启用 | 勾选「启用 Web 远程控制」并保存 |
| 说了一整句却只处理了前两个字 | App 的语音输入设了「说完即停」的短超时 | 改成手动结束或加长静默超时 |
| 首次请求很慢甚至超时 | 手机在 Wi-Fi 与移动数据之间切换 | 固定 Wi-Fi，或给电脑设静态 IP / DHCP 保留 |
| 换路由器后失效 | IP 变了 | 更新命令里的 IP，或设 DHCP 保留 |
| 想查原因 | — | SrcBox 日志：`[WebRemote] /api/voice rejected: token mismatch`、`refused: non private address`、`voiceCommand: "…"` |

## 7. 安全提醒

- `token` 就是遥控器密码，**别把带 token 的 URL 发群或截图**；泄露后到 **设置 → Web 远程控制** 清空「语音密钥」保存，重启后自动换新（旧链接立刻失效）。
- 接口**只接受私有网段**请求，公网进不来；第 3 章的端口映射是你**主动**放弃这层保护，能不做就不做。
- 建议勾选 **需要密码访问**（语音密钥会复用该密码），并把手机上的自动化 App 加应用锁，避免别人拿你手机就能换台。
- 不用了随时整体关掉：取消「启用 Web 远程控制」并保存。
