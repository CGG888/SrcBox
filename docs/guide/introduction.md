# 项目介绍

**源匣 (SrcBox)** 是一款专为 Windows 平台打造的高性能、现代化 IPTV 播放器。基于强大的 **libmpv** 播放内核，结合 **WPF** 现代化界面设计，为用户提供流畅、稳定的直播观看体验。

## 核心特性

### FCC 极速切台
针对 IPTV 场景深度优化的快速切台技术，实现毫秒级频道切换，告别传统播放器的漫长等待。

### M3U + EPG
- 支持本地/远程 M3U 播放列表
- 完整 XMLTV (gz) 电子节目单
- 自动按日切换，智能节目匹配

### 时移与回看
- 实时拖动回看直播历史
- 基于模板自动生成回放链接
- 快进快退限制在节目边界内

### 多屏播放
支持 4/6/9 屏幕同时观看，数字键快速切换，适合监控或多任务场景。

### 预约录制
- 前台/后台双模式录制
- 定时自动停止
- WebDAV 云端同步

### Web 远程控制
通过浏览器随时随地远程操控播放器，支持播放控制、音量调节、频道切换。

## 技术架构

| 层级 | 组件 | 说明 |
|------|------|------|
| 播放内核 | libmpv-2.dll | 高性能跨平台播放器内核 |
| 渲染层 | WindowsFormsHost | 承载 mpv 窗口句柄嵌入 WPF |
| UI 框架 | WPF + ModernWpf | 现代化 Windows 界面 |
| 服务层 | M3U/EPG/Recording | 核心业务服务 |

| 技术选型 | 说明 |
|----------|------|
| 语言 | C# (.NET 8) |
| UI 框架 | WPF + ModernWpf |
| 播放内核 | libmpv |
| 硬件解码 | D3D11VA / DXVA2 / NVDEC |
| 远程控制 | WebSocket + HTTP |
| 录播同步 | WebDAV |
| 文档站点 | VitePress |

## 功能一览

### 播放功能
- 播放/暂停/停止/快进/快退
- 音量调节 + 静音
- 音频延迟调节 (-100s~+100s)
- 倍速播放 (0.5×~5.0×)

### 频道管理
- 分组管理，支持排序
- 快速搜索
- 收藏常用频道
- 播放历史记录

### 画面优化
- 硬件解码自动切换
- 去交错处理 (1080i/720i)
- 自动换源

### 界面特色
- 深色/浅色主题自适应
- 多屏播放 (4/6/9 屏幕)
- 侧边抽屉 (频道列表/EPG)
- 精简模式窗口

### 多语言
- 简体中文
- 繁体中文
- English
- Русский
