# Web 远程控制

SrcBox 提供 Web 远程控制功能，允许您通过浏览器远程操控播放器，实现播放控制、音量调节、频道切换、回看、预约录制等完整操作。

## 功能概述

Web 远程控制基于 WebSocket 和 HTTP 协议实现，支持以下功能：

- **播放控制**：播放、暂停、停止
- **进度控制**：快进、快退、跳转
- **音量调节**：音量增减、静音
- **频道切换**：上下换台、频道列表、频道搜索
- **回看功能**：时移回看、节目回看
- **预约功能**：预约提醒、预约录制（前台/后台）
- **源管理**：添加、选择、删除播放源
- **状态查看**：当前播放状态、节目信息、EPG节目单
- **多语言支持**：中文、英文、俄文、土耳其文

## 启用远程控制

1. 打开 SrcBox 设置窗口
2. 切换到 **Web 远程控制** 选项卡
3. 勾选 **启用 Web 远程控制**
4. （可选）设置访问端口（默认 8899）
5. （可选）启用密码保护，设置访问密码
6. 点击 **保存** 按钮

## 访问远程控制

启用后，在浏览器中访问：

```
http://localhost:8899
```

如果是本机访问，直接使用 `localhost`。如果是局域网远程访问，请将 `localhost` 替换为 SrcBox 所在电脑的 IP 地址，例如：

```
http://192.168.1.100:8899
```

## 界面说明

### 状态显示区

- 当前播放模式（直播/回看/时移/录制/已停止）
- 当前频道名称和 Logo
- 当前节目名称和播放时间

### 播放控制区

| 按钮 | 功能 |
|------|------|
| 全屏 | 切换全屏模式 |
| 播放 | 开始播放 |
| 暂停 | 暂停播放 |
| 停止 | 停止播放 |
| 静音 | 切换静音状态 |
| 上一频道 | 切换到上一个频道 |
| 下一频道 | 切换到下一个频道 |
| 切换源 | 切换播放源 |
| 退出 | 关闭播放器 |
| 刷新 | 刷新状态数据 |

### 快捷控制区

| 按钮 | 功能 |
|------|------|
| 时移开关 | 开启/关闭时移模式 |
| -10s | 快退 10 秒 |
| +10s | 快进 10 秒 |
| 0.5x | 0.5 倍速播放 |
| 1x | 正常倍速 |
| 2x | 2 倍速播放 |

### 音量控制区

- 音量滑块：调节音量大小
- 静音按钮：切换静音状态

### 频道列表

- 显示所有可用频道和收藏频道
- 点击频道名称即可切换播放
- 收藏频道以星标显示在列表顶部

### EPG 节目单

- 显示当前频道的节目列表（默认显示当天节目）
- 点击节目可进入回看
- 支持三种操作按钮：
  - **回看**（紫色）：回看已播出的节目
  - **时移**（蓝色）：时移当前节目
  - **预约**（绿色）：预约未来节目提醒
  - **录制**（橙色）：预约前台录制

### 节目单 Badge 说明

| Badge | 颜色 | 含义 |
|-------|------|------|
| LIVE | 红色 | 正在直播 |
| 回看 | 紫色 | 当前正在回看 |
| 预约 | 绿色 | 已设置预约提醒 |
| 下一节目 | 橙色 | 下一个即将播出 |

### 源管理（需展开）

- 显示所有已保存的播放源
- 显示源的健康状态（绿色=正常，红色=失败）
- 支持选择、添加、删除源

### 预约管理（需展开）

- 显示所有已设置的预约
- 支持取消预约
- 显示预约频道、节目名称、时间、动作类型

### 录制管理（需展开）

- 显示所有录制任务
- 支持停止正在录制的任务
- 支持删除已完成/失败的录制

## 安全设置

### 密码保护

启用密码保护后，访问远程控制页面需要输入密码：

1. 在设置中勾选 **需要密码访问**
2. 设置访问密码
3. 保存设置

访问时需要输入密码才能使用远程控制功能。

### 注意事项

- 默认情况下，远程控制仅允许本地访问（localhost）
- 如需局域网访问，请确保防火墙允许对应端口
- 建议启用密码保护以确保安全
- 更改端口后需要刷新浏览器页面

## WebSocket API 参考

除了浏览器界面操作外，还可以通过 WebSocket API 进行编程控制。

### 连接方式

```javascript
const ws = new WebSocket('ws://localhost:8899');
```

### 认证（需要密码时）

```json
// 发送
{ "action": "auth", "password": "your_password" }

// 接收
{ "success": true, "requireAuth": true }
```

### 通用响应格式

所有操作成功后返回 JSON 响应，失败返回 `{ "error": "错误信息" }` 或 `{ "success": false }`。

### API 列表

#### 播放控制

| Action | 参数 | 说明 |
|--------|------|------|
| `play` | - | 播放/继续播放 |
| `pause` | - | 暂停播放 |
| `stop` | - | 停止播放 |
| `volume` | `volume` (0-100) | 设置音量 |
| `fullscreen` | - | 切换全屏 |
| `seek` | `seconds` (+/-数值) | 跳转秒数 |

#### 频道控制

| Action | 参数 | 说明 |
|--------|------|------|
| `channel` | `channelId` | 切换频道 |
| `prevChannel` | - | 上一个频道 |
| `nextChannel` | - | 下一个频道 |

#### 速度控制

| Action | 参数 | 说明 |
|--------|------|------|
| `setSpeed` | `speed` (0.5/1.0/2.0) | 设置播放倍速 |
| `setTimeshift` | `enabled` (true/false) | 开启/关闭时移 |

#### 回看功能

| Action | 参数 | 说明 |
|--------|------|------|
| `replayProgram` | `channelId`, `programTitle`, `start` (ISO), `end` (ISO) | 回看指定节目 |

#### 状态查询

| Action | 返回 | 说明 |
|--------|------|------|
| `getStatus` | `{ playing, mode, channel, volume, ... }` | 获取播放状态 |
| `getChannels` | `{ groups: [...], favorites: [...] }` | 获取频道列表 |
| `getEpg` | `{ channelId, programs: [...] }` | 获取节目单 |
| `getSources` | `{ sources: [...] }` | 获取播放源列表 |
| `getReminders` | `{ reminders: [...] }` | 获取预约列表 |
| `getRecordings` | `{ recordings: [...] }` | 获取录制列表 |

#### 预约管理

| Action | 参数 | 说明 |
|--------|------|------|
| `addReminder` | `channelId`, `startAt` (ISO), `endTime` (ISO), `action`, `programTitle`, `preAlertSeconds`, `recordDurationMin` | 添加预约 |
| `cancelReminder` | `id` | 取消预约 |

#### 录制管理

| Action | 参数 | 说明 |
|--------|------|------|
| `stopRecording` | `id` | 停止录制 |
| `deleteRecording` | `id` | 删除录制 |

#### 源管理

| Action | 参数 | 说明 |
|--------|------|------|
| `selectSource` | `name` 或 `url` | 选择播放源 |
| `addSource` | `name`, `url` | 添加播放源 |
| `removeSource` | `name` 或 `url` | 删除播放源 |
| `prevSource` | - | 上一个源 |
| `nextSource` | - | 下一个源 |

#### 其他

| Action | 参数 | 说明 |
|--------|------|------|
| `exit` | - | 关闭播放器 |
| `switchSource` | - | 切换源 |

## 故障排除

### 无法访问远程控制页面

1. 确认已在设置中启用 Web 远程控制
2. 检查端口是否被占用（默认 8899）
3. 检查防火墙设置
4. 确认 SrcBox 播放器正在运行

### 页面显示空白

1. 尝试刷新页面
2. 清除浏览器缓存
3. 使用其他浏览器访问
4. 检查是否启用了密码保护

### 操作无响应

1. 确认 SrcBox 播放器正在播放
2. 检查网络连接是否正常
3. 尝试重新启动 SrcBox 播放器

## 技术实现

Web 远程控制采用以下技术：

- **WebSocket**：实时双向通信，用于播放控制指令
- **HTTP**：状态查询和静态资源服务
- **JSON**：数据交换格式
- **原生 HTML/CSS/JS**：无外部依赖

服务端默认监听端口 8899，Web 界面通过浏览器访问，无需额外安装软件。
