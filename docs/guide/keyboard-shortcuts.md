# 键盘快捷键

SrcBox 支持丰富的键盘快捷键，方便在观看直播时实现盲操作。

## 播放控制

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Space` | 播放/暂停 | 切换播放状态 |
| `S` | 停止播放 | 停止当前播放 |

## 频道切换

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `↑` | 上一频道 | 切换到上一个频道 |
| `↓` | 下一频道 | 切换到下一个频道 |
| `←` | 上一源 | 直播模式下切换到上一个播放源 |
| `→` | 下一源 | 直播模式下切换到下一个播放源 |

## 时移与回看

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `←` | 快退 | 时移/回看模式下快退 10 秒 |
| `→` | 快进 | 时移/回看模式下快进 10 秒 |

> **注意**：左右键的行为根据当前播放模式自动切换：
> - 直播模式：切换播放源
> - 时移/回看模式：快进快退

## 音量控制

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `M` | 静音 | 切换静音状态 |
| `=` / `+` | 音量增加 | 调高音量 |
| `-` / `Num-` | 音量减少 | 调低音量 |

## 界面控制

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Enter` | 全屏切换 | 进入/退出全屏模式 |
| `L` | 频道列表 | 显示/隐藏频道列表侧边栏 |
| `Ctrl+Shift+L` | 精简模式 | 切换精简播放器窗口 |
| `E` | EPG 节目单 | 显示/隐藏 EPG 电子节目单 |

## 录制控制

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `R` | 开始/停止录制 | 控制录制开始或停止 |

## 多屏播放 (v1.1.9 新增)

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+4` | 4屏模式 | 打开 4 屏幕多屏播放 |
| `Ctrl+6` | 6屏模式 | 打开 6 屏幕多屏播放 |
| `Ctrl+9` | 9屏模式 | 打开 9 屏幕多屏播放 |
| `1-9` | 选择屏幕 | 多屏播放中选择对应小屏幕 |
| `↑/↓` | 切换频道 | 多屏播放中切换上一/下一频道 |
| `←/→` | 切换源 | 多屏播放中切换上一个/下一个源 |

## 全屏模式专用

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Escape` | 退出全屏 | 从全屏模式返回窗口模式 |

## 其他

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `F1` | 调试窗口 | 打开调试信息窗口 |
| `Ctrl+,` | 设置 | 打开设置窗口 |
| `Ctrl+I` | 关于 | 打开关于对话框 |
| `Ctrl+/` | 快捷键说明 | 打开快捷键帮助窗口 |

## 常见问题

**Q: 为什么按左右键有时候是切换频道，有时候是快进快退？**

A: 左右键的行为是智能切换的：
- 在观看直播时，左右键用于切换播放源（适合多源频道）
- 在时移或回看模式下，左右键变为快进快退
- 在多屏播放模式下，左右键用于切换源

**Q: 快捷键在窗口模式和全屏模式下都生效吗？**

A: 是的，所有快捷键在窗口模式和全屏模式下都通用（`Escape` 仅在全屏模式下有效）。

**Q: 多屏播放的快捷键怎么使用？**

A: 打开多屏播放后，直接按 1-9 数字键选择对应屏幕，选中后即可使用 ↑↓ 切换频道、←→ 切换源。

**Q: 如何快速打开设置窗口？**

A: 按 `Ctrl+,` 即可快速打开设置窗口。
