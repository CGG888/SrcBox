# 常见问题 (FAQ)

## 播放问题

**Q: 有画面无声音怎么办？**
A: 部分 IPTV 源音频探测较慢，已设置 `probesize=32` 加速起播，可能导致短暂无声。可尝试：
- 切换音轨（如果有多音轨）
- 重启播放
- 检查系统音量设置

**Q: 频道切换很慢怎么办？**
A: 确保开启了 FCC 快速切台功能（设置 > 播放 > FCC 快速切台）。如仍慢，可尝试：
- 启用硬件解码（D3D11VA）
- 检查网络延迟
- 关闭 UDP 组播优化（如果不需要）

**Q: 播放卡顿/缓冲怎么办？**
A: 尝试以下方法：
- 切换解码器（自动/D3D11VA/DXVA2/NVDEC/软件）
- 检查网络稳定性
- 降低视频质量期望（部分源有限制）
- 尝试自动换源功能

**Q: 全屏后如何显示控制条？**
A: 鼠标移动到屏幕底部即可显示悬浮控制条，自动隐藏时间可在设置中调整。

## M3U 与播放列表

**Q: 如何加载 M3U 播放列表？**
A: 点击顶部菜单“打开 > 打开 M3U 文件”或“打开 > 打开 M3U URL”，支持本地文件和网络地址。

**Q: 支持哪些 M3U 格式？**
A: 支持标准 M3U/M3U8 格式，兼容 UTF-8 和 GB18030 编码，支持 `#EXTINF` 扩展属性（如 logo、分组信息）。

**Q: TXT 格式的频道列表可以用吗？**
A: 可以，TXT 格式每行一个 URL，程序会自动识别。

**Q: M3U 缓存是永久的吗？**
A: 不是，M3U 缓存默认 12 小时（可通过设置中的 `M3uCacheTtlHours` 调整）。可通过“管理 M3U 列表”强制刷新。

## EPG 电子节目单

**Q: EPG 显示“无数据”怎么办？**
A: 请检查：
- XMLTV URL 是否可正常访问
- 是否为 GZIP 压缩格式（.gz）
- `tvg-id` 是否与 M3U 中的频道匹配
- 网络是否能访问 EPG 数据源

**Q: 如何配置 EPG？**
A: 在设置窗口的“EPG”标签页中填入 XMLTV URL，支持本地文件和网络地址。

**Q: 节目单时间不准怎么办？**
A: 检查系统时区设置是否正确，EPG 数据依赖本地时间计算节目排期。

## 录制功能

**Q: 如何开始录制？**
A: 按 `R` 键或点击录制按钮开始录制，再次按下停止。

**Q: 录制的文件保存在哪里？**
A: 默认保存在“文档\SrcBox\Recordings”目录，可在设置中修改。

**Q: 支持 WebDAV 上传吗？**
A: 支持。在设置中配置 WebDAV 服务器地址、用户名和密码后，录制完成会自动上传。

**Q: 前台录制和后台录制有什么区别？**
A:
- **前台录制**：录制时画面跳转到正在录制的频道，显示录制计时器
- **后台录制**：保持当前播放频道，不跳转录制，录制完成显示 Toast 通知

## 回看与时移

**Q: 时移功能怎么用？**
A: 按 `T` 键进入时移模式，拖动进度条回看直播历史。再次按 `T` 返回直播。

**Q: 回放 (Catchup) 怎么用？**
A: 需要频道支持 `catchup-source` 属性。EPG 中点击已播节目即可回看。

**Q: 时移能回看多久？**
A: 取决于频道服务器的 `catchup-source` 配置和时移缓冲区设置。

## 多屏播放

**Q: 如何开启多屏模式？**
A: 按 `Ctrl+4`/`Ctrl+6`/`Ctrl+9` 分别打开 4/6/9 屏幕模式。

**Q: 多屏模式下如何切换频道？**
A: 使用 `1-9` 数字键选择屏幕，`↑/↓` 切换频道，`←/→` 切换源。

## Web 远程控制

**Q: 如何开启 Web 远程控制？**
A: 在设置中启用 Web 远程控制，按提示设置端口和密码（可选）。

**Q: 如何访问 Web 远程控制？**
A: 在同一局域网内的浏览器中输入 `http://播放器电脑IP:端口号`。

## 快捷键

**Q: 常用快捷键有哪些？**
A:
| 快捷键 | 功能 |
|--------|------|
| `Space` | 播放/暂停 |
| `S` | 停止 |
| `↑/↓` | 上一/下一频道 |
| `M` | 静音 |
| `Enter` | 全屏切换 |
| `L` | 频道列表 |
| `E` | EPG 节目单 |
| `R` | 开始/停止录制 |
| `T` | 时移模式 |
| `Ctrl+,` | 设置 |
| `Ctrl+/` | 快捷键帮助 |

## 故障排查

**Q: 程序启动即崩溃？**
A: 请确保 `libmpv-2.dll` 已放置在程序运行目录。

**Q: 设置不保存？**
A: 确保程序目录有写入权限，或尝试以管理员身份运行。

**Q: 如何反馈问题或建议？**
A: 请到 [GitHub Issues](https://github.com/CGG888/SrcBox/issues) 提交，我们会尽快处理。

## 系统要求

**Q: 支持哪些操作系统？**
A: Windows 10/11 (x64)。

**Q: 需要安装什么运行库？**
A: 需要 .NET 8 Runtime。首次运行如提示缺少运行库，请从微软官网下载安装。
