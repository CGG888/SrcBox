# 频道快照预览

鼠标悬停在频道列表的频道上时，会显示一个实时预览快照浮窗，方便在切换频道前快速预览内容。

![频道快照预览](/screenshots/videosnapshot.png)

## 前置要求

频道快照功能依赖 **rtp2httpd** 的 `X-Request-Snapshot` HTTP Header 特性。

请确保你的 rtp2httpd 已开启快照支持：

```bash
rtp2httpd --enable-snapshot
```

## 功能特点

- **悬停即现**: 鼠标移入频道列表项，快照浮窗立即显示在频道左侧
- **不干扰播放**: 快照仅在悬停时显示，双击播放频道时会自动关闭浮窗
- **可自定义尺寸**: 默认为 214×120 (16:9)，可在设置中调整
- **LRU 缓存**: 30 秒缓存，同一频道 30 秒内不重复请求，节省带宽
- **并发控制**: 最多 2 个并发快照请求，避免 rtp2httpd 过载

## 设置说明

在 **设置 → 频道** 页面：

1. 勾选 **频道快照预览** 开启功能（默认关闭）
2. 可选调整 **宽度** 和 **高度**（最小 80×60）
3. 推荐保持 16:9 比例

## 工作原理

功能实现通过向 rtp2httpd 发送带有 `X-Request-Snapshot: 1` HTTP Header 的 HEAD 请求来触发快照生成，然后以 JPEG 格式返回当前视频帧。SrcBox 使用以下策略确保体验流畅：

- 快照请求为异步，不阻塞 UI 线程
- 结果缓存在内存中，30 秒内重复请求直接返回缓存
- 多个频道同时悬停时，最多等待 2 个请求完成

## 适用场景

- **频道浏览**: 在不播放的情况下快速浏览多个频道的内容
- **频道切换**: 切换前预览目标频道是否为目标内容
- **多屏监控**: 多屏模式下，悬停即可预览各频道当前画面
