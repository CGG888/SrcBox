# 预约功能

SrcBox 提供强大的预约功能，支持预约通知、预约播放和预约录制三种模式，是观看 IPTV 直播的得力助手。

## 功能概览

| 功能 | 说明 |
|------|------|
| **预约通知** | 节目开始前提醒，不自动播放 |
| **预约播放** | 到点自动切换到目标频道播放 |
| **预约录制** | 到点自动开始录制（前台/后台模式） |

---

## 预约通知

节目开始前弹出通知提醒，用户可选择观看或忽略。

### 功能特点
- 提前提醒（可自定义提前时间）
- 右下角 Toast 通知，不抢焦点
- 支持仅提醒模式

### 使用方式
1. 在 EPG 中选择目标节目
2. 右键选择"预约"
3. 选择"仅提醒"模式
4. 等待通知到来

---

## 预约播放

到点自动切换到目标频道并开始播放。

### 功能特点
- 到点自动播放目标频道
- 支持从时移开始播放
- 自动切换到目标频道

### 使用方式
1. 在 EPG 中选择目标节目
2. 右键选择"预约"
3. 选择"到点自动播放"模式
4. 到点后自动切换并播放

---

## 预约录制 (v1.1.9 新增)

到点自动开始录制，支持前台和后台两种模式。

### 前台录制

录制时画面会跳转到正在录制的频道。

| 特点 | 说明 |
|------|------|
| 画面跳转 | 切换到录制频道 |
| 实时预览 | 可看到录制画面 |
| 自定义时长 | 支持设定录制时长，到时自动停止 |
| 计时器显示 | 显示已录制时长 |

### 后台录制

录制时保持当前播放频道，不跳转。

| 特点 | 说明 |
|------|------|
| 不中断观看 | 保持当前播放 |
| 后台运行 | 录制在后台进行 |
| 自动停止 | 支持基于时长的自动停止 |
| 完成通知 | 录制完成显示 Toast 通知 |

### 录制完成通知

- 录制完成时显示 Toast 通知
- 5 秒后自动隐藏
- 区分前台/后台录制完成提示

### 使用方式

1. 在 EPG 中选择目标节目
2. 右键选择"预约"
3. 选择"前台录制"或"后台录制"模式
4. 可选设置录制时长
5. 到点自动开始录制

---

## 预约列表

管理所有已创建的预约。

### 功能特点
- 单实例管理窗口
- 复选框批量删除
- 全选/反选功能
- 状态筛选下拉框（v1.1.9 新增）
- 刷新按钮（v1.1.9 新增）
- 窗口层级在播放器之上

### 入口方式
- 托盘右键菜单 → 预约
- 下拉菜单 → 预约管理
- 右键菜单 → 预约列表

---

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `R` | 开始/停止录制 |

---

## 相关设置

预约功能相关设置可在设置窗口中配置：
- 预约提前提醒时间
- 默认预约模式
- 录制保存路径
- 录制完成通知方式
