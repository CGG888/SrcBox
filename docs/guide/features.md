# 功能特性

## 核心播放功能
- **播放控制**: 播放/暂停、停止、快进/快退、拖动进度。
- **音量调节**: 滑块调节，支持静音（0-100）。
- **音量增益**: 支持 -200dB 到 +60dB 的音量增益调节。
- **最大音量**: 可设置 100% 到 1000% 的最大音量限制。
- **音频延迟**: 支持 -100秒 到 +100秒 的音频同步调节。
- **状态标识**: 全屏条显示直播/回放/时移状态。

## IPTV 专用功能

### M3U 解析
支持本地/远程 M3U 列表，兼容 UTF-8/GB18030 编码。支持 `#EXTINF` 扩展属性。

### EPG 节目单
支持 XMLTV (gz) 格式，按日切换，自动匹配 `tvg-id`。
[查看使用与配置说明](./epg)

### 倍速播放
- 仅支持"时移/回放"，直播不支持倍速
- 可选速度：0.5×、0.75×、1.0×、1.25×、1.5×、1.75×、2.0×、3.0×、5.0×
- 选择后自动开启音高校正，确保人声不变调
- 全屏与窗口模式一致，按钮样式随深/浅色主题自适应

### 去交错功能 (Deinterlace)
- 针对 1080i/720i 隔行扫描视频流优化
- 三种去交错模式：自动 (Auto)、强制开启 (Force On)、关闭 (Off)
- 两种去交错算法：yadif（默认）、bwdif（更优质量）
- 支持场序设置：自动 (Auto)、顶场优先 (TFF)、底场优先 (BFF)
- 设置即时生效预览

### 频道管理
分组、搜索、收藏、历史记录（本地持久化）。

### 频道列表标识（R/T）
- R：支持回放；T：支持时移
- 鼠标悬停有国际化提示文本（中/英/繁/俄）
- 全屏与窗口模式保持一致的样式与布局

### 预约通知与预约播放
- 未来节目支持"预约"入口，区分"仅提醒"和"到点自动播放"策略
- 预约列表支持单实例管理、复选框批量删除、全选/反选
- 支持托盘/下拉/右键统一入口，窗口层级在播放器之上（窗口态/全屏态一致）
- 到点提醒与成功提示不抢焦点，通知策略与位置统一

### 精简模式
- 提供精简播放器窗口形态，保留顶部交互与核心播放控制
- 精简模式支持独立缩放命中、边缘光标提示、窗口拖拽与尺寸同步
- 精简模式与窗口/全屏状态联动，标识、EPG、频道列表状态同步

## Web 远程控制

通过浏览器远程控制 SrcBox 播放器。

[查看详细使用说明](./web-remote)

### 主要功能
- **播放控制**：播放、暂停、停止、快进、快退
- **音量调节**：音量滑块、静音切换
- **频道切换**：上下频道、频道列表
- **状态查看**：当前播放状态、节目信息
- **密码保护**：可选的访问密码保护

### HTTP/RTSP Header 设置
支持自定义 HTTP/HTTPS 流 Header 和 RTSP 传输设置。
[查看详细配置说明](./http-headers)

## 全屏与悬浮层
- **双击全屏**: 在视频区域双击切换全屏。
- **悬浮控制条**: 全屏下鼠标移动到底部自动显示，支持播放控制与 EPG 切换。
- **侧边抽屉**: 全屏下鼠标贴边显示频道列表（右侧）或 EPG（左侧）。

## 录播功能

- **本地录播**：支持直接录制到本地磁盘
- **WebDAV 上传**：支持录播后自动上传到 WebDAV 服务器
- **实时录制**：支持实时录播模式
- **上传队列**：支持上传任务队列管理

## v1.1.2 之后新增与优化

- **EPG 状态芯片**：节目单右侧使用芯片式标识（UI 与"预约"统一）
  - 直播=红色填充、回放=绿色填充（自动适配深/浅色）
  - 点击"直播"芯片=立即播放当前频道直播
  - 当前播放项整行高亮；回放播放中左侧额外绿色竖线提示（深色更明显）
- **预约与通知**
  - 预约通知列表单实例管理，首次打开跟随播放器居中，用户拖动后不再回弹
  - 支持"仅提醒 / 自动播放"两种预约策略，触发行为可区分
  - 支持复选框 + 全选/反选，删除时优先删除勾选项
  - 托盘右键/下拉/右键均可进入预约列表，窗口层级在播放器之上（全屏/窗口一致）
  - 到点/成功通知不抢焦点：右下角（到点/成功）+ 居中（列表）定位策略明确
- **M3U 管理**
  - 新增"管理 M3U 列表"窗口（与预约列表相同样式），支持复选框批量删除、单条编辑
  - 托盘新增入口；下拉/右键与托盘入口行为一致；全屏可见且置于播放器上层
- **系统托盘**
  - 常驻图标；双击恢复；菜单包含 打开/预约/管理 M3U/设置/退出
- **关闭确认**
  - 退出弹窗"×/ESC"仅关闭弹窗；"是"=退出，"否"=最小化到托盘（全屏先退出全屏）
  - 文案三段式国际化（已同步中/英/繁/俄）
- **深浅色适配**
  - 预约列表、M3U 管理、预约提醒、退出对话框等在窗口创建后即时套用深/浅色标题栏
