# 功能特性

## 播放控制

- **播放控制**: 播放/暂停、停止、快进/快退、拖动进度
- **音量调节**: 滑块调节 + 静音 (0-100)
- **音频设置**: 音量增益 (-200dB~+60dB)、最大音量 (100%~1000%)、音频延迟 (-100s~+100s)
- **状态标识**: 全屏条显示直播/回放/时移状态
- **倍速播放**: 时移/回放模式下支持 0.5×~5.0× 倍速，音高校正不变调

## 极速切台 (FCC)

针对 IPTV 场景优化的快速切台技术，毫秒级频道切换，告别漫长等待。

## 节目单与回看

### M3U 解析
支持本地/远程 M3U 播放列表，兼容 UTF-8/GB18030 编码，支持 `#EXTINF` 扩展属性。

### EPG 电子节目单
支持 XMLTV (gz) 格式，自动按日切换，智能匹配 `tvg-id`。
[查看配置说明](./epg)

### 回放 (Catchup)
基于模板自动生成回放 URL（如 `{utc:yyyyMMddHHmmss}`），不错过精彩节目。
[查看使用说明](./catchup-timeshift)

## 多屏播放

支持 4/6/9 屏幕同时观看，适合监控或多任务场景。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+4/6/9` | 打开对应多屏模式 |
| `1-9` | 选择对应小屏幕 |
| `↑/↓` | 切换频道 |
| `←/→` | 切换源 |

## 预约录制

支持前台/后台两种预约录制模式，录制完成自动 Toast 通知。

- **前台录制**: 画面跳转目标频道，支持自定义时长自动停止
- **后台录制**: 保持当前播放频道，支持定时停止
- **WebDAV 同步**: 录播后自动上传到 WebDAV 服务器

## Web 远程控制

通过浏览器远程控制播放器，随时随地掌控电视。

- 播放控制、音量调节、频道切换
- 实时状态查看、节目信息显示
- 可选密码保护

[查看详细说明](./web-remote)

## 频道管理

- **分组**: 频道分组管理，支持排序
- **搜索**: 快速搜索频道
- **收藏**: 收藏常用频道
- **历史**: 播放历史记录，本地持久化
- **R/T 标识**: 快速识别支持回放(R)或时移(T)的频道

## 频道快照预览

鼠标悬停频道列表即可预览当前画面，需要 rtp2httpd 支持 `X-Request-Snapshot`。

[查看详细说明](./channel-preview)

## 解码器选择

支持多种硬件/软件解码器，播放时动态切换：

| 解码器 | 说明 |
|--------|------|
| 自动 | 自动选择最佳解码器 |
| D3D11VA | Windows 视频加速 (默认) |
| DXVA2 | DirectX Video Acceleration |
| NVDEC | NVIDIA GPU 解码 |
| 软件 | CPU 软件解码 |

## 画面优化

### 去交错 (Deinterlace)
针对 1080i/720i 隔行扫描视频流优化：
- 三种模式: 自动 / 强制开启 / 关闭
- 两种算法: yadif (默认) / bwdif (更优质量)
- 场序设置: 自动 / 顶场优先 (TFF) / 底场优先 (BFF)

## 全屏交互

- **双击全屏** 或按 `Enter` 进入全屏
- **悬浮控制条**: 鼠标移到底部自动显示
- **侧边抽屉**: 鼠标贴边显示频道列表(右)或 EPG(左)
- **ESC** 退出全屏

## 界面特色

- **深色/浅色主题**: 完美适配 Windows 10/11
- **精简模式**: 紧凑窗口形态，适合小屏观看
- **多语言**: 支持简体中文、繁体中文、英文、俄文

| `E` | EPG 节目单 |
| `R` | 开始/停止录制 |
| `T` | 时移模式 |
| `Ctrl+,` | 设置 |
